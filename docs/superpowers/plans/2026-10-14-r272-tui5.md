# R272 TUI 五项细化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TUI 五处补齐——bg 投单回执流、顶栏 LLM 位、历史落盘＋二级补全、失败动作行展开、night sparkline。布局不动（对话区出卡＋顶栏加段＋输入区行为），G1（只渲染/派单，不判定）。

**Architecture:** 全部在 `scripts/dwc_tui.py` 内做＋`memory_view` 加一个纯函数（sparkline）。数据源全现货：`agent_rpc.cmd_query`（单态）、`LLMClient()._model/_host_only/configured`（只读，key 不碰——`__repr__` 同款 key-safe）、`var/dwc_tui_hist.jsonl`（新文件）、progress `action` 事件原文。

**Tech Stack:** textual 现状；测试沿 R244/R271 惯例（pilot＋纯函数）。

## Global Constraints

- G1：回执只读 `cmd_query`＋渲染 report 摘要，不重判成败（state 照抄）；展开只展示 ev 原文字段，不推断。
- 凭证：顶栏只显示 host（`_host_only` 同款），model 名可全显，**key 绝不读**（连 `os.environ` 都不碰）。
- 降级：textual 缺席整机回退不变；`cmd_query`/LLM 读数失败记"—"不炸屏。
- 中文输出；`pytest.raises` ≥5%；全量回归 `pytest tests/` 后台；不重启 agent（前端进程）。
