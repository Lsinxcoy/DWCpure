# R276 · 进化第一轮跑通（三根线）

## 断裂点（已实测）
1. 回灌断：`Memory.remember(FAILURE_SIGNATURE)` 生产调用方为零；
   `Loop` 根本无 memory 引用 → judge 判完即弃，failure_sig 表 0 行。
2. 落地丢：`_consolidate_rule→land_rule` 只改内存 RULES；`flush`
   （persist_learned→rules.json）除 e2e 自清洁外无人调。
3. 账丢：`_last_ledger_entries` 只活内存，无落盘。

## 三线（loop.py 内，默认全关/空安全）
① `__init__ += self.memory=None`＋`attach_memory(m)`；fail 分支
   diagnose 前调 `_remember_failure(tid, sigs)`（D6 要 c/q/m，
   缺键跳过；异常 stderr 留痕返条数；未 attach 返 0）。
② `_consolidate_rule` "consolidated" 后调 `tgt.flush()`，
   成败记 `_last_consolidation["flushed"]`（anchors 只增：persist
   只写 learned，种子留代码）。
③ 667 行后调 `_persist_credit(tid, round_no)` → `var/credit_ledger.jsonl`
   append（json default=str；异常留痕不阻断本轮）。
