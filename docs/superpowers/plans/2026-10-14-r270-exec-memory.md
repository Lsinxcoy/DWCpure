# R270 跨任务执行记忆 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 DWC 补上"执行记忆"（episodic 轨迹、效用学习、程序模板、分层晋升、写入门、遗忘四策）， lessons 管道从"结论便签"升级为"用进废退的记忆系统"，灵感逐条锚定母巢/Nexus/Ultra/v10/Protogonos/MSTAR 的实证机制。

**Architecture:** 不建新子系统、不换存储引擎。所有机制挂三处：`agent_quality.py` 的 lessons 管道（touch/分层/写门/效用字段）、`planner.craft` 的提示入口（模板 hint）、`var/` 下两个新 JSONL（episodes、workflows）。recall 排序语义冻结（只增返回字段），新行为全走阈值＋开关。

**Tech Stack:** Python 3.11+，标准库 only（hashlib/md5/json），pytest；新 LLM 调用零个（模板/效用/遗忘全规则）。

## Global Constraints

- 精准手术：只动 `src/dwc/agent_quality.py`、`src/dwc/organs/planner.py`（compose_prompt 2 行）、`scripts/dwc_nightbench.py`（ep 行写入 3 行）、`scripts/dwc_lesson_reconcile.py`（执行 merge/drop 1 个函数）；新建 `src/dwc/organs/workflow_templates.py`、`scripts/dwc_memory_utility.py`、`scripts/dwc_episodes.py`（查询口，可并入 externalization？不——独立小脚本 60 行内）。
- recall_lessons 排序键冻结：仍是 (-overlap, not contrast)；touch/utility/tier 只进返回字段与下游（晋升/reconcile/MemPO），不动排序（旧测试零风险）。
- record_lesson 行 schema 只增字段（use_count/last_used/utility/tier/quality，缺席默认），旧行照读。
- 测试零真 LLM；`pytest.raises` ≥5%；全量回归走 `pytest tests/` 后台。
- 中文注释/输出；原子写回（tmp＋os.replace）；失败计数不炸（G7）。
