**Goal:** 补齐 DWC 投产 P0 三门（单实例互斥、定时备份、回滚演练），验收标准=7 天 cron 全绿+adopt≥1+回滚/混沌各演练 1 次的前三项代码落地。

**Tech Stack:** Python stdlib（fcntl/msvcrt 锁、sqlite3 backup API、shutil）、hermes cron（no_agent script）、pytest fake（零真 LLM）。

**Spec:** 投产审计结论（2026-10-16 对话）：P0=①adopt 真落地零次（R297 不解，等明晨 cron；本计划解②③）②回滚零演练（var/backup 空）③单实例无互斥（8 同名进程实锤，R210 pid 锁非原子竞态可双过）。

## Global Constraints

- 不动生产判定：只增调用/新文件，daemon 主循环、judge、trial、accept 零改。
- anchor 只增不改；双副本 md5 同步（E:→.dwc scripts+src+tests+plans）。
- R292 总闸：新测试写盘一律指 tmp；备份脚本人跑才落生产路径。
- 凭证永不进 git/日志/回显。

## Review Focus

- 双 start 同时撞锁：后到的必须 rc!=0 且先到的 pid 文件字节不变（竞态窗口实测）。
- 备份跑时 daemon 正在写 sqlite：备份必须是 sqlite3 backup API 出来的可用库（打开能查），不是 cp 拷 WAL 中间态。
- 回滚坏规则键不存在：必须大声抛（KeyError 留痕），不静默"回滚成功"。
- 锁文件残留但进程已死：新实例必须能接管（stale 判活），不卡死"永远拒启"。
- Windows 无 fcntl：锁必须走 msvcrt.locking 或等价，不许 import fcntl 裸奔。
