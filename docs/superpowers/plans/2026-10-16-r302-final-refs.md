- [ ] **Step 3: Implement `verify_final_refs` in `src/dwc/llm/step_judge.py`**

签名：`def verify_final_refs(answer: str, root: Optional[str] = None) -> Optional[str]`。算法（顺序执行，首错即返）：
1. 空 answer⇒返 `"final 空 answer"`（与 validate 同口径）。
2. 路径 token：`re.findall(r"[\w\-. /\\]*[\w\-.]/[\w\-. /\\]*\.(py|md|json|yaml|yml|txt|jsonl)", answer)`；逐个 strip，跳过含 `http` 者；`cand = t if isabs else join(base, t)`，`base = root or DWC_ROOT or cwd`；不存在⇒返 `"引用路径不存在: %s"`（截 60）。
3. 行号：`re.findall(r"(?:第\s*(\d+)\s*行|[Ll]ine\s*(\d+)|:(\d+)\b)", answer)`；裸 `:6` 易误伤（轮数/时间）——只认"第N行/line N"两种，第 3 组（冒号型）**不验**；每个 N 就近找上一步已验存在的路径（同 answer 内最后一个存在路径；无则跳过该 N）；`len(open(cand).readlines()) < N`⇒返 `"引用行号超界: %s 第 %s 行（实 %s 行）"`。
4. 引文片段：`re.findall(r"[“\"']([^“\"']{6,60})[”\"']", answer)`；每个片段若 answer 内有已验存在路径⇒该文件全文含片段？通过：失配⇒返 `"引文失配: “%s” 在 %s 未找到"`；无路径⇒跳过（观点句放行）。
5. 全过⇒None。
