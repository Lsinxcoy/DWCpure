# R271 记忆机制可视化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R268–R270 落地的执行记忆（episode 链/分层/写门/模板/遗忘/效用/终态机）在 TUI 里完全不可见。补一个只读记忆看板：`/mem` 四子视图＋顶栏记忆摘要，TUI 只渲染不判定（G1）。

**Architecture:** 看板=纯函数（`src/dwc/organs/memory_view.py`，DWC-MEM，零 TUI 依赖，单元可测）→ TUI 经 `/mem` 命令调纯函数→Markdown 卡渲染。布局零改动（对话区出卡＋顶栏加一段），不碰动作区/树/输入/面板。

**Tech Stack:** textual 现状（Markdown 卡＋Static 顶栏），标准库 only；测试沿 R244 惯例（`run_test` pilot＋纯函数断言）。

## Global Constraints

- G1：TUI 不判定——`memory_view` 只读 var/ JSONL（lessons/episodes/workflows/curve/archive），排序/阈值复用现有函数，不发明新判据。
- 设计语言：Deep Space（纯白字＋amber 点缀，三级灰阶），看板用现有 `msg-sys`/`msg-ans` 卡，不新增 CSS 类（最多 1 个）。
- textual 缺席时 `/mem` 走 `dwc_chat` 同命令？不——chat 回退是整机回退（main 级），`/mem` 只在 TUI 内有效；`memory_view` 纯函数在 scripts 里 `import` 必须失败降级（try/except 留痕，R263b 同款）。
- 中文输出；`pytest.raises` ≥5%；全量回归 `pytest tests/` 后台。
