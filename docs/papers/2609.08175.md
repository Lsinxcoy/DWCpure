## 一、核心问题

失败任务上修好了≠以前成功的任务还保得住——可靠采纳（reliable adoption）要求全用户任务分布上的期望 reward 真涨。论文给三件套：**充分条件（T=(λ,δ)）＋验证规则（Two-Gate，带保证）＋天花板（验证/评估成本决定）＋停滞诊断（reachability：是生不出好候选，还是证据不够不敢收）**。一句话：失败任务增益必须盖住保留任务的可能损失＋评估误差，否则不采纳。

## 二、理论基础

### 2.1 分解（§2.2）

任务分布 D_user 按当前 agent 失败率 Z_k 切成失败分布 D_F 与保留分布 D_R（Eq.1）。候选的总期望差分解（Eq.2）：J(ẽA)−J(A_k) ＝ L（失败任务贡献） ＋ (1−Z_k)·保留任务平均差。保留任务用**平均绝对变化** D_R(ẽA;A_k) 控制。

### 2.2 充分条件（Thm 1 / Cor 1）

Qualified 集 P_k(T)＝{L_k(c)≥λ, D_k(c)≤δ}。若 λ＞(1−Z_k)δ，则其中每个 c 的增益 ≥λ−(1−Z_k)δ＞0。γ-校准：λ_k(γ,δ)＝γ＋(1−Z_k)δ 保增益 ≥γ。

## 三、方法

### 3.1 Rule 1：Two-Gate 验证（§3.1）

估计 L̂≥τ、D̂≤δ、且增益下界 Δ_k＝τ−ε_L−(1−Ẑ＋ε_Z)(δ＋ε_D)＞0（Eq.4-5）才收。Thm 2：误收（真增益＜Δ_k）概率 ≤β_step；特别 P(收了但真增益≤0)≤β_step。**Remark 5：采纳后 reference data 必须刷新。**

### 3.2 达成概率＋跨轮累积（Thm 3 / Thm 4）

N 个独立生成 run＋验证，达成 T-qualified 采纳的概率上下界（Eq.8）：(1−β_stat)(1−(1−P⁺)ᴺ) ≤ R ≤ 1−(1−P)ᴺ。**验证只能收池子里有的——generation 也封顶可靠采纳。** 跨 K 轮增益累加 ΣΔ_k（Eq.9），不需轮间独立；分布漂移扣 total-variation（Thm 10）。

### 3.3 天花板（§4）

Two-Gate 天花板（Cor 2）：J＜1−(1−Z)δ−ε_Σ 时才能继续验证——**验证把全额允许的保留变化当潜在损失扣掉，评估误差再压一层**。Rule 2（Measured-margin，Eq.12）改用候选**自身的**保留损失 D⁻_R，天花板升到 B_k＝1−(1−Z)δ⁻。Thm 5：gap u＝1−J 时，任何 level-β 验证程序最坏期望评估 cost Ω(u⁻¹)——**越接近满分，验出小增益越贵**。

### 3.4 停滞诊断（§5，reachability）

Reachability P_k(T)＝一次生成 run 产出 T-qualified 修改的概率；用 N_meas 个输出的评估区间给上下界（Eq.13，Thm 6，对一切 T 同时成立）。判据：**上界小＝生不出；下界大＋有独立确认但未验证的修改＝证据不够**。DS-1000 实证（持久 Python solver-harness 修，3 种生成×96 输出，56 audit 任务，目标 T₀=(0.05,0.50)）：audit 达标率 26–38.5%，但验证通过仅 2/96（全是 Independent 组）——回溯 1 个 outcome-feedback 候选 L≥0.055/D≤0.2766/Δ≥0.0556，结论：**原验证证据不足，不是生不出**。

## 六、讨论

### 6.1 与 2610.18813 的关系

Cai 是 Harness RSI 的"采纳理论分册"：18813 给 Eq.8（Hoeffding 准入），Cai 给 T=(λ,δ) 充分条件＋Two-Gate＋天花板＋诊断。两者互补：18813 管"怎么验"，Cai 管"收到什么数才算够、什么时候别验了、停了怎么查"。

### 6.2 局限（§7 自述）

保证只管期望 reward＋平均变化；reward–utility gap 需另界（B.5）；用户需求随更新而变需修正（E.4）；group 保护需有限数据估计保证（B.2）。

### 7.2 关键建议

1. **停滞查账**（最高优，零代码）：ledger 按拒因聚合——duplicate-key/空过/blocked 各多少，判 0.888 是生不出还是不敢收。
2. **门参数显式化**：eps/max>0 改写成 (λ,δ,γ) 三数＋注释对应 Cor 1。
3. **基线刷新纪律**：adopt 落地后重拍快照（Remark 5），先核实 R299-b 现状。
4. **小 Δ 熔断**：Δ＜spread 直接不验（Thm 5 成本论），省 LLM 预算。

## 九、总结性评价

### 核心贡献

1. T=(λ,δ) 充分条件把"收不收"变成两个可估的数。
2. Two-Gate＋β_step 误收保证；Thm 3 点出 generation 也封顶。
3. 天花板＋Ω(u⁻¹) 成本下界：第一次有人算出"满分附近别硬验"。
4. Reachability 诊断：停滞二分法＋DS-1000 实证（2/96 vs 26–38.5%）。

### 局限性

全是期望＋平均；group/utility/需求漂移全要另界；证明附录未验。

### 总体评估

DWC 下一步的"采纳理论分册"：accept 门的定型（T 参数化）、0.888 停滞的查账法、天花板的预算观，三件事都可直接用。建议入库＋先做 §7.2-1 查账（零成本）。**理解自评：L4（正文 §§1-5＋7-8 全读，数字逐个核对；附录 A–G 证明未逐行；related work 已扫）。**
