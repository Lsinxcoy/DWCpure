## 一句话总结

EDIT 是一个**两阶段评分器训练框架**：Phase-1（EDIT-SFT）用模型**自己的内部状态**——对最终分数的后验信念漂移 Δε_k + 输入掩码接地审计 G^ρ/G^a/G^p——定位判分推理里"把信念拉离金标准"的那一个步骤，只对它做受局部性约束的原子改写（改写时喂入 gold mark 作特权信息的 rubric checklist）；Phase-2（EDIT-RL）在 GRPO 上叠加**信念引导的奖励塑形**，惩罚中途大漂移、容忍阈值内的良性探索，从而把"规则忠实性"从"分数预测准确"里分离出来。

## 核心方法/机制

### 0. 问题定性（论文自陈的缺口）

- 评分是**规则应用任务**，不是自封闭推理任务：`Each judgement must be groundedinthemarkschemeandevidencefrom the student answer.`（Abstract）
- 现有 credit-assignment 方法（GRPO 单标量、token 级重分配、干预式训练）是为数学类任务设计的，**"do not identify where grading reasoning goes wrong or how the model's belief about the final mark changes during reasoning"**（Abstract）。
- 两条额外要求（§1）：① **external grounding**——每一步必须同时锚定 mark scheme 与学生书面证据；② 规则推理是**不确定性消减过程**，`The model’s belief about the final mark should progressively converge.`，而 outcome-only RL 会忽略中段的有害信念漂移、token 级约束会过度惩罚良性措辞探索。

### 1. 内部状态信号（§2.1，两阶段共用同一坐标系）

记号：问题 q、评分规则 ρ、学生答案 a、rollout 的 T 个推理步 s_{1:T}、金标准分 m*、满分 M_q。

**(A) 后验信念探针（Eq.1–2）**：在步边界 k∈{0,…,T}，把"最终打分 scaffold"接到部分推理链后面，读有效分数 token 上的 next-token logits：

```
p̂_k(m) ∝ exp( logit_θ(m | q, ρ, a, s_{1:k}, scaff.) )        (Eq.1)
m̂_k = E_{m∼p̂_k}[m] ,   ε_k = |m̂_k − m*|
Δε_k = ε_{k−1} − ε_k                                          (Eq.2)
```

Δε_k > 0 ⇒ 该步把信念拉近金标准；< 0 ⇒ 拉远。**候选步骤就是按 Δε_k 最负来排的**。

**(B) 掩码接地审计（Eq.3–4）**：对每个 s_k 算全上下文负对数似然 ℓ^full_k = ℓ_k(q,ρ,a,s_<k)，再分别把某一输入段换成占位符：

```
G^ρ_k = ℓ_k(q,[MASK],a,s_<k) − ℓ^full_k        # 规则支撑
G^a_k = ℓ_k(q,ρ,[MASK],s_<k) − ℓ^full_k        # 学生答案支撑
G^p_k = ℓ_k(q,ρ,a,∅)       − ℓ^full_k          # 前缀支撑
ẽG^p_{i,k} = G^p_{i,k} − µ_p(u_{i,k})          (Eq.4, 位置残差化)
```

论文把它定义为 `Thisauditisaninput-ablationprobe.`——把某段输入换成占位符，量"已经生成的这一步变难了多少"。因为 G^p 天然随位置增大，用数据集级位置均值 µ_p(u) 做残差化。

**外部效度（Appendix E）**：用**更强的标注模型**（非人工）给每步打 grounding/synthesis 标签，两个信号**反向解耦**——Answer Grounding 区分两类 `with a large effect (r=0.71,p<10 −300)`，Prefix Grounding 同向（r=0.58, p<10^-300），而 `Rubric Grounding, in contrast, is statistically significant but practically negligible (r=0.08)`。

### 2. Phase-1 EDIT-SFT：规则感知原子干预（§2.2 + Algorithm 1）

四个子阶段：

1. **Rubric-checklist 生成**：以 **gold mark m* 作特权信息**（`available only during training- pool construction, not at inference`）prompt 策略，让它逐字列出每个 scoring point 并判断是否被覆盖、附引用证据 span。
2. **候选步选择（Algorithm 1，Appendix C 逐行）**：
   ```
   1: C ← { j : Δε_j < −τ }            # 只用信念漂移准则（丢弃正向/近平局）
   2: C ← top-k of C by most-negative Δε_j
   3-5: w_j ← [G^ρ_j < p25(G^ρ)] ∧ [G^a_j < p25(G^a)] ∧ [ẽG^p_j < p25(ẽG^p)]
   6: 稳定重排：w_j=1 在前，同组保持 Δε 序   ▷ 只重排, 不删步
   7: return first min(n, |C|)
   ```
   关键纪律：**接地审计只做重排、`The audit never excludes a step.`**，且"信念大幅变负但接地很强"的步（证据齐全却判错）仍是首选目标。
3. **原子改写 + 局部性约束**：把被选步改写成 1–3 个子步，prompt 含 {q,ρ,a}、高亮目标步的完整推理链、内部信号诊断 bullet、checklist（`a checklist to CONSIDER, not satisfy`）；局部性约束同时防"从 gold/checklist 里抄答案"，配 checklist-mimicry detector（Appendix J）。
4. **结果过滤与组池**：每次改写采 N 个续写，`retain the revision if any continuation reaches the correct mark`；存活 rollout + 天然正确的 golden rollout 一起进 SFT 池。

### 3. Phase-2 EDIT-RL：信念引导奖励塑形（§2.3，Eq.5–7）

```
r_out  = max(0, 1 − |m − m*| / M_q)                          (Eq.5, parse 失败=0)
r_shape = −(1/M_q)·(1/T)·Σ_k max(0, |m̂_k − m*| − β_drift)    (Eq.6)
r = r_out + γ_Φ · r_shape                                    (Eq.7) → 距离感知 GRPO
```

- **β_drift 是"探索容差"**（单位=原始分），阈值内的波动不罚，超出部分按超出量罚。
- **探针跑在冻结的 EDIT-SFT checkpoint 上，不是当前策略**，理由（Appendix D）：① *Non-gameability*——`RL could lower the shaping penalty by shifting its own beliefreadout rather than by grading more faithfully`；② *Calibration*——SFT 策略已是合格评分器，其步边界后验是"信念该在哪"的有意义参照。
- 承认这放松了经典 PBRS 的策略不变性（Ng et al. 1999），但给出可验证的替代：附录 D 直接测 KL（见下）。
- **两个超参的标定规则**（Appendix B，验收规则）：β_drift 与 γ_Φ 只用训练 rollout 的随机 10% 子集、**只用信号统计不用性能指标**；β_drift 扫描取"错误 rollout 与正确 rollout 上塑形罚触发率分离最大"者；γ_Φ 取**最大的 flip-safe 值**——`the accu- mulated penalty on a correct rollout stays below the outcome-reward gap to an incorrect one, so the shaping term can never invert the outcome rank- ing within a group.` 探针读取温度 0.7。

### 4. 工程实现要点（Appendix B）

- 全部方法同一 Qwen3-8B + LoRA（r=64, α=128，作用于 q,k,v,o,gate,up,down），SFT 2 epoch / lr 2×10⁻⁴；RL lr 5×10⁻⁶、β_KL=0.02、每 prompt 8 rollouts × 4 prompts = 32 completions、温度 1.0、1024 token 上限；SAS 200 步、Private-Science 500 步；**`every re- ported result uses the final-step checkpoint rather than a selected peak`**，无任何 test 指标参与选点。
- 后验探针"一次前向出全部步边界"：每个边界挂一个 answer scaffold，用 block attention mask + 匹配位置索引，让每个 scaffold 只注意自己的前缀（平均每 rollout 5.2 个边界）。
- 算力（Private-Biology）：EDIT-SFT `≈9 GPU-hours`（≈2.5 探针 + ≈4 选步与接地审计 + ≈2.5 采样验证改写）vs InT ≈8；SFT 池 `56,595 samples for Edit-SFT( 33,958 golden rollouts and22,637 revi- sions) and29,822 for InT`（两者共享同一 20-rollout/响应池与 55,278 条错误 rollout）；RL 单卡 `All RL runs use a single GPU (H200 141GB)`，EDIT-RL 比 GRPO 每步多 ≈2s（12s 步）。

### 5. 附带提出的一个**可迁移评测协议**：Rule-Sensitivity Ratio（§3.4 + Appendix I）

对 mark scheme 施加**确定性、gold 分可精确重算**的改动（LoR 档位平移 A1 +2 / A2 ×2 / B1 差分；PTS 分值 ×0.5 / ×1.5 / ×2.0），in-prompt 换规则重新打分，量：

```
RSR = |Δpred| / |Δgold|        (1=完全跟规则; <1 欠反应; >1 过反应)
因 pred=0 是一切编辑的不动点 ⇒ 拆成:
  FR  = 被扰动预测中等于 0 的比例（floor rate）
  IB-RSR = 只在非零预测上算的 in-rubric RSR
聚合用 AE-RSR = mean |IB-RSR − 1|  （消掉正负抵消）
```

### 负面结果 / 论文未报告（诚实项）

- **PTS 缩放对所有系统都未解**（AE-RSR ≥ 0.5），绝对计数锚定是开放问题。
- **Geography 上所有 RL 变体都劣于 Base**（QWK 0.675–0.745 vs 0.706），只有 EDIT-SFT 0.779 例外；论文把它归因于终局分数带/部分分合成错误（附录 H：EDIT-SFT 与 InT-SFT 的 73 处分歧中 66% 属此类）。
- **SAS-History 三种子 Δ 的 CI 含 0**（[−0.007, +0.030]）——论文原样报告，未宣称显著。
- **流水线级算力不对等**：`the two RL arms in our controlled com- parisonarebudget-matched,thepipeline-levelcom- parison against baselines is not:Editincurs extra offlinecomputeforposterior-beliefprobing,ground- ing audits, and revision sampling (Appendix B)`。
- **结果过滤有偏**：`62.8%ofincorrectrolloutson Private-Biology and 76.4% on SAS-History yield no corrected example` ⇒ 池子偏向"局部改写可修"的样本（Limitations 第四条）。
- **Private-Science 不可公开**（licensing/privacy），OOD 每科只有 2–3 题，题级显著性分析只在 SAS 上做：`the Private-Science OOD splits contain only two to three questions per subject`。
- 论文**未报告**：主表的多 seed 方差（仅 Table 4 两个数据集做了三种子）、长作文/ASAP 与法律医疗域的表现、清单不可用时的退化曲线。

## 与 DWC 的映射

| 机制（EDIT） | DWC 现状（代码级） | 判定 |
|---|---|---|
| 后验信念探针：步边界读分数 token logits，Δε_k 定位"拉远金标准"的步（Eq.1–2） | 无任何模型内部状态读取。`organs/judge.py` 的 `Verdict` 只有 `success: Optional[bool]`、`reason`、`failure_signature{c,q}`、`n_checks/n_pass`；判分是规则比对（`classify_c`/`classify_q`/`_diff`），不产生逐步信念轨迹 | **缺**（无逐步内部信号；DWC 也无权重训练，探针需要 logit 通道，DWC 现有 LLM client 不回传 logits） |
| 掩码接地审计 G^ρ/G^a/G^p + 位置残差化（Eq.3–4） | 证据链是**外显**的：`judge._store_evidence()` → `evidence.jsonl` → `Verdict.failure_signature` → `TaskScoreStore`（C3' TS3 逐任务分数序列），存的是"结论从哪来"，不是"输入消融后这步变难多少" | **缺**；可挂点：C3' 已有 `task_scores()`/`evidence(ref)` 双查询口，若要加"每步接地分"，落点就是 `TaskScorePoint` 的扩展字段 |
| 步选择验收规则：信念负漂移 top-k → 接地三分位只重排不删（Algorithm 1） | 候选生成走 `organs/candidates.py::CandidateGenerator.generate()`（R1/R2 规则变异 + `_llm_generate`），筛选靠 `evolver.check_component`/`check_pairing`(K2) + 池上限 G4；**没有"按证据定位坏步"的排序键**，只有失败签名 (c,q) 粗粒度分组 | **缺**；δ 稀有度排序（`weakness.py::weak_ranking`）是唯一已有的"排序偏置"接口，但排的是签名频次，不是步级证据 |
| 原子改写 + 局部性约束 + checklist-mimicry 检测 | 候选是整函数体 splice（`_splice_body`/`_r1_range_offset`/`_r2_type_wrap`），无"只改一步/1–3 子步"的局部性约束，也无"禁止抄 oracle"检测 | **缺**（对象不同：DWC 改代码而非推理链，但"局部性 + 禁抄参考"这两条约束本身可移植） |
| 结果过滤保留（N 采样中任一到达金标才留） | 同族机制已存在且更严：`applier.apply_on_copy` → `commit`/`rollback` + 回归窗口 `window_settle`，实测注释 `860 accepted → 2 applied`；外加 K1 覆盖/K2 声明一致/池上限 | **确认型**（DWC 的门更严，且拒绝原因可查 `candidates.record_rejection`）；EDIT 的独有点是**过滤偏差显式记账**（62.8%/76.4% 无产出），DWC 未对"门拒后有多少候选白白生成"做同类偏差报表 |

## 综述 L 框架定位

**共享背景**：DWC = 独立自进化 agent：世界树(seed/expand/observe, W1-W6 纪律) + judge 判分(C3' 证据链) + δ 失败签名稀有度排序 + EL 采样调度(B/τ 窗口) + Dreaming 回放(K₂/β/V) + M>1 策略修订(PolicySpec)。综述 L 框架: B0=任务内输出改, L1=执行人定程序, L2=自主选改法, L3=自主定学习议程, L4=部署交互改持久态, L5=改改进机制本身。

- **L 级别：L1（Improvement Execution Autonomy）**。综述 Table 2 把 EDIT 放在 **L1 Execution** 列，技术族三处：**A4. LLM Reflection / Critique**、**C1. Supervised Fine-Tuning (SFT)**、**C3. Reinforcement Learning (PPO/GRPO/RLVR)**；正文引用位置 **§3.2.2（training-method level）**，综述原话：`Researchers first specify the diagnostic signals and revision criteria, after which the system identifies problematic reasoning steps and an LLM revises only the affected parts according to a rubric checklist.`（另被 Table 3 引用）。**符合判据**：目标、反馈信号、更新规则、验收准则全部由人预先规定（β_drift/γ_Φ 的标定规则也是人写的），AI 只执行这套诊断→改写→校准程序，产出的改进（LoRA 权重）被持久保留并作用于后续判分任务 —— 越过 B0 的"仅改当前输出"边界，但**没有任何一项"改进流程本身"的决策权交给模型**。
- **structural L5：否**。L5 判据是 `AI persistently modifies a mechanism responsible for future improvements and uses the revised mechanism in subsequent rounds`。EDIT 被修改的对象是**判分器的任务能力（权重）**，而"如何诊断、如何改写、如何算奖励"的机制（两阶段流程、信号定义、选步规则、flip-safe 标定）在论文中**逐字固定、全程未被模型触碰**——既无"修订后的机制回到下一轮改进的生成/评估/选择"的闭环，也不存在可被 AI 修改的"改进机制"实体。
- **effective L5：否**。没有"修订机制在可比预算 + 独立评估下产出更好后继"的实验（根本没有机制层的后继概念）；EDIT 的全部证据都是**被改进对象（评分器）的任务指标**。
- **递归判断的一句话**：EDIT 是 L1 的教科书样本——**执行层自动化 + 被动持久化（权重）**，与 DWC 的关系是"可借协议，不可借层级"：DWC 若引入 RSR 类规则扰动探针，落点也在 judge 的**验收规则**，属于 L1 配置项而非 L2 自主选择。
