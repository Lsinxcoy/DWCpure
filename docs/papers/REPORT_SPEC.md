# 深读报告规范 · DWC

> 19 篇逐篇深读，**每篇一份独立报告**，落`docs/papers/`。
> 统一结构 = 可横向比较；**不是模板填空，每篇必须回答它自己的问题**。

---

## 固定骨架（六节，不可省略）

### 1. 问题
这篇要解决什么？**它自己承认的**缺口是什么（不是我们猜的）？

### 2. 核心机制
它到底造了什么？用**可复现的粒度**描述——具体到算法步骤、数据结构、判据公式。
禁止复述摘要。必须出现论文里的**具体名词/符号/伪代码**。

### 3. 关键实验与数字
- 基准是什么、样本多少、对照组设了什么
- **提升了多少，用什么单位**（百分点 / 倍数 / 通过率）
- 有没有**负面结果或失败案例**（诚实项：很多论文这部分空着，要写"论文未报告"）

### 4. 它假定了什么（Assumptions）
把这篇的隐含前提挖出来。**这一节最容易被跳过，但它决定能不能搬进DWC。**

### 5. 可迁移到 DWC 的点 / 不可迁移的点
- 可迁移：写清**搬什么机制** + **DWC 侧的接口**
- 不可迁移：写清**为什么搬不了**（前提不成立 / 量级差太多 / 依赖闭源模型）
> 禁止"有借鉴意义"这类空话。要么给出具体机制，要么明说不可迁移。

### 6. 与其他 18 篇的关系
它和其他论文是**互补 / 竞争 / 前序**？放到 RSI 领域图谱的哪个位置？

---

## 诚实条款（**违反即报告作废**）

```text
1. 没读到全文不许写"深度报告"—— 每篇须注明读的是全文还是仅摘要
2. 数字必须来自论文正文, 不来自二手转述
3. 论文没报告的实验/负面结果, 必须写"论文未报告", 不许推测填补
4. "可迁移"必须给出具体接口, 不许写"有参考价值"
5. 若论文的方法依赖闭源模型(GPT-5/Claude Opus 等), 必须标注
   —— DWC 不具备同等模型条件, 这直接影响可迁移性判断
```
