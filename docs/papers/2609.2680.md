## 2. 核心机制

### 2.1 ★ 两个工程目标（§3.2，全文的组织轴）

```text
Goal A · automated design of AI infrastructure（自动设计）
  公式 (2): (a*, λ*) ∈ arg max Q(S(a, λ, θ*(a,λ)); D_val)
            θ*(a,λ) ∈ arg min L_train(θ; a, λ, D_train),  C_search ≤ B
  ★ "A new design is an output of the search. **A recursive return path exists only
     when the retained result also affects how later designs are generated or selected.**"

Goal B · repair and optimization of an existing system（修复/优化）
  公式 (3): δ*_t ∈ arg max Q(S_t ⊕ δ; D_target) − λ_e·d(δ)
            subject to  Q(S_t ⊕ δ; D_j) ≥ Q(S_t; D_j) − ϵ_j  ∀j     ← ★ 保护能力约束
                        C_update(δ) ≤ B_t
  ★ "All selection data here are development or validation data. An independent audit
     tests whether the selected edit also works outside them."

★ 两目标可重叠（原文）:
  "Replacing a workflow after a failure is both a repair of its current behavior and a
   design decision. The distinction lies in the experimental goal and constraints,
   **not the format of the code or whether model weights change**."
```

### 2.2 ★★ 统一循环（§3.3 式 4）—— 全文骨架

```text
★ 状态定义（原文）:
  X_t = (S_t, I_t)  保留态 (retained state)
    S_t = 支撑任务求解的状态: model parameters, prompts, memory, skills, executable programs
    I_t = 产生/选择后续更新的过程: its programs, parameters, strategies, persistent context
  ★ "This is a distinction between **functional roles**: one model or program can support
     both task solving and improvement. The roles can therefore **share an implementation**."

  其余符号:
    E_t = 本轮可用于改进的经验与反馈
    V_t = 用于验证候选并选择更新的信息
    C   = 声明为**外部固定**的条件 (task objectives / data-access rules / resource
          constraints / models, tools and evaluation interfaces outside the update scope)

★ 更新式（式 4，两行，注意是两个不同算子）:
    X̃_{t+1} ~ P_{I_t}( · | X_t, E_t ; C )        ← P = 候选生成 (由当前改进过程参数化)
    X_{t+1} = R_t( X_t, X̃_{t+1}, V_t ; C )       ← R = 实际验证与保留机制

★ 原文的关键补充（三条）:
  ① "Updatable parts of the retention mechanism fall within the analysis of I_t,
      while its externally fixed constraints belong to C."
     ⇒ ★ 保留机制本身可以可进化, 但它的外部固定部分属 C
  ② "Validation can accept a candidate, **retain the existing task system and improver**,
      or place a candidate in an archive for later selection;
      **failed attempts and their costs also require recording**."
     ⇒ ★ 三态: 接受 / 保持现状 / 入档; 且失败尝试与其成本必须记录
  ③ "For evolution with multiple branches, X_t can include the candidate archive and
      selection state, allowing this representation to accommodate **non-greedy retention
      and multiple exploration paths**."
```

### 2.3 ★ 四种"存活模式"（§3.3 Figure 6）—— 最有用的分类

```text
按"跨轮携带什么状态"分四类:

(a) Local revision（局部修订）
    Revise within one task; check → revise; **local only**
    ★ 答案修订**不**成为求解器或改进器的持久更新
    ★ "Same solver" 进入未来任务

(b) Memory retention（记忆保留）
    Accumulate experience; distill; M_t → M_{t+1}; **retain**
    ★ 模型参数与所选更新过程保持固定
    ★ 未来任务拿到 "Solver + memory"

(c) Parameter learning（参数学习）
    Learn weights θ_t; train; θ_{t+1}; **retain**
    ★ 在固定训练过程下更新参数

(d) Improver update（改进器更新）★ 唯一构成"递归"的
    Revise the update process; I_t revise/test; I_{t+1}; **retain**
    ★ "An accepted change to the improver I is retained and governs a subsequent
       task-system update ΔS_{t+1}."

★ 论文的边界声明（原文）:
  "These analytical patterns may coexist and **do not form a capability ranking**;
   persistent or meta-level changes alone do not establish sustained recursive gains."
```

### 2.4 ★★ 三个经验主张（§3.4，全文最可操作的一节）

```text
★ 三个观测量，回答三个不同问题:

(1) 任务增益  Δ_t = Q(S_t; D_test) − Q(S_0; D_test)                    (式5)

(2) 保留与迁移  ρ_{t,j} = Q(S_t; D^test_j) − Q(S_{t_j}; D^test_j)        (式6上)
                τ_t     = Q(S_t; D^test_new) − Q(S_0; D^test_new)       (式6下)
    ★ "The reference checkpoint t_j is **predeclared**; ρ_{t,j} < 0 indicates a loss
       relative to it."
    ★ "**Neither positive Δ_t nor positive τ_t isolates the improver.**"

(3) ★★ 改进器增益（配对探针，式 7/8）—— 这是最关键的设计
    令 S⁺(I; S, B) = 改进器 I 在预算 B 内从**同一**起始求解器 S 选出的后继
    g(I; S, B) = E[ Q(S⁺(I; S, B); D_test) − Q(S; D_test) ]            (式7)
    Γ_t(B) = E_{S~P_start}[ g(I_t; S, B) − g(I_0; S, B) ]              (式8)
    ★ "Positive Γ_t with appropriate uncertainty supports a **stronger improver**
       under that probe. **Controls must match starting states, feedback access and
       resource accounting.**"
    ★ "The expense of obtaining I_t is additional and belongs in an end-to-end comparison."
    ★ 共享状态警告: "If solver and improver share inseparable state, a swap can change
       both roles; component ablations then support a **narrower claim**, and the
       coupling must remain explicit."

★ ★ 加速的更强要求（原文，一句）:
  "Even increasing task scores over a finite horizon **do not demonstrate accelerating
   improvement**: that stronger claim requires **gains per unit cost over longer horizons,
   without changing the criterion that defines success**."
```

### 2.5 ★ 六族重叠机制（§4.2）

```text
① Parameters and data
   参数更新内化生成/选中的经验; 数据与任务更新改变例子/课程/任务生成策略
   ★ "Their classification must keep the **generator, acceptance criterion and trainer
      separate**. Learning a task proposal policy does not imply learning the rule that
      trains that policy."

② Memory and skills
   持久文本/图/潜状态/可执行库, 不必改骨干
   ★ ★ 关键区分（原文）: "A stored record belongs to the **solver** when it guides task
     execution and to the **improver** when it guides diagnosis or update selection;
     the same record can serve both."
   ★ "Changing a memory's **contents** and changing its **management algorithm** are
     separate interventions."

③ Prompts, programs and agent harnesses
   文本指令/工具/编排代码
   ★ "A recursive call graph describes execution; **it does not by itself show that an
     improved artifact survives to the next task**."

④ Feedback and evaluation
   判官/critic/测试/奖励模型决定循环接受什么
   ★ "Self-rewarding and meta-rewarding make this role explicit, but **actor and judge
     can share the same parameters**."
   ★ "Feedback quality should be measured against an **independent reference**, and its
     effect on downstream updates tested separately."
   ★ "A changed evaluator can **alter the scale** on which apparent progress is reported."

⑤ The improvement process ★ 递归所在
   "A prompt that generates mutations, a program that edits programs, a memory-management
    policy or a learned workflow designer can all act as an improver."
   ★ "These functional labels overlap with the state carriers above: an improver may be
     stored in **weights, code or context**."
   ★ "The relevant evidence traces the changed object into the **next update**."
```

### 2.6 ★★ 评估协议（§7，Figure 7 四面板）—— 最直接可用

```text
(a) Multi-round update  t = 0..T−1
    继承已接受状态 → Propose → Candidate X̃_t → Validation V 用 I_t → accept? → X_{t+1}
    拒绝/回滚: 保持 X_t, 入 archive

(b) Independent test（所有 run 结束后）
    封存测试 + 固定评估器, 审计**预声明调度**选出的 checkpoint
    ★ "**No test feedback to updates, acceptance, or checkpoint selection.**"
    报告: gain / transfer / cost / variance / regressions
    ★ "rather than assuming monotonic progress"

(c) Fixed-budget controls
    Full RSI B  vs  Frozen improver B  vs  No-update search B
    ★ "Same start, data and total cap; count search, checks and failures;
       downstream gain at equal cost"

(d) Improver ablation
    Evolved I_t  vs  Initial I_0, 施加到**同一** held-out solver S
    ★ "Same start, data and total cap Δ; count search, checks and failures;
       Downstream gain at equal cost"
```

### 2.7 ★ §5 自动设计基础设施（逐节，第 6 轮深读）

```text
§5.1 Learning Pipelines and Task Curricula
   ★ "Its output should be judged by the **successor it trains**, rather than the fluency
     of its synthetic data."
   ★ 核心张力（原文）: "tasks should be solvable enough to yield feedback and diverse
     enough to extend capability. **Raising difficulty alone can eliminate the learning
     signal.**"
   ★ 硬要求: "A **fixed independent test distribution** is needed to separate better
     learning from a task generator's changing preferences."
   ★ 三簇机制: Scheduling（89-93）/ Co-evolution（94-99）/ Population & multi-agent（100-105）
     ★ "a harder task pool and a more diverse population are **not interchangeable**
        measures of learning opportunity."
   ★ grounding 第二轴: "Verified problem construction, learned critics and solver–verifier
     interaction differ in **who can certify an answer**."
   ★ ★ 关于判据（关键，直接对应 DWC）:
     "Constitutional principles, model preferences and process supervision supply different
      forms of feedback. Their external information differs: **a human-written principle, a
      reference answer and a tool outcome cannot all be counted as an absence of supervision.**
      Changing an internal judge is compatible with RSI, but **independent task checks must
      remain outside the criterion it can rewrite**."
     ⇒ ★ 这正是 DWC 原则 1 + JUDGE_LAYERS 纪律 2 的同一句话。

   ★ 三选: "how to represent a design, how to allocate roles and communication, and
     whether to train the designer."
   ★ 表示法的权衡（原文）: "A natural-language program admits broad edits but **can hide
     interface changes**; a graph exposes dependencies but **constrains the operators
     available**."
   ★ ★ 对照要求: "Useful comparisons therefore report **both the artifact and the state
     of its designer**."
   ★ "Model heterogeneity, population size and communication density must remain
     **separate budget variables**."
   ★ ★ 持久性账目: "A topology selected for one query and a trained policy for selecting
     future topologies have **different return paths**."

§5.3 Algorithms, Search Operators and Reusable Design Knowledge
   ★ ★ 判据（一句定音）: "A fixed search engine can produce a substantially better algorithm.
     **That result becomes evidence about recursive improvement only when the discovery
     also changes later search or the model that conducts it.**"
   ★ ★ 常见局限: "a high validation score can reflect **specialization to the search
     population**. Held-out artifacts, tasks and starting programs test different kinds of reuse."
   ★ "Their transfer should be tested on **new combinations**, not inferred from library size."
   ★ ★ 代理评估的陷阱: "A proxy can reduce search cost while **misranking** the eventual

   ★ ★ Highlight（原文）:

      discovery improves the designer, retain the relevant change and measure the next
      search on **new starting systems at a matched budget**."

   ★ ★ 继承物是什么（原文）: "The important inherited object is an **executable finding
     together with its evidence and conditions of use**, rather than the research report alone."
```
