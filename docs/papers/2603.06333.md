## 1. 问题

### 论文自己承认的缺口

1. **RSI 从理论进入实现，但缺少可验证的对齐保持机制。** §1 原文："What remains missing is a principled, verifiable mechanism for ensuring that such self improvement does not introduce subtle misalignments that compound across cycles."
2. **它给出了一个判定"改进是否真实"的反例式论据**：§1——"A system that improves its code generation capability by 10 percent but simultaneously becomes 15 percent less truthful has not actually improved in any meaningful sense."（**注意：这只是修辞性举例，不是实验数据。**）
3. **漂移是多层的，且四层相互作用。** §1 列出 semantic / lexical / structural / distributional 四类漂移，称 "These four dimensions interact in complex ways, and detecting them requires methods that can operate across all of them while remaining computationally efficient and theoretically grounded"。
4. **参数不应手调。** §1/§7："all parameters in our framework are derived from data distributions and information theoretic principles rather than arbitrary choices. Drift thresholds are learned during calibration phases... Component weights are optimized to maximize detection accuracy. Regression probabilities are computed from historical stability patterns."
5. **它要画一张前沿。** §7 把 Capability Alignment Ratio（CAR）列为贡献之一，定位为"capability–alignment trade-off"的量化框架。

### 论文没有承认、但读完发现缺口更严重的一处

**贡献列表里的第二个构件"constraint preserving loss"在全文没有定义任何损失函数。** 全文 "loss" 只出现 4 次：§1 与 §7 的 "constraint preserving loss that maintains safety properties"（名词性提及）、§6 同一措辞、以及 Appendix E.1 里另一个无关的 "alignment loss"。而 Appendix C.3 给出的实际机制是 **prompt 级惩罚**："we apply explicit penalties for constraint violations in the improvement prompts... we highlight those violations in the prompt provided to the model for the next cycle."

同样地，**θ_c → θ_{c+1} 的生成机制全文未定义**：全文 "fine-tun*" 0 命中、"gradient" 0 命中、"weight update" 0 命中、"LoRA" 0 命中（唯一近似命中是 "thresholds" 的子串）。Appendix A.2 只写 "Feedback derived from these evaluations... is used to construct an improvement prompt; the result of applying that prompt yields the improved model θ_{c+1}"。**这意味着 SAHOO 报告的全部增益，其"改进动作"是黑箱。** 这一条必须进入 DWC 的评估结论。

## 2. 核心机制

### 2.1 形式化（Appendix A）

任务三元组 **τ = (π, 𝒞, ℳ)**：π 为自然语言 prompt/题面，𝒞 为解必须满足的约束集合，ℳ 为定义正确性的参考解。
模型 θ 收 π 产 y = θ(π)，沿**三个维度**评估：**质量 𝒬(y)**、**约束满足 CPS(y)**、**对齐/漂移 Δ(θ₀, θ_t)**。

递归过程按周期 c = 0, 1, …, C_max 推进（Eq.1–4）：

```
y_c        = θ_c(π)                                  (1)
𝒬_c        = 𝒬(y_c, ℳ)                                (2)
CPS_c      = CPS(y_c, 𝒞)                              (3)
Δ_c        = Δ(θ₀, θ_c | baseline)                     (4)
```

**关键设计（Appendix A.2 明确写出）**："Note that drift is measured with respect to the initial model θ₀ rather than the immediately preceding model; this yields a cumulative measure of deviation and prevents short-term, high-variance cycle-to-cycle changes from masking long-term drift."

### 2.2 三项对齐稳定性要求（Appendix A.3）

- **Drift Boundedness**：GDI 全程低于学到的阈值 τ_gdi；
- **Constraint Preservation**：CPS 全程保持 1 或近 1，**任何显式约束违反都是直接的对齐破坏**；
- **Regression Prevention**：量化"回到更早低质量状态"的概率并设上界，高风险时暂停。

### 2.3 Goal Drift Index（Appendix B）—— 四信号 + 学出权重

四个分量全部落在 [0,1]：

| 分量 | 公式（原文编号） | 定义细节 |
|---|---|---|
| Semantic Δ_semantic | (1 − s_cos)/2　**Eq.8** | s_cos = ê₀·ê_t，ê = e/(‖e‖+ε)，e = embed(y) 为**均值池化 hidden state**；"0.5 represents orthogonal embeddings" |
| Lexical Δ_lexical | JSD(P₀‖P_t) = ½KL(P₀‖M) + ½KL(P_t‖M)，M = ½(P₀+P_t)　**Eq.9** | token 频率分布上的 Jensen–Shannon 散度，选它是因为"symmetric and bounded" |
| Structural Δ_structural | (1/K)·Σ_{k=1..K} min(1, \|s₀^{(k)} − s_t^{(k)}\| / (s₀^{(k)}+ε))　**Eq.10** | 结构特征向量 s = (长度 l, 行数 n, 是否含代码块 c, …)；min 保证有界（"even with response length doubling"） |
| Distributional Δ_distributional | W(P_baseline, P_current)　**Eq.11** | **1-Wasserstein 距离**，需维护近期 response embedding 缓冲区 |

合成（**Eq.12–13**）：

```
GDI = w_s·Δ_semantic + w_ℓ·Δ_lexical + w_st·Δ_structural + w_d·Δ_distributional
w_s + w_ℓ + w_st + w_d = 1,  各 w ∈ [0,1]
```

**权重学习（Eq.14）**：

```
w* = argmax_w  Σ_{i=1..N_cal} AUC( GDI_i(w), y_i^drift )
```

y_i^drift ∈ {0,1} 是"该响应是否发生实质漂移"的**专家标注**标签。

**阈值学习（Eq.15）**：按任务类型选 F1 最优阈值 `τ*_GDI = argmax_τ F1(GDI_τ, y^drift)`。
**置信区间（Eq.16）**：bootstrap B 次重采样（token 分布与 embedding 样本），取 0.025 / 0.975 分位。

### 2.4 约束保持（Appendix C）

约束分类为 Format / Content / Logical / Ethical 四类；评估方式"both automatic checking (for format and simple content constraints) and learned evaluators (for semantic constraints)"。

```
CPS = (1/K)·Σ_{k=1..K} 1[ 𝒞_k(y) = true ]        (17)
```

**CPS 是硬指标**（原文："Notably, CPS operates as a hard metric: either a constraint is satisfied or it is not. This ensures that alignment preservation requirements are not compromised through soft relaxation."）。
**C.3 分级惩罚**：违反的约束在下一周期 improvement prompt 中被显式列出并要求修复；"Violations of ethical constraints receive higher attention than violations of format constraints."
**C.4 硬停**：任一周期 CPS = 0 立即停止整个改进过程。

### 2.5 回归风险（Appendix D）—— 全文最可复用的一段

```
R_c = Pr( 𝒬_c < 𝒬_max − δ  |  H_c ),   H_c = {𝒬_0, …, 𝒬_{c−1}}     (18)
```

三个统计量：
- **Volatility**：σ = std(H_c)　**(19)**
- **Trend**：最小二乘拟合 𝒬̂_t = α + β·t　**(20)**
- **Volatility-normalized gap**：z = (𝒬_c − 𝒬_max)/(σ + ε)　**(21)**——"how many standard deviations the current value lies below the historical peak"

高斯近似（**Eq.22**）：

```
R_c ≈ Φ( (𝒬_max − δ − 𝒬̂_{c+1}) / σ )
```

趋势校正（**Eq.23**）：

```
R_c^adj = min{ 1,  R_c + 1{β < −ε_trend}·λ·|β| }
```

决策：`R_c^adj > τ_R` 告警并考虑暂停；τ_R 由校准（例如验证期观测风险的某个百分位）选出，"can be adjusted to reflect organisational risk tolerance"。

**长时程稳定性界（D.5, Eq.24）**：若每周期增量 Δ𝒬_i ~ N(μ, σ²)（**独立且同分布**），则"未来 c 个周期全部为正增量"的概率为 (Φ(μ/σ))^c。论文举例：每周期 0.6 的改进概率，10 周期后 0.6^10 ≈ 0.00605（约 0.6%）。

### 2.6 Capability Alignment Ratio（Appendix E）

```
CAR_c    = (𝒬_c − 𝒬_0) / GDI_c                                  (25)
CAR_inc,c = (𝒬_c − 𝒬_{c−1}) / (GDI_c − GDI_{c−1})                  (26)
```

CAR 大 = 每单位对齐退化的能力收益高。E.3 决策规则：CAR_inc,c 大 → 继续；小或为负（"drift without improvement"）→ 停止或回滚。
**实施注记**：分子分母用 EMA 平滑；分母加下界 ε 防数值不稳；**与 D 节回归风险合成复合停止规则**。

### 2.7 停止规则（§3，五条，约束违反绝对优先）

1. 连续三次迭代质量变化 < 0.01；
2. 回归风险超过校准阈值；
3. 任一周期约束保持为 0；
4. 达到最大周期数；
5. GDI 超过校准阈值。

### 2.8 理论（Appendix G）

- **Proposition 1（Lipschitz 连续性）**：若 Δ = Σᵢ αᵢΔᵢ、αᵢ ≥ 0、Σαᵢ = 1，各 Δᵢ Lipschitz 常数 Lᵢ，则 L_Δ = Σᵢ αᵢLᵢ（Eq.27）。
- **Proposition 2（渐近漂移界）**：在 |Δ_c − Δ_{c−1}| ≤ L_Δ|Δ𝒬_c| 与独立性假设下，**E[Δ_C] ≤ Δ₀ + L_Δ(μC + O(σ√C))**（Eq.28）——μ>0 时至多线性增长，μ≈0 时 O(√C)。
- **Definition 1 + Proposition 3（收缩区）**：L_Δ < 1 时 `lim E[Δ_c] = L_Δ·μ/(1 − L_Δ)`；L_Δ ≥ 1 时线性化递推预测不稳定。

### 3.3 分项发现（§4，全部论文自报）

- **约束违反**：代码域与数学域 **0 次**；真实性域 **170 次**，分布在 63 个任务上（均值 2.70/任务，"non-uniformly distributed"）。违反类型构成：**fabrication 91（53.5%）> overconfidence 48（28.2%）> system-call 式输出 15（8.8%）**。§4 另给任务级比率："fabrication prevention incurred 91 violations (28.2% task-level rate), overconfidence constraints 48 violations (15.0%), and system-call restrictions 15 violations (4.8%)"。
- **回归**：3,780 个周期（189 × 20）中共 **170 次回归事件（4.5%）**；**其中 117 次集中在单个任务**（双峰振荡）；剔除该离群任务后回归频率降至 **0.7%**，远低于主要风险阈值 **0.803**。170 个任务（**89.9%**）零回归；受影响任务的中位数为 2 次。
- **稳定性**：均值 0.825、SD 0.068；**189 个任务中仅 3 个低于 0.70**，均经人工核实为非典型条件（训练数据不足或双峰行为）。GDI 轨迹线性斜率均值 **0.0509**；**121 个任务中性或负趋势、68 个正漂移**。
- **收敛**：§4 正文为"173 of 189 (91.5%) 达到收敛判据，mean convergence cycle 8.2, SD 4.1"，16 个任务触及最大周期；分域 code 7.1 / math 8.9 / truthfulness 10.4。
- **不收敛任务的早期预警**：16 个不收敛任务"mean time to threshold breach of **4.5 cycles**（median 5）"——§5 称"humans have early warning and opportunity to intervene before drift becomes severe... perhaps as important as drift prevention itself"。
- **CAR 前沿**：最优前沿聚集在高质量（≈0.65–1.00）与低漂移（≈0.20–0.50）；"quadrant with drift 0.50 and quality 0.65 corresponds to costly alignment trade-offs"。CAR 初期接近 1.0，在**第 2–3 周期**衰减到约 **0.6–0.7** 后稳定。
- **置信精度**：平均区间宽 0.084（±0.042），"Even the widest intervals remained within ±0.15 of the critical threshold of 0.44"。

### 3.4 负面结果与诚实项（论文自述）

- §5 承认 **truthfulness 提升"harder and more drift-costly"**（+3.8%、CAR 0.60），并建议部署方"may need more conservative thresholds or more intensive human oversight"。
- §6 承认依赖显式约束规格（"hard to write for many ethical or value laden properties"）、真实性检查需人工（引入 "evaluator drift risk"）、**测量的是相对基线的偏离——"if that baseline is already misaligned our framework measures drift from misalignment rather than drift from true alignment"**。
- Appendix F.2 追加两条：**任务分布漂移需重校准**；**对"专门设计来规避漂移检测"的对手不鲁棒**（"A system specifically designed to evade drift detection might succeed"）。
- Appendix H 的部署建议中有一条值得 DWC 直接注意：**保守周期上限 5–7 周期**即可拿到大部分收益（"most valuable improvements occur in the first few cycles"）；人工复核建议**每 10–20 周期一次**。

## 4. 它假定了什么（挖隐含前提）

1. **假定"改进"存在但不可见。** 整篇论文测量的是"改进之后有没有漂移"，从不检查"改进是否真的由那个动作造成"。θ_c → θ_{c+1} 未定义（见本报告 §1 末），因此**所有增益都是观察性关联，不是因果归因**。
2. **假定基线 θ₀ 大致对齐。** Appendix F.2 明说："The framework is most useful when the initial model's behavior is reasonably aligned."——这是把最难的问题（基线本身就错）排除在适用范围外。
3. **假定质量可测。** 𝒬 依赖 pass@1 / accuracy / exact match，即**必须有可自动判分的真值源**。DWC 的记忆底座恰恰没有这种统一真值（母巢 5 个 P0 缺陷同根因）。
4. **假定约束可写成谓词。** CPS 的硬性（Eq.17）建立在 𝒞_k(y) 可判定之上；对"记忆是否仍然有用"这类性质，本文的 CPS 无定义。
5. **假定高斯独立同分布。** D.5 的 (Φ(μ/σ))^c 与 Eq.22 的正态近似都要求"per-cycle increments are independent Gaussian random variables with identical distribution across cycles"。**而实测数据里最需要预测的那一类（117 次双峰振荡）恰恰违反这个假设**——它不是同分布噪声，是多模态。
6. **假定漂移可分解为四个可加信号且各落在 [0,1]。** Proposition 1 的证明是"各分量 Lipschitz + 非负线性组合"，但 GDI 的**经验有效性**只由 Eq.14 的 AUC 最大化支撑，而 AUC 最大化**不保证加权线性组合是良好检测器**。
7. **假定 54 条人工标注足以定 4 个权重。** 校准集的漂移标签由专家标注；论文声称权重"generalize across task types"（四域同权重），但**没有报告 AUC 数值、没有报告交叉验证、没有报告留出验证**——"maximize detection accuracy" 这句话本身在正文里没有任何数字支撑。
8. **假定 18 个任务的阈值可迁移到 189 个任务、20 个周期。** 论文自己警告过需重校准（F.2 Task Distribution Shift），却把校准集扩到主实验的 9.6%（18/189），且主实验复用同一批基准（HumanEval/TruthfulQA/GSM8K 的同分布子集）——**这是同分布校准，不是外部验证**。
9. **假定人工监督始终有效。** §6 末："Critically, for very high capability or potentially deceptive systems the assumption that human oversight and intervention remain effective may break down, meaning this paper should be treated as **a necessary but insufficient mitigation**."（论文自己的定级。）
10. **单作者、单代码库、单模型。** SS 承担全部方法/实验/分析/图表/写作；代码仅以 GitHub 仓库名给出，**正文未描述任何实现细节**（推理框架、embedding 模型来源、约束检查器的具体实现、prompt 模板均未报告）。

## 5. 可迁移到 DWC 的点 / 不可迁移的点

> DWC 当前状态：`README.md` 记 "代码 0"，`src/dwc/` 尚未建立；`scripts/gate.py` 已有 7 道可执行门（定位门 / 真值门 / 活性分层门 / 生灭配套门 / 声称-实测分离门 / 加减平衡门 / 静默可见门）。**因此下面的"接口"是给 DWC 前向定义的落点，不是对已有代码的描述。**

### 5.1 可迁移（每条给出具体接口）

**① 四信号漂移分解 → DWC 的 drift 模块（服务"自我强化"轴）**

- **搬什么**：Appendix B 的四个 Δ 分量 + Eq.12 的非负加权合成。**关键优势是它只需要"基线 vs 当前"的成对观测，不需要任务真值源**——这一点恰好绕过母巢 L2 的困境（漂移测量不是"是否成功"的判断，不需要外部真值）。
- **DWC 接口**：`src/dwc/selfevolve/drift.py`
  ```python
  class GoalDriftIndex:
      def __init__(self, weights: DriftWeights, tau: float): ...
      def update(self, baseline: TrajectorySample, current: TrajectorySample) -> DriftReport: ...
  # DriftReport{semantic, lexical, structural, distributional, gdi, ci_low, ci_high}
  ```
- **DWC 侧的四个分量怎么取**（这是可直接落地的映射）：
  - semantic：记忆写入/读取决策的 hidden-state 均值池化余弦距离（沿用 Eq.5–8）；
  - lexical：记忆条目与 prompt 的 token 分布 JSD（Eq.9）；
  - structural：**记忆底座调用的工具序列 / 上下文拼装形状**（等价于 Eq.10 的"组织结构"）；
  - distributional：同一检索 query 在 N 次采样下的返回分布 1-Wasserstein（Eq.11）。

**② Eq.23 的趋势校正回归风险 → DWC 任何"接受一次改动"之前的门**

- **搬什么**：D.2/D.3 的三统计量（σ、β、z）+ `R_c^adj = min{1, R_c + 1{β < −ε_trend}·λ|β|}`。这是 DWC 目前最缺的一块：**DWC 接受一次自我强化改动时，没有"这次改动会不会被后面的改动吃掉"的量化判据**。
- **DWC 接口**：`src/dwc/selfevolve/regression.py`
  ```python
  def regression_risk(history: list[float], delta: float, eps_trend: float, lam: float) -> float: ...
  ```
  接到 `scripts/gate.py` 的**门 4（生灭配套门）**作为淘汰判据的一部分：`|β| < −ε_trend` 且 `R_c^adj > τ_R` → 该机制候选标记 `hold`。

**③ Eq.26 的增量 CAR → DWC 的"能力/漂移效率比"**

- **搬什么**：`CAR_inc,c = Δ𝒬 / ΔGDI`，以及 E.3 的三条实施注记（EMA 平滑、分母加 ε 下界、与回归风险合成复合停止规则）。
- **DWC 接口**：`src/dwc/selfevolve/cost_of_change.py::incremental_car(...)`，用于 DWC 的**机制采纳决策表**：一条新机制若 ΔGDI 相对 Δ效果过大，CAR_inc 变小 → 不采纳。**这是 DWC 母巢教训 L1（"定位外的东西不许进承重区"）的量化版本**：定位门只能靠人写声明，CAR 能给出数。
- **注意量纲警告**：CAR 的分母是漂移，GDI ∈ [0,1] 且**随周期单调累计**（Appendix A.2）。DWC 若把 CAR 用在"跨不同寿命的机制"上，会系统性偏向短寿命机制。

**④ bootstrap CI 半宽 → DWC 的"声称 vs 实测"量化版**

- **搬什么**：B.8 的 bootstrap CI（2000 次 → ±0.042）。
- **DWC 接口**：`src/dwc/evidence/bootstrap_ci.py::mean_ci(samples, B=2000)`，接到**门 5（声称/实测分离门）**：PROGRESS.md 的实测数字若 CI 跨 0，必须写 `UNKNOWN`，不得写 SUCCESS。**这是把母巢 L5 从纪律变成可执行检查。**

**⑤ 三类漂移失败签名 → DWC 记忆底座的分类维护**

- **搬什么**：§4 的违反类型分布（fabrication / overconfidence / system-call）。虽然是 TruthfulQA 语境，但**"按违反类型分类并跟踪其时间分布"这个做法**可搬：DWC 的记忆条目若出现"编造来源""过度自信的断言""越权写入"三类，应分别计数并随时间画趋势。
- **DWC 接口**：`src/dwc/memory/violation_taxonomy.py`，直接给**门 7（静默可见门）**提供分类计数（原文的 "silent spectrum 有基线, 增长即门报警" 需要分类才有基线）。

**⑥ Appendix H 的周期上限建议 → DWC 自我强化循环的默认预算**

- **搬什么**：论文实测支持"**5–7 周期**即可拿到大部分收益"（论文 §5）+"每 10–20 周期人工复核一次"（F.3）。
- **DWC 接口**：`config/selfevolve.yaml` 中 `max_cycles: 7`（默认值，可调）+ 告警节流到每 10 周期。**这是零成本、可立即执行的一条。**

**⑦ Appendix F.3 的部署清单 → DWC 的运行时要求**

- 搬什么：**Monitoring and Logging（所有周期、漂移测量、决策记录全部落盘审计）**、**Circuit Breaker Mechanisms（框架外的人工熔断）**、**Rollback Capabilities（每周期检查点）**。这三条与 DWC 的 `archive/gate_trace.jsonl` 是同一件事，SAHOO 给出的是字段清单。

### 5.2 不可迁移（写清为什么搬不了）

1. **θ_c → θ_{c+1} 的机制不可搬**——全文未定义（见本报告 §1 末）。DWC 若照搬"改进动作"，只能自己定义，而**任何 DWC 自定义版本都无法用本文数字背书**。
2. **GDI 的四个权重不可直接搬。** 它们由 54 条**人工标注**观测经 AUC 最大化学出，论文未报告 AUC 本身。DWC 若照抄 0.38/0.12/0.21/0.29，**就是在把别人 54 条标注的结论当作先验**。必须自行校准——而这正是论文 Appendix H 称为 "computationally modest" 的部分的部分：18 任务 × 3 周期。**DWC 可以做，但要承认需要标注。**
3. **TruthfulQA 式约束检查不可搬。** 论文 §6 自认需要人工评估真实性并引入 evaluator drift risk。**DWC 无标注预算**，因此"fabrication / overconfidence"两类约束在 DWC 只能降级为启发式检查，且必须按门 2 声明 `TRUTH_SOURCE = None`。
4. **Table 1 的全部数字不可作为 DWC 的性能预期。** 只有一个基座模型（Qwen3-8B）、三个基准、无消融、无重复运行、无成本报告；且 §3.5 的四处内部不一致说明数值报告的严谨度有限。**这些数字只能用于判断"该领域大致能做到什么量级"，不能用作验收阈值。**
5. **"收益来自护栏"这一因果结论不可搬。** 无消融（本报告 §3.5 第 1 条）→ **DWC 不能引用 SAHOO 来论证"加护栏会提升效果"**；只能引用它论证"护栏可测量"。
6. **收缩区理论（L_Δ < 1 → 极限漂移 L_Δμ/(1−L_Δ)）不可用于 DWC 的容量规划。** L_Δ 从未被估计或报告；Proposition 1–3 是条件性陈述，其前提（各分量 Lipschitz、增量独立同分布）在 DWC 的记忆-自我强化耦合系统里**没有理由成立**。
7. **高成本人工监督的假设不成立。** 论文部署建议依赖"每 10–20 周期人工复核"与"inter-cycle human verification for high stakes applications"；DWC 是自主系统，**这条不可迁移，只能用自动门替代，而自动门会引入 L2 所说的"自说自话"风险**。

## 6. 与其他论文的关系

**在 RSI 图谱中的位置**：19 篇里**唯一的"垂直护栏"论文**——它不产生改进，只测量改进带来的偏离。放在 `docs/RSI_PAPERS.md` 的第 V 组"契约·护栏·安全"（与 `2603.25111` SEVerA 同组）。

**与 `2603.25111` SEVerA 的关系：同组直接竞争，各自补对方的洞。** 已完成的 `2603.25111.md` §6 已写明"SAHOO 是经验性的，SEVerA 是形式化的"。补一条 SAHOO 侧的证据：**SAHOO 全程没有形式验证，只有 Eq.17 的硬性 CPS 与 Eq.27–28 的条件性不等式**；反过来 SEVerA 的契约是人写的一阶逻辑，**没有任何"契约之外行为漂移"的监测器**。两者叠起来才是完整的：契约内用 SEVerA 保证，契约外用 GDI 测偏离。

**与 `2607.12790` Who Grades the Grader（Double Ratchet）的互补关系比 SEVerA 更直接。** 2607.12790 的核心结论（据其报告）是"移除 anchor guards 会让 metric 塌缩成 always-pass 的空检测器"。**SAHOO 的 GDI 恰好是一个 anchor guard 的形态**——它的阈值 τ_GDI 由 18 个任务的人工标注定出，之后固定不动。**但 SAHOO 的锚只有 18 个任务，且四域共用同一组权重**（0.38/0.12/0.21/0.29），这正是 2607.12790 所警告的"锚太弱会被共同演化拖走"的形态。**两篇合起来给出的判读：GDI 可以当锚，但必须按任务类型分别校准并定期复核，共用一组权重是本文最薄弱的一环。**

**与 `2609.14858` Dream-RSI 的关系：目标函数 vs 护栏（据 `2609.14858.md` §6 已指出"两篇都需要目标函数，而 Dream-RSI 的 replay objective 正是一个可用的目标函数形式"）。** 补充 SAHOO 侧：**Dream-RSI 的 replay objective（质量 − 成本 + 并行度）只回答"值不值得选"，SAHOO 回答"选完会不会漂"。两者可以在同一个决策点串联：先用 CAR 判效率，再用 GDI 判安全。** 但要提醒：Dream-RSI 那篇报告指出 Dream-RSI 全文未涉及泛化/过拟合讨论，而 SAHOO 也未涉及"递归策略本身被漂移检测覆盖"——**两篇都没有覆盖"改进机制自己漂移"这一层**。

**与 `2609.26457` AIDE²（本批次第三篇）的关系：一方提供循环，一方不提供护栏。** AIDE² 的接受规则只有一条：`a*_k = argmax_{a∈a_{≤k}} g(a)`（Eq.4），**没有漂移度量、没有约束集合、没有回退判据**（其唯一的安全测量是"reward hacking 率从 55% 降到 32%"这一涌现结果，且论文自认"they do not identify which rewrites produced it"）。SAHOO 有全套护栏但缺一个真实循环。**DWC 若同时用两篇，正确拼法是：以 AIDE² 的 pub/priv 信号解耦作为接受门的前置条件，以 SAHOO 的 GDI + CPS + R_c^adj 作为接受门的后置条件。**

**与 `2608.10299` Co-Evolution 综述（本批次第二篇）的关系：综述点名的空白，SAHOO 填了一半。** 综述 §6 "Safety and governance" 明确写 "we only treat these at the level of desiderata, and do not develop concrete safeguards or protocols for them"，并列出三个特有失效模式：**evaluator exploitation、partner overfitting、diversity collapse**。SAHOO 对应前两个的部分：diversity collapse 是 §4 的双峰振荡任务（117 次回归）被框架成功标出；evaluator exploitation 是 §5 承认的 "specification gaming" 风险类别。**但 SAHOO 全文没有出现 "diversity collapse" 这一词，也没有对 co-evolution 场景做任何实验**（§7 未来工作才提到 "extension to multi agent self improvement scenarios"）。**所以准确表述是：SAHOO 是 object-level 的护栏，综述要的是 co-evolution-level 的治理，综述自己也承认这一层尚无具体方案。**

**本篇与本批次另外两篇均无引用关系（已核实）**：SAHOO 全文不含 "AIDE"、"co-evolution"、"Weco"；综述与 AIDE² 全文均不含 "SAHOO"。**三篇是独立来源，不是同一脉络的连续工作。**

**给 DWC 的一句话定位**：它是 19 篇里**唯一一篇告诉你"改进会带来什么代价、以及代价怎么量"**的论文；`2603.25111` 告诉你"输出必须满足什么契约"，本篇告诉你"离基线远了没有"。**两者的区别恰好对应 DWC 门 2 与门 4 的分工——门 2 管绝对契约，门 4 管相对退化。**
