## 1. 问题

### 1.1 它要解决的缺口（论文自陈）

§1 明确说：生物大脑有复杂的时间依赖神经动力学，而人工神经网络**故意抽象掉**神经元交互的精确时序（引 LeCun 2015、Goodfellow 2016、Wei 2022）。这个抽象虽在任务上有效，却造成"灵活的人类认知与当前 AI 能力之间的鸿沟"，并暗示"缺失了某种基础组件，可能与时间处理有关"。

论文的三句定位原文：
1. 神经网络忽略了**单个神经元的复杂度**（Abstract："Most artificial neural networks ignore the complexity of individual neurons"）。
2. **递归只是拼图的一块** —— "recurrence, while essential, is merely one piece of the puzzle. The temporal dynamics unlocked by recurrence are equally crucial."
3. 静态"快照（snapshot）"表示过于受限：从 `z^t` 投影会把它强绑定到下游任务，从而限制它能产生的动力学类型 —— **同步（synchronization）解耦了这个绑定**（§3.4 脚注 1，全文最关键的机制动机）。

### 1.2 它自己承认的缺口（§8 Limitations，原文三条）

- "The CTM uses an internal sequence, meaning **training times are extended**."
- "NLMs also increase parameter counts compared to standard activation functions, but also provide a new avenue for scaling."
- "The experiments in this paper are **preliminary and not intended to beat state-of-the-art** models tailored for performance, therefore a limitation of this paper is its **relatively limited depth of comparison** since we favored breadth to investigate the CTM's internal functionality."

Abstract 自己也说："The goal of this work is to **share the CTM and its associated innovations, rather than pushing for new state-of-the-art results**."

### 1.3 它没承认但致命的缺口（报告者挖出）

- **没有自进化/自我改进回路**。全文没有一次"agent 修改自身权重/代码/prompt 并验证改进"的循环。§8 Future Work 把 "lifelong-learning" 与 "biologically-inspired **memory and plasticity**" 列为**将来**要做的事 —— 即记忆与可塑性在本文是被承认的空白，不是已解决的贡献。
- **没有跨会话记忆**。所有"记忆"实验（Q A MNIST、parity、maze）都是**单次 episode 内**的记忆，episode 结束即清零。
- **RL 上没有优势**。§G.6.2 结论是 "In all tasks, we find that the CTM achieves a **similar performance to the LSTM baselines**"。
- **不依赖 LLM**：全文无 tokenizer、无 prompt、无语言模型，backbone 全是 ResNet / MLP / 小 CNN。

## 2. 核心机制

CTM 是一个**从零训练的神经网络架构**，不是 harness、不是记忆系统。数据流见 §3 Figure 3，伪代码见 Appendix B。

### 2.1 符号（论文 Table 2 术语表）

| 符号 | 含义 |
|---|---|
| `T` | internal ticks 数（内部计算步数） |
| `M` | memory length（pre-activation 的滚动 FIFO 历史长度） |
| `d_model` (D) | latent 状态 `z^t` / `a^t` 的维度 = **神经元个数** |
| `d_input` | attention 输出 `o^t` 的维度 |
| `d_hidden` | 每个神经元私有 MLP（NLM）的隐藏宽度 |
| `k` | synapse MLP / U-Net 深度（偶数） |
| `n_heads`, `p_dropout` | 注意力头数 / synapse dropout |
| `J_action`, `J_out` | action / output 同步表示使用的神经元数 |
| `D_action`, `D_out` | action / output 同步向量维度 |
| `n_self` | 同步采样中自配对 `(i,i)` 的个数 |
| `r_ij` | 神经元 `i,j` 之间同步的**可学习时间衰减率** |
| `S^t`, `q^t`, `y^t` | 第 t 步的同步矩阵 / attention query / 输出 |

### 2.2 机制一：内部序列维度（§3.1）

CTM 有与数据维度**解耦**的时间轴 `t ∈ {1,…,T}`（internal tick）。即使输入是静态图像，模型也沿这条自己生成的"思考步"时间线迭代精修表示 —— 不是处理数据固有序列，而是 "unfolds neural dynamics for downstream use"。

### 2.3 机制二：Synapse 模型 —— 跨神经元共享信息（§3.2, Eq.1–2）

`f_{θ_syn}` 把神经元连在共享 `D` 维 latent 空间：

```
a^t = f_{θ_syn}( concat(z^t, o^t) ) ∈ R^D              # (1) pre-activations
A^t = [a^{t-M+1} ; a^{t-M+2} ; … ; a^t] ∈ R^{D×M}       # (2) pre-activation 历史
```

- `f_{θ_syn}` 论文实测最好的是 **U-Net 式 MLP**（Appendix C.1：深度 `k`（偶数），最内层瓶颈宽度固定 16，逐层线性缩放，带 skip + layer-norm；如 `k=16` 即 8 层下 + 8 层上）。
- **`z^{t=1}` 与初始 pre-activation 历史 `A^{t=1}` 都是可学习参数**（不是零初始化）。
- `M` 经验区间：`M ≈ 10-100`（§3.2，"effective during our initial exploration"）。各实验实际用 15 / 25 / 30 / 50 / 5。

### 2.4 机制三：Neuron-Level Models（NLM）—— 每个神经元私有参数（§3.3, Eq.3, Listing 2）

每个神经元 `d` 有**自己的** MLP：

```
z_d^{t+1} = g_{θ_d}( A_d^t )
```

`g_{θ_d}` 是 depth-1、宽度 `d_hidden` 的 MLP，`A_d^t` 是该神经元**自己的 M 维 pre-activation 历史**。Listing 2 用两次 einsum 实现：

```python
weights_1 = Parameter(shape=(M, d_hidden, d_model));  bias_1 = zeros((1, d_hidden, d_model))
weights_2 = Parameter(shape=(d_hidden, d_model));     bias_2 = zeros((1, d_model))

# inputs: (b, d, M)
out = einsum('bdM,Mhd->bhd', inputs, weights_1) + bias_1
out = einsum('bdh,hd->bd',  out,    weights_2) + bias_2
```

第一个 einsum 对每个神经元从 M 步历史算出 `d_hidden` 维隐状态，第二个 einsum 压成该神经元的单个激活。**"私有权重"是关键**：neuron `d` 的 `g_{θ_d}` 与 neuron `d'` 完全不共享参数 —— 这是 CTM 参数量的主要来源。

### 2.5 机制四：Neural Synchronization 作为 latent 表示（§3.4, Eq.4–5, 10, Listing 3）

```
Z^t = [z^1 ; z^2 ; … ; z^t] ∈ R^{D×t}                # (4) post-activation 历史
S^t = Z^t · (Z^t)^T ∈ R^{D×D}                       # (5) 神经元对历史的内积
```

**定义原文**："neural synchronization is defined as the inner product of the histories of each neuron"。

带可学习时间衰减的重标度版本：

```
R^t_ij  = [exp(-r_ij(t-1)), exp(-r_ij(t-2)), …, exp(0)]^T ∈ R^t     # (9)
S^t_ij = (Z^t_i)^T · diag(R^t_ij) · (Z^t_j) / sqrt( Σ_{τ=1..t} [R^t_ij]_τ )   # (10)
```

`r_ij ≥ 0` 越大越偏向近期 tick；`r_ij = 0` 表示不衰减。**论文自陈的关键负面发现**（脚注 2）："we found that the CTM **barely leveraged this for ImageNet** but more so for 2D mazes, suggesting **task-dependent temporal sensitivities**."

### 2.6 机制五：Neuron Pairing 子采样（§3.4.1, Eq.6–8, Appendix C.2）

`S^t` 是 `O(D²)`，全算太大，故训练开始时**随机预选**两套神经元对，构成两个同步表示：

```
y^t = W_out · S^t_out                                   # (6) 输出
q^t = W_in  · S^t_action                                # (7) attention query
o^t = Attention(Q=q^t, KV=FeatureExtractor(data))      # (8) 标准 cross-attention
```

`o^t` 与 `z^{t+1}` 拼接后进入下一 tick。

Appendix C.2 的三种配对策略（**直接影响架构形态，不是超参微调**）：

| 策略 | 做法 | 表示维度 | 瓶颈强度 |
|---|---|---|---|
| **Dense pairing** | 选 `J` 个神经元，算全部 `(i,j)` 对 | `D_out = J_out(J_out+1)/2` | **强**（所有梯度必须穿过选中神经元） |
| **Semi-dense pairing** | 左 neuron 取 `J_1`、右 neuron 取 `J_2` 两个不同子集 | 瓶颈宽度 2× | 中 |
| **Random pairing** | 随机取 `D_out`/`D_action` 个**对**（允许重叠），并**故意保留 `n_self` 个 `(i,i)` 自配对** | 直接等于选的对数 | 弱（"opens up the bottleneck much more"） |

`n_self` 的用意原文：故意算 `(i,i)` 内积，是 "to ensure that the CTM could **recover a snapshot representation** if it wanted to" —— 保留退回普通 RNN 表示的退路。不同实验选择：maze 用 Dense；parity 与 Q A MNIST 用 Semi-dense；ImageNet / CIFAR 用 Random。

### 2.7 机制六：计算复杂度的递归化（Appendix H, Eq.12–17）

朴素算法每 tick 重算全部 `D²` 个内积，复杂度 `O(D²t)`。利用 Eq.(10) 的指数衰减可写成两个**一阶差分方程**：

```
α^t_ij = Σ_{τ=1..t} exp(-r_ij(t-τ)) · z^τ_i · z^τ_j ,   α¹_ij = z¹_i z¹_j    # (14)
β^t_ij = Σ_{τ=1..t} exp(-r_ij(t-τ)) ,                     β¹_ij = 1          # (15)

α^{t+1}_ij = exp(-r_ij) · α^t_ij + z^{t+1}_i · z^{t+1}_j                  # (16) rank-1 更新
β^{t+1}_ij = exp(-r_ij) · β^t_ij + 1                                      # (17)

S^t_ij = α^t_ij / sqrt(β^t_ij)
```

**不需要存储完整 activation 历史**，每 tick 每对 `O(1)`，总体 `O(D_sub) = O(D_out + D_action)`，其中 `D_sub ≪ D`。

### 2.8 机制七：双 tick 损失 —— 自适应算力的真正来源（§3.5, Eq.11, Listing 4）

最容易被忽略、但对 DWC 最有用的一节。每个 internal tick 都出 `y^t`：

```
L^t = CrossEntropy(y^t, y_true)
C^t = certainty = 1 - normalized_entropy          # normalized entropy = (-Σ p log p)/log(C)
```

**每次前向只选两个 tick 参与损失**：
1. `t_1 = argmin(L)` —— 优化"最好的"那个预测；
2. `t_2 = argmax(C)` —— 让"确定"与"正确"对齐。

```
L = ( L^{t_1} + L^{t_2} ) / 2                                                        # (11)
```

Listing 4 实现：`certainties = 1 - (entropy / max_entropy)`，`lowest_idx = losses.argmin(-1)`，`certain_idx = certainties.argmax(-1)`。

原文："Since `t_1` and `t_2` are dynamically defined **per data point**, the CTM can attribute variable compute (internal ticks) to different data points as needed **without explicit restrictions** on which tick should be used in the loss function. This effectively implements **native adaptive computation** as opposed to a post-hoc addition."

Maze 变体（Listing 5）加**自动课程**：先只对"已正确预测的路径步 + 额外 5 步"计损失，让模型从起点一格一格往后学；CTM 与 LSTM 基线**用同一个损失**（对照公平性有保障）。

### 2.9 完整流程（Listing 1 骨架）

```
kv = kv_projector(backbone(inputs))                 # FeatureExtractor
pre_acts_history = pre_acts_history_init             # (B, D, M) 可学习
post_acts_history = [z_init]                         # 可学习初值
synch_a = compute_synch(post_acts_history, "action")
for step in range(n_thought_steps):                  # T
    q        = q_projector(synch_a)
    attn_out = attn(q, kv, kv)
    pre_acts = synapses(concat(attn_out, z))         # U-Net 式
    pre_acts_history = concat(pre_acts_history[:,:,:-1], pre_acts, dim=-1)   # FIFO
    z = neuron_level_models(pre_acts_history)        # Listing 2, einsum
    post_acts_history.append(z)
    synch_a = compute_synch(post_acts_history, "action")
    synch_o = compute_synch(post_acts_history, "output")
    outputs_history.append(output_proj(synch_o))     # Listing 3
return outputs_history                               # → ctm_loss (Listing 4)
```

**重要限定**：论文明确说未做充分超参搜索（"it would require a thorough hyperparameter search ... outside the scope of this work"），且不追求 SOTA。72.47% top-1 低于同期标准 ResNet-152 水平，**这个数字只能当作"机制可行"的证据，不是能力指标**。

### 3.2 2D Mazes —— 全文最强的一组对照（§4, D）

任务刻意加难：(1) 必须直接输出动作序列（不是逐格二分类）；(2) **视觉输入禁止位置编码**。目的是强迫形成内部世界模型。

| 项 | 数值 |

| 训练尺寸 / 步长 | 39×39 迷宫，预测最多 100 步路径（类：left/right/up/down/wait，`wait` 用于补齐短于 100 步的样本） |
| 泛化测试尺寸 | 99×99（通过**顺序重复施加同一模型**） |

| CTM 参数量 | **31,998,330** |
| 数据量 | 每尺寸生成 50,000 个迷宫，train 45,000 / test 5,000（19×19 / 39×39 / 99×99 三套随代码开源） |

基线（§D.4）：LSTM 1/2/3 层 = 42,298,688 / 75,869,504 / 109,440,320 参数；FF（宽度 2048 + GLU）= 54,797,632 参数。

**结果（正文）**："The CTM **significantly outperforms** the baselines"；"FF 模型和 LSTM 难以有效学习或过拟合（§D.5 loss curves）"。
**⚠️ 论文未报告**：maze 主结果的精确准确率数值只出现在 Figure 4 的曲线图里，正文与附录正文都没有可引用的数字（Figure 4c 的 "Mean re-application count" 同样无数值）。本报告不推测。

### 3.3 机制消融 —— NLM + 同步缺一不可（§G.3, Table 4/5）

15×15 迷宫消融，四种配置**都参数匹配到约 9M**、训练 **100,000 iterations**、**2 个 seed**：

| 配置 | 参数量 | Test Accuracy (%) | Test Solve Rate (%) |
|---|---|---|---|
| **CTM**（标准） | 8,967,160 | **94.6 ± 0.7** | **65.9 ± 5.7** |
| CTM (No NLMs)（加厚 synapse 补参数） | 8,948,885 | 82.9 ± 4.4 | 35.0 ± 7.2 |
| CTM (No Synch)（query / 输出直接由 `z^t` 生成） | 8,965,112 | 85.1 ± 0.5 | 37.5 ± 0.7 |
| LSTM + Synch（用隐状态时序算同步） | 8,967,454 | 82.4 ± 0.9 | 33.8 ± 3.3 |

差距（**pp 值为本报告按 Table 5 自算**，原文只给原始数值）：CTM 比最强变体高 **9.5 pp**（94.6 − 85.1）；solve rate 高 **28.4 pp**（65.9 − 37.5）。论文结论："the combination of neuron-level models and synchronization as a representation is **key to the success of the CTM**。"

### 3.4 Parity —— 累计算术 + 可解释策略（§6, F）

- 任务：长度 **64** 的 ±1 序列，在**每个位置**输出累计 parity（不是只输出最终 parity，这是与 ACT 的关键区别）；数据在线生成，每个 batch 重新生成。
- 架构：`d_model=1024`, `d_input=512`, `d_hidden=4`, `k=1`, `n_heads=8`, `J_action=J_out=32`, **Semi-dense pairing**，**加了绝对位置编码**（唯一用位置编码的任务）。参数 4,908,706（T=1）到 6,564,514（T=100）。
- 算力：batch 64，1×H100，200,000 iterations，lr 1e-4，warmup 500。
- 结果（正文）：CTM 精度随 internal ticks 提升，"significantly outperforming parameter-matched LSTMs, which struggled with stability and performance"；"CTMs with **75 and 100 ticks could achieve perfect accuracy in some seeded runs**"。
- 策略（F.2）：10-tick 模型只能正确预测序列约一半；75-tick 模型能预测整条累计 parity 序列。100-tick 的 CTM 学会**从序列开头扫到结尾**；75-tick 的学会**反向扫描**，在最后几个 tick 一次性给出大部分位置答案 —— 论文称之为 "a form of **planning**"。
- **⚠️ 负面结果（F.6，本报告认为这是全文最重要的诚实项）**：同配置 3 个 seed，**Run 1 与 Run 3 收敛到 loss=0，Run 2 收敛到非零 loss**；三个模型学到的注意力模式完全不同。原文标题即 "Model performance varies significantly between seeds"。
- 损失公平性：CTM 用 §3.5 双 tick 损失；LSTM 用**最后一个 tick** 的交叉熵（因 certainty 损失训不动 LSTM）。

### 3.5 Q A MNIST —— 唯一直接测"记忆"的实验（§G.5）

任务：顺序看 `N_d` 个 MNIST 数字（各 `t_d` ticks）→ 交错的 index embedding 与 operator embedding（各 `t_idx`/`t_op` ticks，模 10 加减）→ 零张量 answer flag `t_ans` ticks → 输出答案。`N_d`、`N_op` 均匀采样于 1–4。

**关键设置**：记忆长度设为 3 / 30 步，而数字观测**必然落在该窗口之外** —— "the digit observations will **always lie outside of the memory length-sized window** during the answering stage. In this way, the CTM must organize its activations such that it can recall the digits at later time steps."

| 配置 | T | M | Repeats/Input | Answering Steps | 总参数 |
|---|---|---|---|---|---|
| CTM | 1 | 3 | 1 | 1 | 2,501,388 |
| LSTM | 1 | – | 1 | 1 | 2,507,218 |
| CTM | 10 | 30 | 10 | 10 | 3,413,772 |
| LSTM | 10 | – | 10 | 10 | 3,418,954 |

**结果**：
- **单 tick：LSTM 一开始优于 CTM。**
- "all three seeded runs for the CTM with 10 internal ticks per input achieved **over 96% accuracy** on the most challenging in-distribution task (performing four operations after observing four digits). In contrast, the corresponding 10-internal tick LSTM performed **at or below 21%** accuracy across all seeded runs." → **差距 ≥ 75 pp**。
- 机制归因原文："CTM **learned to memorize** what it has observed to some degree, **purely via the organization and synchronization of neurons**" —— 本文对"记忆"最实质的贡献。
- 泛化（Figure 31/32）：两者都能泛化到更多操作；CTM **边读 embedding 边算**，不等 answer flag 就输出中间结果（Figure 32 的 `((((((1-9)%10)-1)%10+8)%10-8)%10)` 逐段输出 2、1、9、最终 1）。
- 论文明确收住："We are **not claiming that the CTM can do something that the LSTM cannot**, but instead that it can learn to **use synchronization as a tool**."
- 损失：CTM 用双 tick 损失，**LSTM 用最后一个 tick 的交叉熵**。

### 3.6 CIFAR-10 vs 人类（§G.1）

- 3 seeds 平均；CTM / FF / 参数量匹配 LSTM 都用 50 internal ticks；共用 constrained backbone 以强调 post-featurization 的结构差异。
- **CTM 每步前向比 LSTM 慢 ±2.4×**，但训练更稳定、test 性能最好。
- 校准："**the CTM has even better calibration than humans**, while the LSTM follows the human under-confidence"（人类基线用 CIFAR-10H [54]，难度用 CIFAR-10D [53]）。
- 不确定性：CTM/LSTM 用 internal ticks 上平均的归一化熵，与人类反应时间趋势相似；**CTM 的难度曲线最贴近 CIFAR-10H**。
- **⚠️ CTM 相对 FF 的精确准确率 pp 差：论文未报告**（只在 Figure 21 训练曲线里）。
- 超参：`D=256`, `k=10`, `d_input=64`, `n_heads=16`, Random pairing, `D_out=256`, `D_action=512`, `n_self=0`, `T=50`, `M=15`, `d_hidden=64`；batch 512，1×H100，600,000 iterations，lr 1e-4。**LSTM 因不稳定被迫把所有实验 lr 固定在 0.0001**。

### 3.7 其他实验

- **Sorting 30 个实数**（§G.4）：**不用 attention**，把 attention 换成直接拼接来吃 30 个打乱的数；每 tick 输出长度 31 的向量（30 索引 + CTC blank），全程 CTC 损失。结果：wait time 与序列位置、以及与"前一个输出值与当前值的差（data delta）"都相关 → 内部算法依赖数据布局；并能外推到训练分布之外的正态分布。（对照：ACT [18] 排的是 15 个数。）
- **CIFAR-100 消融**（§G.2）：更宽的模型 → 神经元活动更多样（跨数据点的神经元级余弦相似度分布更紧地聚在 0 附近）；**50 internal ticks 表现最好**（不是更多更好）；"two regions of certainty"现象 —— 无论 T 多大都出现"早期 + 后期"两个高确定区，论文说 "difficult to say exactly why this emerges"。
- **RL（§G.6）**：PPO（CleanRL [64] 实现）+ CartPole / Acrobot / MiniGrid Four Rooms，全部改造成 POMDP（屏蔽位置与角速度观测 / 限制视野）。环境步数：CartPole **10M**、Acrobot **2M**、MiniGrid Four Rooms **300M**（Table 10）。CTM 跨环境步维持神经元动态，用**长度 M 的滑动窗口**算同步（避免历史涨到数千步），并维护可学习的 initial state trace。**结果：三者全部 "similar performance to the LSTM baselines"**。RL 任务的 synapse 用 2 层 FF（linear+GLU+LayerNorm），单层在导航任务上 "consistently failed to match the LSTM's average episode length"。
  - **⚠️ RL 部分的回报数字论文未报告**（只在 Figure 34 的 episode length 移动平均曲线里）。

## 5. 可迁移到 DWC 的点 / 不可迁移的点

### 5.0 先定性：它与 DWC"记忆 + 自进化"定位的关系

**直接回答：这篇论文与 DWC 两大核心能力都只有部分交集，而且交集不是它自己声称的强项。**

- **与"记忆"的关系**：CTM 提供了一种**神经层面的记忆实现原语** —— "把历史压缩成激活轨迹之间的相关性"（Q A MNIST 的 96% vs LSTM ≤21%，且数字必然落在 M 窗口之外）。这个原语的**思想**（记忆 = 时间相关结构，而非状态向量）对 DWC 有价值。但它实现的记忆是**单 episode、连续值、宽度受限**的，与 DWC 需要的**跨会话文本记忆检索**不是同一个问题。
- **与"自进化"的关系：几乎为零。** 全文没有任何自我改进回路 —— 没有 trace 积累、没有失败记忆、没有自我修改并验证。§8 Future Work 把 "lifelong-learning" 与 "biologically-inspired memory and plasticity" 列为**将来工作**，等于自认这块是空白。CTM 解决的不是"harness 自进化"，而是更底一层的"表示函数该是什么"。
- **结论：它不是 DWC 的候选机制来源，而是 DWC 的"表示层灵感 + 方法论对照组"。** 按净价值排序，最值得搬的是 5.1 的 **M1 / M2 / M3**（都是纯算法、不需重训模型）；5.2 的 N1 是硬阻断。

### 5.1 可迁移（给具体 DWC 接口）

**M1 · 双 tick 损失 → DWC 的"自评分选优"机制（最高价值，纯算法、零算力前提）**

搬什么：`t_1 = argmin(L)` + `t_2 = argmax(C)`，`L = (L^{t_1}+L^{t_2})/2`（Eq.11 / Listing 4）。

DWC 接口：DWC 每个任务 / 每轮已有多个候选轨迹（不同工具序、不同检索序、不同 draft）。落成一个纯函数：

```
DWC 接口：select_best_and_most_certain(candidates) -> 进化打分目标
  L_i = 任务 verifier 打分（0-1 或 reward）
  C_i = 1 - normalized_entropy(候选_i 的分数分布)   # 分数分布来自 verifier ensemble 或多次自评
  选两个: i1 = argmin(L), i2 = argmax(C)
  target = (L_i1 + L_i2) / 2
```

为什么值得搬：CTM 用它同时做到"优化最优预测"与"校准"，且**天然实现自适应算力**。DWC 的 A/B 进化门目前多半是"最后一名 vs 对照"的二元比较；这条纪律把它变成"最优 + 最自信"的二元平均 —— 后者直接对应 DWC 关心的"进化收益要被采信，不能是运气"。

**M2 · `certainty = 1 - normalized entropy` 作预算控制器**

搬什么：`C^t = 1 - entropy/log(C)`（Listing 4）。ImageNet 上阈值 0.8 → **多数样本在 50 ticks 中的 <10 步就可停**（§5.1）。

DWC 接口：作为推理预算停止判据 —— `continue_reasoning() = (C < threshold)`。论文直接给了阈值参照：**"约 15 步以内用 Instant 预测合理，之后改用 certainty 判断更优"**（§E.3），这告诉 DWC 该把阈值定在哪。

**⚠️ 前提标注**：此条**依赖能拿到 token 级 logprobs 或自评分布**。DWC 若走 API 且只拿文本，`C^t` 不可计算 → 需降级为"自评置信度问卷"，其可靠性**论文未验证**。若 DWC 用可拿 logprobs 的开源本地模型，此条直接可用。

**M3 · 取历史最优 tick 而非最后一个 tick → 治 DWC 的"越想越错"**

搬什么：CTM 的输出是"ticks 上的一串"，损失取 `argmin` 而非末位；§E.4 Figure 14 直接展示 **over-thinking**（先经过正确答案 tick，之后反而错）；Figure 2(b) 的正确案例则是"早期出现 sharpness 的 certainty 上升"。

DWC 接口：agent 多步推理循环里，**必须保留 best-of-N 中间结果并在超时时回滚**，而不是提交最后一步。这是可直接编码的不变式（对应 DWC 现有 gate 的 "best-so-far 快照"）。

**M4 · 机制消融必须"两两拆开"的方法论**

搬什么：§G.3 的设计 —— 把两个新机制**各自**消掉，且每个变体都**参数匹配到 ~9M**、**同 seed 数**、**同训练步数**：CTM / No-NLMs / No-Synch / LSTM+Synch。

DWC 接口：DWC 的"记忆"改造若要声称有效，消融矩阵至少要有 {记忆层, 无记忆层} × {压缩 / 表示层, 无压缩层} × {检索层, 无检索层}，每格参数与步数对齐。当前若只做"整体 on/off"，按 CTM 的标准是**不足以支撑结论**（No NLMs 82.9 vs No Synch 85.1 vs 全 94.6 —— 只消一个会漏掉另一半）。

**M5 · 用"激活方差"检测死记忆条目**

搬什么：§I 第 2 条 —— "visualizing neural dynamics enables understanding whether there are **any 'dead' neurons** (there is actually 1 of these in Figure 2(a), evidenced by having extremely little variation across data instances)"。

DWC 接口：给记忆库每条记录维护跨 episode 的"引用频次 + 贡献方差"；方差长期≈0 的条目 = dead memory，纳入 GC。这个"用动态而非静态指标检测死单元"的思路通用，不依赖 CTM 架构。

**M6 · 两条负面经验（照抄即可）**

1. **对 NLM 输入历史加 layer-norm 能强制产生更"周期性"的动力学，但性能普遍变差**（§I 第 1 条）→ DWC 任何"让记忆轨迹更规整"的归一化 hack，需先测是否掉点。
2. **"双 take" 自举浪费算力**：maze 训练早期 CTM 会"快速粗解一遍再从头慢解一遍"，随能力提升自动消失（§I 第 3 条）→ DWC 进化循环要能识别"这一轮改动会不会只是把已有能力重新发现一遍"，别当新收益计数。

**M7 · Appendix H 的 O(1) 递归（若 DWC 想实现同步表示本身）**

搬什么：Eq.(16)(17) 的 `α/β` 一阶更新。**纯标量递推、零梯度依赖**，任何 Python 环境都能实现。若 DWC 想给每条记忆记录一个"跨时间的关联强度特征"，这是最省的实现。

### 5.2 不可迁移

**N1 · 整套 CTM 架构 —— 硬阻断，不是因为"没借鉴意义"，而是因为前提不成立。**

CTM 需要 per-neuron 私有权重 + 从零训练 20 万～100 万次迭代（ImageNet 更是 8×H100 / 50 万步）。DWC 的定位是给已有 LLM 加记忆与自进化，不是训新 backbone。**A1 / A2 两条前提在 DWC 现有架构下均不成立**，"把 CTM 当 DWC 推理内核"这条路直接封死。

**N2 · 语言任务完全未验证。**

论文自己的 Future Work 第一条就是 "apply the CTM to **language modeling**"。即**零个语言实验、零个 agent 实验、零个多轮对话实验**。DWC 作为 LLM agent 的一切结论都不能从这里外推 —— 尤其不能假设"同步表示在长文本上优于普通状态向量"，因为论文在 ImageNet 上都发现 `r_ij` 衰减 "barely leveraged"（脚注 2）。

**N3 · RL 上无优势 → 对"连续交互 agent"这一类价值有限。**

§G.6.2 结论是 CTM 与 LSTM "similar performance"，CartPole / Acrobot / MiniGrid Four Rooms 全部如此。若 DWC 需要的是"agent 在持续环境里表现得更好"，CTM 没提供证据。另外 MiniGrid 用了 **300M 环境步**（Table 10），算力量级远超 DWC 可承受范围。

**N4 · NLM 与同步的增益只在 15×15 小迷宫上测过（2 seeds）。**

94.6% vs 85.1% / 82.9%（§G.3）是全文唯一的机制消融，样本量：一个小迷宫任务、2 个 seed、100k 步。**无统计检验，也没在 ImageNet / CIFAR 上重做这两个消融**。按 DWC 自己的 `VERIFICATION.md` 纪律，这是"单点证据"，不足以作为采纳依据。

**N5 · "自适应算力"不是免费的。**

CIFAR-10 实测 **±2.4×** 前向开销（§G.1）；CIFAR-100 上 50 ticks 反而优于更长（§G.2.2，论文猜是过拟合或训练不足）；maze 上 LSTM 因稳定性 50 优于 75。**在 DWC 的 API 成本模型下，"多想几步"的账要单独算。**

**N6 · 不依赖闭源模型，但也因此完全不兼容 DWC 的模型层。**

反向说明：本篇**不依赖** GPT-5 / Claude Opus 等闭源模型（这是与本语料库其他 18 篇的关键差异，那 18 篇普遍依赖闭源强模型）。代价是它停留在权重层 —— 而 DWC 的可动点在 harness 层。**层级不对齐。**

**N7 · 涌现现象（§I 的 11 条）全部是定性观察。**

"会 look around"、"会 double take"、"会改主意"、"两个区域的 certainty"、"travelling waves" —— 全部**只有视频，无量化指标、无统计**（论文自己说 "We do not assign functional meaning to these observed waves"）。**不要把任何一条当可依赖的能力来设计 DWC 机制。**

- **`2609.08183` NeoHorse-1（Agentic Post-Training + Routing Harness）** —— 唯一同样动权重层的邻居，但走"用 harness 路由产生数据 → 后训练"的路径，而非重新设计表示函数。**互补**：CTM 问"表示该长什么样"，NeoHorse-1 问"怎么用现有模型产出后训练数据"。
- **`2607.27201` MWM（心理世界建模）** —— CTM §D.6 有一整节论证"world model / cognitive map 是智能的先决条件"，并靠"禁止位置编码 + 必须直出路径"把迷宫任务设计成必须建内部地图。**两者问题意识高度同构**：MWM 从 agent / LLM 侧提出，CTM 从架构侧提出，且 **CTM 用一个具体 benchmark 把"必须有内部地图"落成了可测量的形式**（§4 Setup + §D.6）。CTM 的迷宫任务设计是 MWM 值得反向借鉴的实验设计范式。
- **`2608.10299` 共演化综述（Co-Evolution in Agentic Systems）** —— 综述的三阶段分类（Agent–Agent / Agent–Environment / Meta）在 CTM 里**几乎没有对应物**：CTM 只触及"环境"这一侧的极简形式（CartPole / Acrobot / MiniGrid 的 PPO），且与 LSTM 打平。按该框架，CTM 不构成任何一层的 co-evolution 贡献。
- **其余 harness 层论文（SAHOO / SEVerA / Self-Harness / HarnessX / ModularRSI / RRSI / AIDE² / 环境演化 / Dream-RSI / MetaRSI）** —— 与 CTM **无直接机制交集**，唯一共享的是"打分要选对样本/时刻"这一抽象模式（见 M1）。它们的验证闭环（改自己 → 测 → 保留）在 CTM 里不存在。
