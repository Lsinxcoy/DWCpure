## 1. 问题

论文开篇点出的缺口不是"世界模型不够好"，而是**世界模型建模的对象选错了**。

**(a) 三大家族的 world model 都在建模物理基底，不建模人。** 论文把现有工作分成三族并逐一点名：
- **Representation world models**（Ha & Schmidhuber 2018 World Models、Dreamer 家族、JEPA、V-JEPA 2、Dreamer 4）
- **Video-generative world models**（Sora、Genie、Genie 3、Sora 2、Cosmos、GAIA-2、OmniDreams、Matrix-Game 3.0）
- **3D interactive / spatial world models**（World Labs 的 Marble、HunyuanWorld 1.0、HY-World 2.0）

三族的共同点是："They share a default object of modeling: **the physical substrate of the world**, that is, objects, positions, geometry, motion, contact, occlusion, affordances, and perceptual continuity. They ask what the world is like and how the physical scene may evolve, **and they leave the agents in that world as just another kind of moving object**."

**(b) 缺口的可判定形式（这是本文最锋利的一句）**：论文原文——"a model that tracks the physical scene but not **what each agent knows and believes about it** predicts the wrong action for the right-looking scene"。Figure 2 的反例：她的马克杯在她不看的时候被移到柜子里。只跟踪物体的世界模型，对一个**看起来完全正确**的场景给出**错误**的动作预测。

**(c) 现有认知科学 / ToM 路线都不够。** mental-model theory、Theory of Mind、BDI agency、affective computing 都相关，但论文明确指出它们的建模单位不同：心理模型与 ToM 研究"通常聚焦于推断或评估一个心理状态"，benchmark 工作"常把问题简化为一个静态答案"，BDI 系统"通常形式化 agent 自身的实践推理"。论文自己给的对比："**MWM instead asks for a world model that contains both physical and mental state, renders a target agent's partial observation, accepts candidate actions, and simulates the next joint state.**" 并且点出关键的升维：**"mental variables are not only labels to infer; they are state variables that evolve as physical events, speech acts, observations, and social consequences unfold."**

**(d) 论文自己承认的第二个缺口（§6.1）**：现有 outcome-only 社会推理基准**不足以验证 MWM**——"a system may select the correct option from surface cues **without constructing the variables the framework claims are necessary**"。所以必须自建 process-complete 的测试床。

## 2. 核心机制

### 2.1 Property 3.1（联合状态的必要性 —— 全文的理论支点）

给定真实目标动作分布 $p^\star(a_t^\epsilon\mid s_t)$，联合状态 $s_t=(s_t^{\mathrm{phy}},s_t^{\mathrm{ment}})$：

- **纯物理表征不充分**，当存在心理成分 $s_t^{\mathrm{ment}}\neq\tilde s_t^{\mathrm{ment}}$ 使得

$$p^{\star}\big(a_{t}^{\epsilon}\mid s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}}\big)\neq p^{\star}\big(a_{t}^{\epsilon}\mid s_{t}^{\mathrm{phy}},\tilde{s}_{t}^{\mathrm{ment}}\big).\tag{1}$$

- **纯心理表征不充分**，当存在物理成分 $s_t^{\mathrm{phy}}\neq\tilde s_t^{\mathrm{phy}}$ 使得

$$p^{\star}\big(a_{t}^{\epsilon}\mid s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}}\big)\neq p^{\star}\big(a_{t}^{\epsilon}\mid \tilde{s}_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}}\big).\tag{2}$$

证明用反证：一个只观测 $s_t^{\mathrm{phy}}$ 的模型**无法区分** $(s_t^{\mathrm{phy}},s_t^{\mathrm{ment}})$ 与 $(s_t^{\mathrm{phy}},\tilde s_t^{\mathrm{ment}})$，所以它必须给两者分配同一个动作分布，而 Eq.(1) 说真实分布不同。论文指出社会场景**常规地同时实例化**这两个条件：false-belief 任务共享同一物理布局但信念不同；可见性 / affordance 任务共享相似心理目标但物理通路不同。

### 2.2 状态分解（Table 1 / Eq.5–8 的符号体系）

$$s_{t}=\big(s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}}\big)\in\mathcal{S}^{\mathrm{phy}}\times\mathcal{S}^{\mathrm{ment}}$$

$$\underbrace{s_{t}^{\mathrm{phy}}=\big(O_{t},C_{t},R_{t}^{\mathrm{phy}},E_{t}\big)}_{\text{实体 / 角色 / 空间接触关系 / 环境}}$$

$$\underbrace{s_{t}^{\mathrm{ment}}=\big(\{m_{t}^{i}\},\{m_{t}^{G}\},R_{t}^{\mathrm{ment}},\alpha_{t}\big)}_{\text{个体心理 / 群体心理 / 心理关系 / 氛围}}$$

$$\underbrace{m_{t}^{i}=\big(\mathrm{id}_{t}^{i},b_{t}^{i},q_{t}^{i},g_{t}^{i},\iota_{t}^{i},e_{t}^{i},d_{t}^{i},n_{t}^{i},c_{t}^{i}\big)}_{\text{身份/信念/注意/目标/意图/情绪/倾向/规范/行为约束}}$$

论文强调心理状态"不是直接可见的。它是一个紧凑的状态变量，summarizes the history relevant to future interpretation and action"。

### 2.3 两个计算角色（Eq.3–4）与一条三段式链（Eq.12）

$$\textsc{TargetAgent}_{\epsilon}:o_{t}^{\epsilon}\mapsto a_{t}^{\epsilon} \qquad \textsc{WorldModel}:(s_{t},a_{t}^{\epsilon})\mapsto(s_{t+1},o_{t+1}^{\epsilon})$$

$$s_{t}\xrightarrow{\ \Omega_{\epsilon}\ }o_{t}^{\epsilon}\xrightarrow{\ \Pi_{\epsilon}\ }a_{t}^{\epsilon}\xrightarrow{\ T_{\theta}\ }s_{t+1}\tag{12}$$

**关键分离**：target 是第一人称 + 部分可观测；world model 是第三人称 + 生成式。论文专门澄清"**The world model is not the agent**"——"The target may be wrong, uninformed, biased, or socially constrained; **the world model still represents the hidden variables that explain why the target's observation differs from the global state.**"

### 2.4 观察生成：视角化的 ToM 推断（Eq.13–14）

$$o_{t}^{\epsilon}=\Omega_{\epsilon}(s_{t})=\Big(\Omega_{\epsilon}^{\mathrm{phy}}(s_{t}^{\mathrm{phy}};\kappa_{t}^{\epsilon}),\ \Omega_{\epsilon}^{\mathrm{ment}}(s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}};\rho_{t}^{\epsilon})\Big)$$

其中 $\kappa_t^\epsilon$ = 感知通路变量（位置、视线、听觉范围、模态可用性），$\rho_t^\epsilon$ = 社会认知视角变量（角色、先验信念、与他人的关系、规范意识、ToM 能力）。

心理观察被拆成自观察与 ToM 推断两级（Eq.10，$\widehat m_{t,\epsilon}^{j,(\ell)}$，$1\le\ell\le L$）：

$$o_{t}^{\epsilon,\mathrm{ment}}=\Big(\underbrace{\omega_{\mathrm{self}}(m_{t}^{\epsilon})}_{\text{self-observation}},\ \underbrace{\{\widehat{m}_{t,\epsilon}^{j,(\ell)}\}_{j\neq\epsilon,\,1\le\ell\le L}}_{\text{Theory-of-Mind inferences}}\Big)$$

$$\widehat{m}_{t,\epsilon}^{j,(1)}\sim Q_{\epsilon}^{(1)}\big(m_{t}^{j}\mid o_{t}^{\epsilon,\mathrm{phy}},m_{t}^{\epsilon},R_{t}^{\mathrm{ment}},\alpha_{t}\big)\tag{14}$$

**Eq.14 被论文明确标注为 "intentionally perspectival"**：Alice 知道 Jack 期待奖杯且看到他哭 → 推断失望；Bob 知道 Jack 刚从危险中获救 → 推断宽慰。**同一物理信号 → 不同心理观察。**

### 2.5 动作分解与链式法则（Eq.15–16）

$$\Pi_{\epsilon}\big(a_{t}^{\epsilon,\mathrm{phy}},a_{t}^{\epsilon,\mathrm{ment}}\mid o_{t}^{\epsilon}\big)=\Pi_{\epsilon}^{\mathrm{phy}}\big(a_{t}^{\epsilon,\mathrm{phy}}\mid o_{t}^{\epsilon}\big)\,\Pi_{\epsilon}^{\mathrm{ment}}\big(a_{t}^{\epsilon,\mathrm{ment}}\mid a_{t}^{\epsilon,\mathrm{phy}},o_{t}^{\epsilon}\big)\tag{16}$$

条件变量是 **observation 而非 full state**——论文说这是"the formal reason MWM can represent false belief, ignorance, surprise, and socially biased action"。链式法则的两种分解序都合法；论文选 carrier-conditioned 形式，因为它匹配 **action consumption** 的方式（被观察或候选的行为先暴露其物理载体，心理内容必须条件于该载体读出）。

### 2.6 耦合转移核（Eq.17 —— 全文机制的核心）

$$T_{\theta}(s_{t+1}\mid s_{t},a_{t}^{\epsilon})=T_{\theta}^{\mathrm{phy}}\big(s_{t+1}^{\mathrm{phy}}\mid s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}},a_{t}^{\epsilon,\mathrm{phy}}\big)\cdot T_{\theta}^{\mathrm{ment}}\big(s_{t+1}^{\mathrm{ment}}\mid s_{t}^{\mathrm{phy}},s_{t}^{\mathrm{ment}},a_{t}^{\epsilon,\mathrm{phy}},a_{t}^{\epsilon,\mathrm{ment}}\big)$$

两个非对称条件是刻意设计：
- $T^{\mathrm{phy}}$ **不直接条件于** $a_t^{\epsilon,\mathrm{ment}}$："the semantic intention 'comfort Bob' **does not itself move air, change posture, or reposition objects** unless it is realized through speech, gesture, motion, or another physical carrier already represented by $a_t^{\epsilon,\mathrm{phy}}$."
- $T^{\mathrm{phy}}$ **却条件于** $s_t^{\mathrm{ment}}$：其他 agent 的隐藏目标与意图可能产生**并发反应**，影响下一物理状态。
- $T^{\mathrm{ment}}$ 同时条件于两个动作分量。

### 2.7 Mentis 六阶段管线（§5.2，Figure 5 的六个编号区）

$$x\xrightarrow{\hat s_t}\xrightarrow{\hat o_t^\epsilon}\xrightarrow{\{\hat a_{t,k}^\epsilon\}_{k=1}^{K}}\xrightarrow{\{\hat s_{t+1}^k\}_{k=1}^{K}}\xrightarrow{\{r_k\}_{k=1}^{K}}\xrightarrow{\hat k}$$

1. **StateParser** → $\hat s_t=(\hat s_t^{\mathrm{phy}},\hat s_t^{\mathrm{ment}})$（按 Figure 3/4 分类，JSON 表示）
2. **ObservationGenerator**（MWM 内的 $\Omega_\epsilon$）→ $\hat o_t^\epsilon$，**过滤掉 target 接触不到的信息**
3. **ActionParser** + target pseudo-agent → 每个 option $c_k$ 变成 $\hat a_{t,k}^\epsilon$（physical + mental 两分量）
4. **WorldStateTransitor**（MWM 内的 $T_\theta$）→ 每个候选的 $\hat s_{t+1}^k$，K 个分支并行
5. **Evaluator** → 三个归一化分数 + **safety/legality veto**
6. **Decision** → 确定性决策模块，**保持在语言模型之外**

**设计原则（§5.1）**："**Mentis should never select an answer before constructing the branch it is selecting.**" 论文强调这个原则让 Mentis 在绝对准确率不高时仍然有用——失败可被**定位到具体模块**："A monolithic answer prompt offers no such decomposition."

**Evaluator 的三个维度**（刻意映射理论）：**mental consistency**（给定其信念与目标，target 会选这个动作吗，心理后继状态是否随之而来）、**physical plausibility**（模拟结果在物质上可能吗）、**social appropriateness**（动作是否符合场景的社会关系、礼貌规范、习俗、道德约束、角色义务、任务语境）。加上二值 **safety/legality veto**，该分支价值**无论其他分数如何都归零**。评分是**比较式**的（batched comparative scoring：所有成功分支在同一个 prompt 上下文里分级 + 严格跨分支排序）；若 schema 校验失败，回退到逐分支打分。

**Target pseudo-agent 为什么是 pseudo**：它不接受例给的 option set，只把 option 变成候选分支。论文给出方法论理由："the goal is **not** to measure whether a model can generate a creative policy, but to compare given branches under a controlled action space"。概念上 Mentis 也支持 free-proposal regime（从自身观察采样 K 个候选），但论文明确"**Keeping the two regimes separate avoids a common evaluation error: confusing the quality of action generation with the quality of world-state transition.**"

### 2.8 模块接口（Appendix E，四份 typed JSON 契约）

- `current_state_s_t`：`physical_state{objects[], characters[], relations{spatial[],contact[]}, environment{time,place,region,ambient{visual,acoustic,air,space}}}` + `mental_state{individuals[{id,identity,beliefs,attention,goals,intentions,emotions,dispositions,norms,constraints}], groups[...], relations{attitudes[],role_relations[]}, atmosphere}`
- `target_agent_observation_o_t`：**target 接触不到的字段填字面量 `"Unknown"`**；高阶条目携带推断序 $\ell$
- `sampled_actions`：`{option_id, physical_action, mental_action, affected_objects[]}`
- `next_state_s_{t+1}` + `score`：`{option_id, physically_plausible, mentally_consistent, socially_appropriate, relative_rank, veto, reasoning}`

论文说"the deeper commitment is not JSON itself but the requirement that **the state be explicit enough for later modules to read and update**"。

### 3.6 工作点标定与统计口径

- 所有报告运行共享**单一全局工作点 = medium reasoning effort + batched comparative-rank scoring**，在**冻结的 30 条分层切片**（20 text / 7 image / 3 video）上先标定后冻结；标定切片**排除在所有报告结果之外**，论文称之为 "a pre-registration of the operating point rather than a tuned hyperparameter search"。
- 统计：**McNemar 精确检验**（Eq.31，双侧二项精确式，理由是切片上 discordant counts 小）；**Wilson score 区间**（Eq.32，"accuracy differences alone are **never** reported as significance"）。
- 成本记账：按模块与样本汇总 provider-reported token（含 reasoning tokens），**同时记录 latency 与 retry/JSON-repair 计数**，"so that an accuracy gain driven by extra calls is **never confused with** one driven by better modeling"。

### 3.7 负面结果与"未报告"项（诚实项）

- **论文未报告 LLM judge 的任何数值**：§6.2 与 Appendix G.3 定义了 $J_c$（$c\in\{\mathrm{phy,ment,sem,trans,coup}\}$，Eq.23）、**perspective-leakage rate** $\mathrm{Leak}$（Eq.24，含 answer-flip 子集）、$RWW$（right answer / wrong world，Eq.30），以及 $MAE_h$（Eq.25）、decision margin $\Delta_i$（Eq.26）、TieRate（Eq.27）、artifact presence $\mathrm{Pres}(u)$（Eq.21）、branch schema coverage $\mathrm{BCov}$（Eq.22）、run-failure rate $\mathrm{Fail}$（Eq.20）、$\mathrm{ValMargin}$（Eq.29）。**但 §7 的所有表只报 final-action F1；这些语义/结构/估值指标一个数字都没给。** 论文只说 "judge scores are **validated against human ratings** before entering any headline claim" 与 Appendix J "it makes an accuracy gain..."，**但一致性数值本身未报告**。
- **未报告**：token 成本表、延迟表、每个 run 的 run-failure rate、tie rate 数值、margin 直方图。Table 4 只给 F1。
- **未报告**：S6 与 A1/A2/A3 在 agent-level judge 上的语义分数；$C$ 谓词（Table 17 里被点名的 172 类 unsupported completion rejection 那种量级）无。
- **未报告**：MENTI-Bench 的 inter-annotator agreement / Cohen's κ（附录 F 写明做了人工重裁，但没给一致率数字；"Cohen"/"kappa" 在全文只出现在 §3.1 与 Table 12 的引文语境，不是统计一致性）。
- **有正面报告的失败面**：Appendix L 的 **7 类错误分类**（State omission / State hallucination / Perspective leakage / Action misparse / Physical transition error / Mental transition error / Evaluator error）**只有分类定义，没有任何发生率**。
- **明确自陈的局限（B.3）**："Mentis should be read as a **baseline implementation, not the final architecture**... It inherits the weaknesses of prompted LLM/MLLM modules: **sensitivity to prompt wording, schema failures, over-inference of mental states, and error propagation across stages**."

## 4. 它假定了什么（Assumptions）

把隐含前提挖出来，因为它们决定能不能搬进 DWC：

**A1（最强的一条）· 心理状态是"可写的、可检查的"，但论文自己承认它是"hypothesis-bearing"。** §5.3 原话：状态解析阶段"some mental variables are directly supported by text, speech, facial expression, or gaze, while **others are only weakly implied**. Mentis therefore treats $\hat s_t^{\mathrm{ment}}$ as a **hypothesis-bearing state**"。Appendix A 更狠："**Every mental variable a system fills in is an inference from behavior and context, not an observation.**" 也就是说：**Property 3.1 证明的是"若存在这样的心理变量则必要"，而实验只证明了"用 LLM 猜出来的心理变量有用"**。这两者不是同一个命题。

**A2 · gold process 标注本身是可用的真值源。** 全部 oracle 分析、全部 process-level 指标都依赖 $s_t^\star$ / $o_t^{\epsilon,\star}$ / $\hat s_{t+1}^\star$ 的正确性。Menti-Bench 的 gold 由作者构造、裁军、重裁（Appendix F.1），并**规定 "an *unspecified* global-state field 不罚，*Unknown* 观察字段被填则算 leakage"**。这是一个**人工判定的规范约定**，不是自然事实。

**A3 · 动作空间是 6 个给定的自然语言选项，且候选集合固定。** B.3 自陈："Its current benchmark mode also constrains the action set to annotated options, so it **does not yet evaluate open-ended policy generation**"。因此 §7 证明的是**在受控分支上的比较能力**，不是行动生成能力。

**A4 · 单步。** B.3："The **one-step** transition format is appropriate for early component analysis, but longer-horizon MWM will require memory, uncertainty propagation, model calibration, and learned transition functions." M.3 把"longer horizons"整节留给未来。

**A5 · target 是"人"且世界是"日常社会场景"。** 全部 448 条是英文、虚构、日常居住/公共/商业/机构/职场场景。Appendix A 明确："its norm judgments reflect the conventions its authors and annotators considered defensible; **they are not universal**"。

**A6 · LLM judge 可以作为语义的外部读数。** 但 paper 声称 judge 与人工评分相关过，未给数字（见 3.7）。**在这个意义上它并不满足 DWC 的 L2（自我评价必须从系统外部来）**——judge 是 LLM，仍然在系统内。

**A7 · 世界状态是第三人称"全局"可得的。** Eq.13 的 $\Omega_\epsilon^{\mathrm{ment}}$ 直接用 $s_t^{\mathrm{ment}}$ 生成"这个 target 在部分可观测下能推断出什么"。这只在模拟器**拥有**真实状态时成立。真实部署中没有一个 $s_t^\star$。

**A8 · $\tau$ 的价值函数来自"被选动作的分支分数"。** 决策规则是三分量加权和 + veto，权重由 prompt 指定，**论文未报告具体权重**（只说 "The final value of a branch is a weighted combination of the three dimension scores after the veto"，以及 Appendix H 记录了标定纪律）。veto 的触发规则也没给。

**A9 · 评测是单步多选，不是长程策略。** 因此"MWM 对预测人类决策是必要的"这个结论，**其作用域是"给定一个决策点 + 6 个选项"**。

## 5. 可迁移到 DWC 的点 / 不可迁移的点

### 5.1 可迁移（给具体接口）

**① 双通道状态 schema —— 直接是 DWC 记忆记录该长的样子。**

DWC 的记忆条目现在只有 text。MWM 的 Table 11/12 + Appendix E 给出了一份**已经过标注校验的字段清单**，可直接作为 DWC 记忆记录的类型定义：

```python
# DWC 侧接口建议：src/dwc/memory/state_schema.py  (定位声明: DWC-MEM)

GoalStatus = Literal["pending", "done", "blocked"]

@dataclass(frozen=True)

    """对应 Table 11 + Appendix E 的 physical_state"""
    objects:      list[dict] = field(default_factory=list)   # id,name,attributes,position,motion_state,semantic_content

    spatial:      list[dict] = field(default_factory=list)
    contact:      list[dict] = field(default_factory=list)
    environment:  dict = field(default_factory=dict)        # time,place,region,ambient{visual,acoustic,air,space}

@dataclass(frozen=True)
class MentalEntity:                       # Table 12 的六类状态字段
    id: str
    identity: str = ""                    # name/occupation/group type/role

    attention: str = ""                   # epistemic
    goals: str = ""                       # motivational
    intentions: str = ""                  # motivational

    constraints: str = ""                 # behavioral constraints

@dataclass(frozen=True)
class MentalState:
    individuals: list[MentalEntity] = field(default_factory=list)
    groups:      list[MentalEntity] = field(default_factory=list)

```

**为什么这条可迁移而没有"有借鉴价值"空话**：它是一份**字段级契约**，不是"要建模心理状态"的口号。Table 12 的六个 Level-2 分支（epistemic / motivational / affective / dispositional / normative / constraint）是认知科学里已被使用的分类，不是本文发明的。

**② "先构造分支再决策" 的强制不变式 —— 对母巢 445 万行空账的直接反制。**

母巢 `mwm_invocation` 445 万行 + `mother_world_model.py` 124 KB 的问题是"记账 + 预测 effect 数值"，不是"模拟动作选最优"（`docs/lessons/MOTHERNODE_LESSONS.md` L5）。MWM 的不变式是可直接断言的：

```python
# DWC 侧接口建议：src/dwc/memory/branch_first.py  (定位声明: DWC-MEM)
def decide_only_after_branches(scores: dict, successors: dict, tie_break) -> str:
    """Mentis §5.1: 'should never select an answer before constructing the branch it is selecting'
    对应 DWC 的 G4 生灭门精神: 生成与淘汰同设计。
    scores[k] / successors[k] 必须都非空才允许决策 —— 否则 raise 而非 fallback ok=True (母巢 P0-3/4/5 的形状)。"""
    missing = [k for k in successors if k not in scores]
    if missing:
        raise ValueError(f"branch(s) missing score: {missing}")
    unbuilt = [k for k in scores if k not in successors]
    if unbuilt:
        raise ValueError(f"score(s) without constructed successor: {unbuilt}")
    return tie_break(scores)   # 确定性，决策逻辑在 LLM 之外
```

**③ 四通道 oracle 探针 —— 这是 DWC 记忆底座第一个"有对照的实验"的模板。**

Menti-Bench 的 O1–O4 + A1–A3 设计可以原样翻译成 DWC 记忆系统的**故障注入探针**，用来回答"DWC 的记忆到底哪一环在起作用"：

**必须照抄的一条实验纪律**：**S0 options-only floor 必须与头条数字并列报告**（S0 29.7–33.2），以及通道干预。论文原话："the options-only floor and the channel interventions **are reported alongside the headline comparisons**, ruling out gains that come from guessable options or leaked evidence."

**④ 未指定 / 未知 的二值语义 —— 对应 DWC L2 的一个现成落点。**

Appendix F.1 的两条承重约定值得直接进 DWC 的记忆写入路径：

| 标注值 | 含义 | 判定 |
|---|---|---|
| `unspecified`（全局状态字段） | 标注者**故意留空** | 预测填或省略**都不罚** |
| `Unknown`（target 观察字段） | 断言 **target 不可能知道**该事实 | 预测**填了就判 leakage** |

这是一个现成的**记忆可信度标记**，可以直接进 DWC 记忆 schema：哪些字段是"我没查到"（Unknown，可被后续证据填充），哪些是"这件事本身没定义"（unspecified，不该被填充）。**这两者混淆正是 DWC L4/L7 要防的那类静默缺陷。**

**⑤ oracle 增益的次可加性 —— DWC 进化门该有的告警项。**

论文的 +8.7（四个单增益之和）vs +6.3（四个合并）是一个可以直接搬到 DWC 自我强化门（G4/G2）里的**健全性检查**：

```python
# DWC 侧接口建议：src/dwc/evolution/gate.py 里的诊断项  (定位声明: DWC-AUTO)
def oracle_subadditivity_warning(sum_of_singles: float, combined: float) -> str | None:
    """四个单点增益之和 > 合并增益 ⇒ 上游误差向下游传播（论文: +8.7 vs +6.3）。
    DWC 含义：如果 DWC 的进化把若干条独立改进一起评出来的分相加当作可回收空间，
    它在给一个并不存在的 2.4 点做预算。必须在 PROGRESS.md 的声称栏标注。"""
    if sum_of_singles - combined > 0.2 * sum_of_singles:
        return ("EVIDENCE-CORRELATED: 单点增益严重次可加；"
                "进化预算应按合并增益计，不是单点之和")
    return None
```

### 5.2 不可迁移（写清为什么）

**① 全部性能数字依赖闭源前沿模型 —— 必须标注。**

Table 4 的八个 world-model 角色是 **gpt-5.6-sol、gpt-5.5、gpt-5.4、gpt-5.4-mini、gpt-4.1、claude-fable-5、claude-opus-4-8、claude-haiku-4-5**，经统一端点接入；另有 judge 角色与 target 角色（论文说 held fixed 但未指明型号）。**DWC 不具备同等模型条件**。因此：
- **S0–S6 的阶梯增益（+2.4/+2.3/+5.3）、A1/A2/A3 的 −12.1/−16.5/−6.4、O1–O4 的 +2.8/+1.7/+0.7/+3.5、以及 98.5 的人类参照 —— 这些都是"在前沿 LLM 上、用训练无关的 prompt 编排"测出来的。DWC 若用更弱的模型，同样的结构大概率不会产生同样的绝对增益，更不能拿这些数当 DWC 的验收阈值。**
- 可迁移的是**结构与实验纪律**，不是性能数字。这与 `2609.14858` 报告里对 Gemini-3.1 Pro 的处理是同一条纪律。

**② `Mentis` 本身整体不可迁移为 DWC 的实现。** 它是 prompt 编排 + 一次性 JSON 状态 + 单步。§5.3 自陈弱点（prompt 措辞敏感、schema 失败、心理状态过度推断、**跨阶段误差传播**），且 B.3 明说更长程需要 memory / uncertainty propagation / calibration / **learned transition functions**。DWC 若照搬，会重演母巢"结构正确、零实质"的路径。

**③ Property 3.1 的**证明**不可迁移（它的**推论**可）。** Eq.(1)/(2) 说的是"存在这样的变量则必要"。它**不**说"你用一个 LLM 提示词写出来的那些字符串就是这些变量"。DWC 若把 MWM 当成"我在状态里写 `beliefs: "用户可能困惑"` 就做到了 MWM"，就是把一个存在性命题当成构造性命题用——这正是母巢 3,808 个产物里"形状正确、零实质"（L7）的那个形状。

**④ 评测方法的一整套不可迁移。** Menti-Bench 是英文虚构日常场景、448 条、6 选 1、process gold 由作者构造与裁军，且论文自己说它"deliberately **not** a large-scale leaderboard"、"media subsets should be read as **directional**"。DWC 若拿 448 条的多选 F1 当记忆系统的验收基准，会把"prompt 编排能力"误测成"记忆能力"——论文 §6.2 第一节就是这个论证。

**⑤ 语义层指标一个数字都没报 —— 这是它自身最大的诚实缺口，DWC 不应假装它是"过程可测量"的范例。** $J_c$、$\mathrm{Leak}$、$RWW$、$\mathrm{MAE}_h$、$\mathrm{TieRate}$、$\mathrm{BCov}$ 全有定义无结果（见 3.7）。论文 §M.1 自己把"process-outcome divergence 应当单独报告、绝不被平均掉"列为**下一步**，不是本文的已完成工作。DWC 的 L7（"同输入、对照组、事后校验"三关）要求的是**实测**；这篇论文在语义层只有设计没有实测。

**⑥ 长时间程 / 不确定性 / 自适应深度的部分全是"未来工作"，不可当结论用。** §M.2 与 Table 17 明确：learned transition、error-aware interface、calibrated uncertainty、adaptive ToM depth、hybrid symbolic-latent state、pruning —— 这些**一项都没实现**。特别是"维护心理变量的分布或排序假设 + 校准 + 不确定性感知弃权"（Table 17 "Unknown mental states" 行）——DWC 若不做这层，M.3 的安全论证（"biased toward asking rather than asserting"）就落空。

## 6. 与其他论文的关系

**在 RSI 图谱里的位置**：**这不是一篇 RSI 论文**。19 篇里绝大多数改的是"改进机制本身"（harness / evaluator / environment / meta-search / memory）。2607.27201 改的是**世界模型的建模对象**——它把"state 里有什么"当作被设计的东西。这是一条正交的轴，而且它恰好正对着母巢的病：母巢有世界模型的**行**（445 万行台账）没有世界模型的**内容**（`_world_model_simulate` / `_verify_world_model` 零实现）。MWM 是这批论文里**唯一一篇把"状态里必须有 X 类变量"写成形式化必要性命题（Property 3.1）的**。

**与 `2607.27924` ODEWorld 的关系：同一层（世界模型）的两条互补路线，一静一动。**
- 2607.27924 问的是"**时间怎么流**"——把离散时间换成物理时间连续流，学 latent velocity field，预测 = ODE 积分。
- 2607.27201 问的是"**状态里放什么**"——把物理状态扩成物理-心理联合状态，预测 = 分支模拟 + 价值评估。
- **两者不冲突，可叠**：MWM 的 $T_\theta^{\mathrm{ment}}$ 完全可以实现为 27924 那种连续流，而 27924 的 $z_t$ 完全可以承载 MWM 的 $s_t^{\mathrm{ment}}$。**但要注意 27924 的 E（Limitations）自己写了：它"does not incorporate action conditioning and primarily focuses on video generation"** ——也就是说 27924 现在还没有 $a_t$ 这个维度，因此**还不能直接当 MWM 的转移核**。
- **两者的失败诊断可互为镜像**：27924 说它最大的失败是"**模拟基准不够真**"（附录 B：single-agent trajectory generation 缺少真值）；27201 说它最大的失败是"**转移模拟不准**"（O4 +3.5 最大单项 oracle 增益）。同一族论文的两种病灶。

**与 `2608.24876` Recuris 的关系：状态-行为耦合 vs 状态-技能耦合，是同一根轴的两端。**
- 27201 的 `ObservationGenerator` **过滤 target 接触不到的信息**（perspective leakage 是它的一类错误）。
- 24876 的 checker $C_{k,g}$ **拒绝没有被工具回执支撑的完成声明**（"Invoking a skill or attempting a tool call is **not** completion evidence"）。
- **两者是"证据门槛"这一原则的两种形态**：27201 把它用在**世界状态的可写性**上，24876 把它用在**工作记忆的可提交性**上。24876 还在另一个维度上走得更远——它让**状态 schema 本身（$W_k$）可被进化**，而 27201 的 mental taxonomy 是手写且固定的（§M.2："the hand-written JSON schema, which was the right instrument for a first study, will need hybrid symbolic-latent successors"）。
- **规模完全不同**：27201 = 448 条 / 6 选 1 / 单步 / 1 个决策点；24876 = 4 个长程基准 / 最多 200 步 / 完整轨迹。**24876 的命题（"经验只有在被决定调用时才值钱"）与 27201 的 Proposition 3.1（"联合状态是必要的"）在"状态决定行为"这一点上同构。**

**与 `2609.13406` GAI 的关系：grounded 判据的一个具体实例。** 13406 的 Dial 2 问"评估所依据的标准是否 grounded"（内容来自系统外**且** base 本身在 agent 之外）。27201 的 MWM 里有一个**恰好同形**的结构：$\rho_t^\epsilon$（社会认知视角：角色、先验信念、关系、规范意识、ToM 能力）**在 agent（target）之外**，而 $\omega_{\mathrm{self}}$（自观察）在 agent 之内。**但 27201 并没有把这一点形式化为一个判据**——它是四套系统（$s,o,a,r$）里唯一没有任何 authority boundary 声明的。**这是 27201 相对 13406 的结构性弱点**：13406 能说清楚"什么在 agent 外"，27201 只能说"world model 在 target 外"。

**与 `2609.14858` Dream-RSI 的关系：27201 的 $s_t^{\mathrm{ment}}$ 正是 Dream-RSI 那个 world model 该有的内容，Dream-RSI 缺的正是 27201 给的。**
- 2609.14858 已经有 `docs/papers/2609.14858.md` 的判断：它是"记忆的第二个消费者 = replay simulator"，并警告"若把它包装成'我们有了世界模型'，就是重演母巢 445 万行空壳的路径"。
- 27201 恰好给出**那个世界模型该往里填什么**（Table 11/12 的字段清单）+ **一个可判据化的必要性命题**（Property 3.1）。**换句话说：Dream-RSI 给了消费端，27201 给了内容规格，母巢两头都没有。**
- 但要诚实：**27201 的 $T_\theta$ 是 prompted LLM，Dream-RSI 的 replay 是经验回放**。27201 自己也说未来要"learn the physical and mental transition from annotated successor states"（§M.2）。**在 DWC 里，replay simulator 提供的是"评估策略的场"，MWM 提供的是"场里的状态该长什么样"——两者是不同层的东西，不能互相替代。**

**与 `2607.12790` Double Ratchet（Who Grades the Grader）的关系：一条"判据互锁"的隐含对偶。** 2607.12790 的核心是"怀疑评分本身"；27201 的 Appendix A 说 "**none of our results should be read as evidence that a language model has a Theory of Mind**"、语义判断 "are not measurements"、且必须"keep them contestable: a person should be able to see, question, and correct what a system assumed about them"。**两篇在"不要把模型的内部读数当成真值"这一点上是同一立场的两个版本**，但 2607.12790 把它做成了机制（co-evolving rubric），27201 把它写成了伦理声明（且没有实现任何效度检验）。
