## 1. 问题

论文开篇第一句就是它的问题："When we speak of recursive self-improvement (RSI), **are we speaking of a phenomenon, a mechanism, or a prospect?**"

它诊断的核心缺口有三层：

**(a) 术语被滥用，缺的是判据而非又一个例子。**
论文原话："RSI is being claimed at many scales, while no single framework that formally describes these emerging instances exists... **What is missing is a criterion rather than another example**: a way to say which systems improve themselves, and what changes once they do."
它点名了这个混乱：Self-Refine/Reflexion（改自己的输出）、STOP/Gödel Agent/DGM/SICA（改自己的代码级实现）、AlphaEvolve/AI Scientist（固定 evaluator 下搜程序）、Red Queen Gödel Machine（**共同演化评判标准**）、Schaul（**连标准都不要**）。这些跨度极大的系统都被叫 RSI。

**(b) 古典对应物已有理论，递归侧没有同等范围的。**
迭代策略改进的正式框架是 **GPI**（generalized policy iteration，Sutton & Barto §4.6）：在有限 MDP 中 evaluation 与 improvement 的交替收敛到最优策略。**但 GPI 成立的前提是"update principle 与 evaluation base 都在 agent 之外"。**递归情形下它们不在。而"GPI 的保证如何一条一条地在自指化时失效"，**没有同等射程的账户**。

**(c) 现有术语没有让这些过程显式地位于一条连续体上。**
论文原话："Existing terminologies, such as Gödel agents, meta-learning, and agentic loops, do not make explicit that these processes live on one continuum."

**它自己承认的第二个缺口（§1 末）**：现有做法"keep some component fixed outside the loop, be it model weights, a prompt template, an outer loop, or a verifier; the agent then improves within, but not beyond, that fixed mechanism, so **the attainable quality is bounded by it**"。论文把这些称为 **bounded self-improvement**，与 strong RSI（"a system improves the mechanism that will carry out the next round of improvement", Zhang 2026）区分开。

## 2. 核心机制

### 2.1 经典起点：GPI

$$V^{\pi}(s)=\mathbb{E}\big[\textstyle\sum_{t\ge0}\gamma^{t}\,r(S_t,A_t)\,\big|\,S_0=s,\;A_t\sim\pi(\cdot|S_t)\big]$$

GPI 的循环（Fig.1）：
- **evaluation**：$V \to V^{\pi}$（把价值推向与当前策略一致）
- **improvement**：$\pi \to \mathrm{greedy}(V)$（把策略推向在当前价值下贪婪）

**"generalized"的含义**：两步都不绑定具体实现。evaluation 可以是 Bellman backup、TD 更新、Monte-Carlo，或任何把价值估计推向与策略一致的算子；improvement 可以是 greedy，也可以是 softmax、truncated，或任何产出"被当前价值偏好"的策略的算子。

### 2.2 Definition 1 (System and Agent) —— 五个组件

世界保持为 MDP $\mathcal{W}=(\mathcal{S},\mathcal{A},p,r)$，写 $G$ 为**外部目标**。"Both belong to the environment, and neither is part of the system itself."

$$\chi^{\star}\in\operatorname*{arg\,max}_{\chi\in X}\;\mathbb{E}\Big[\textstyle\sum_{t\ge0}\gamma^{t}r(S_t,A_t)\,\Big|\,\chi\Big]\qquad(\text{Eq. }1)$$

**"This objective is fixed by the world and the goal alone, not by the system itself."**

系统定义为五元组 $\chi=(\pi,V,m,U,\rho)$，组件集 $\mathcal{O}=\{\pi,V,m,U,\rho\}$，内容空间 $\mathcal{C}_o$，系统位于 $X=\prod_{o\in\mathcal{O}}\mathcal{C}_o$：

| 符号 | 名称 | 类型 | 作用 |
|---|---|---|---|
| $\pi$ | **policy** | $\mathcal{S}\to\Delta(\mathcal{A})$ | 选择世界动作 |
| $V$ | **action critic** | $\mathcal{S}\to\mathbb{R}$ | 评估 $\pi$ 表现多好 |
| $m$ | **modifier** | $X\to\Delta(X_{\mathrm{Ag}})$ | **提议系统应该如何改变** |
| $U$ | **modification critic** | $X\to\mathbb{R}$ | 评估提议的改动是否服务于 $G$ |
| $\rho$ | **evaluation base** | — | **critics 据以度量的标准** |

$\mathrm{Ag}\subseteq\mathcal{O}$ 是构成 agent 的组件集；agent instance 是一个赋值 $\xi\in X_{\mathrm{Ag}}$；$\chi[\xi]$ 表示"把 $\chi$ 的 agent 部分换成 $\xi$"得到的系统。

**论文关键的工程性论断**：$\mathrm{Ag}$ 的成员**随系统而变** —— $\mathrm{Ag}=\{\pi,V\}$ 当 modifier 固定时，$\mathrm{Ag}=\{\pi,V,m,U,\rho\}$ 当系统连 modifier 和评估标准都能重写时。

> **Remark 1（世界中的目标 vs 自设任务）**：有系统让 agent 自设任务/问题/目标。论文把它当作**特定形式的自改进**处理，因为"such self-set tasks remain **subordinate to an external goal** that is objective and cannot be edited by the agent"。

### 2.3 Definition 2 (Generalized Agent Iteration)

一个 GAI 是交替两个作用于系统 agent 部分的过程：
- **Agent evaluation**：在用的 critic 对着 evaluation base $\rho$ 给 agent 部分打分，**policy 层用 $V$，agent 层用 $U$**
- **Agent improvement**：modifier 产出新 agent instance，$\xi\sim m(\cdot\mid\chi)$，系统采纳，$\chi\leftarrow\chi[\xi]$

**Figure 2**：policy / critic $V$/$U$ / modifier $m$ / evaluation base $\rho$ / environment and goal 构成一个环，环上**恰好一条 authority boundary**（与 06396 的 kernel 是同构的形状）。

### 2.4 两个 dials（框架的全部判别力）

**Dial 1：改进 agent 的机制是否在 agent 内。**
- $m\notin\mathrm{Ag}$ → 内容固定，$m$ 是外部改进机制 → GPI
- $m\in\mathrm{Ag}$ → 系统可重写自己的 modifier，**recursion closes at $m$ with no external meta-layer**

**Dial 2：改进据以度量的标准是否保持 grounded。**
论文给 grounded 的定义（**这是全篇最关键的一句话**）：**"An evaluation is _grounded_ when its base draws its content from outside the system, the world and the goal, AND when the base itself lies outside the agent."** 两个条件并列。
- 内容来自外部但 base 在 agent 内 → 会随系统自己的编辑移动
- 无任何外部内容 → 除了自一致性外不约束循环

### 2.5 GPI 与 RSI 作为两个实例（Eq. 2 / Eq. 3）

**GPI（anchored 实例）**：$\mathrm{Ag}=\{\pi,V\}$，$m\notin\mathrm{Ag}$，$m$ 的内容固定为两个算子 $\mathcal{E}_m$ 与 $\mathcal{I}_m$：
$$V\leftarrow\mathcal{E}_m(V,\pi;\rho_V)\quad\text{(evaluation)},\qquad \pi\leftarrow\mathcal{I}_m(V)\quad\text{(improvement)}\qquad(\text{Eq. }2)$$
$U$ 在场但**未被行使**（因为 $m$ 固定，没有替代修改被打分）。

**RSI（self-modifying 实例）**：$\mathrm{Ag}=\{\pi,V,m,U\}$，
$$\begin{aligned}\text{policy update:}\quad & V\leftarrow\mathcal{E}_m(V,\pi;\rho_V),\quad \pi\leftarrow\mathcal{I}_m(V)\\\text{agent update:}\quad & \xi\sim m(\cdot\mid\chi),\quad \chi\leftarrow\chi[\xi],\quad m'\leftarrow(\xi)_m,\quad U'\leftarrow(\xi)_U\qquad(\text{Eq. }3)\end{aligned}$$
**"The second line is the recursion itself"** —— $(\xi)_m$ 与 $(\xi)_U$ 是提议中的 modifier 与 modification-critic 槽位，所以下一个 modifier 和下一个 critic **由当前那个产出**。

### 2.6 自一致性条件（reference ideal，Eq. 4）

记 $\rho_U(\chi,\xi)$ 为 base 对"从 $\chi$ 采纳 agent instance $\xi$"赋的值：
$$\text{agent evaluation:}\quad U(\chi)=\mathbb{E}_{\xi\sim m(\cdot\mid\chi)}\Big[\rho_U(\chi,\xi)+\gamma\,U\big(\chi[\xi]\big)\Big]\qquad(\text{Eq. }4a)$$
$$\text{agent improvement:}\quad \operatorname{supp}m(\cdot\mid\chi)\subseteq\operatorname*{arg\,max}_{\xi\in X_{\mathrm{Ag}}}\Big[\rho_U(\chi,\xi)+\gamma\,U\big(\chi[\xi]\big)\Big]\qquad(\text{Eq. }4b)$$

**论文反复强调这是 characterization conditions, not enforced updates**："they describe the internal structure a self-improver must have, and **no external mechanism guarantees them**."

### 2.7 Dial 2 的三态：polarity（Table 2）

| Polarity | $\rho$ 的状态 | 后果 | 代表系统 |
|---|---|---|---|
| **Anchored** | 外部内容，$\rho\notin\mathrm{Ag}$，agent 无法重写 | 朝固定外部标准改进 | Gödel machine、STOP |
| **Goal Drift** | 外部内容，但 $\rho\in\mathrm{Ag}$，agent 可重写 | 标准本身可被重写 → 自改进可能漂离外部目标 | Red Queen Gödel Machine |
| **Fully Self-Referential** | 无外部内容：空的，或 $\rho$ 依赖 $U$ | 无外部信号进入自改进循环，critic 方程退化为内部自一致性 | Socratic learning（Schaul, 2024，**position paper**） |

> **Remark 2 (learned proxies)** —— 这条 Remark 对 DWC 极重要：**"An external judge or reward model is anchored, whatever data it was trained on: the dial asks where the standard sits, not how faithful it is to the goal. A proxy can be anchored and still be satisfied without serving the goal; the same judge as an agent component is the Goal Drift case."**

论文明确："In current practice, **most demonstrated self-improving systems fall into the Anchored row**; the two lower rows are so far represented mainly by **boundary cases and by position papers**."

### 2.8 Table 3：现有系统在两个 dial 上的定位

| 系统 | $\mathrm{Ag}$ | Dial 1 | Dial 2 → 分类 |
|---|---|---|---|
| Policy/value iteration, PPO | $\{\pi,V\}$ | no; $m$ 是固定更新原理 | Anchored; 环境 reward → **(Anchored) GPI** |
| Fixed outer loops | $\{\pi\}$ | no; 循环由设计者固定 | Anchored; 外部目标/验证指标 → **(Anchored) GPI** |
| Gödel machine | $\{\pi,m\}$ | yes; 证明成功时改写程序 | Anchored; 固定外部 utility + proof gate → **Anchored RSI (guarded)** |
| Gödel Agent, DGM, STOP, SICA, Polaris, Hyperagents | $\{\pi,m\}$（harness；权重与基准在外） | yes; 改 prompt/记忆/工具/代码 | Anchored; 外部 benchmark → **Anchored RSI** |
| Red Queen Gödel Machine | $\{\pi,m,U\}$ | yes; 同时重写 agent 与 evaluator | **Goal Drift** → **Drifting RSI** |
| Closed-system proposals (Schaul) | all components 含 $\rho$ | yes; 可改任何组件 | **Fully Self-Referential** |

> **Remark 3 (language agents as model and harness)**：**"The harness, holding prompts, memory, tools, and control flow, is what a modifier changes; the weights and the evaluation benchmark stay outside the admissible set."** ← 这句话是 06396 的五槽 $\mathcal{H}$ 的形式化先声。

### 2.9 四条缺陷（Table 4）—— 本篇最可用的部分

论文说 GPI 的经典保证依赖两个条件：**改进步廉价且单调** + **目标与评估工具都在 agent 之外**。递归可放弃两者。

| 缺陷 | 触发条件 | 违反的 GPI 条件 | 状态 |
|---|---|---|---|
| **Search over candidate selves** | Dial 1: $m\in\mathrm{Ag}$ | 改进是廉价且单调的 | **Structural; observed** |
| **Self-evaluation** | Dial 1: $U\in\mathrm{Ag}$ | 评估者站在被评估物之外 | Structural |
| **Ungrounded base** | Dial 2: $\rho_U$ not grounded | 目标从 agent 外部被评估 | Structural |
| **Goal Drift** | Dial 2: $\rho_U\in\mathrm{Ag}$ | 同一条件，随 base 被重写而丢失 | **Structural; observed** |

**§5.1 的核心论断**：改进步是 Eq.4b 里的 argmax，取遍一个**无界内容空间**，**没有任何一般程序能决定哪个候选最好**。Gödel machine 的 proof gate 是既定 workaround（只允许能证明收益的重写），其统计变体给同一 gate 加风险预算（Wu et al. 2025, SGM）。
评估丢失的相关理由：**当 $U$ 是 agent 组件时，被评估的对象与评估工具重合，且它报告的价值本身可修改**。"A system can still restrict itself, as the proof gate does, but **the restriction is then part of its content, not an external constraint**."

**§5.2 的两个后果（ungrounded base）**：
1. 自一致性条件**不唯一确定系统**，且容纳"服务 $G$ 很差或根本不服务 $G$"的成员；
2. **不给 faithfulness 保证**——自一致的系统可以一边报告改进一边移动它据以报告的标准，"since calibrating $U$ and honoring $\rho_U$ are **choices of content, not properties enforced from outside**"。
早期形式类比：**Ring and Orseau 的 delusion box**（2011，agent 改自己的输入后发现可以脱离世界的配合就满足标准）。

**Minimal Example（同一个标准的三种放置）** —— 这段是全篇最锋利的：
coding agent 的 modification critic 按"通过的测试比例"给改动打分，modifier 提议提升该比例的改动。同一构造在**三种** base 放置下都满足自一致性条件：
- 测试 held out 且固定 → 报告的改进追踪"产出可用代码"的目标 → **anchored**
- 测试放在 agent 自己的仓库里 → 允许一种"改测试本身"的改进 → **Goal Drift**
- 换成 agent 自己判断什么算改进 → 依赖 critic 自身 → **fully self-referential**
**"The conditions hold in all three; only the first serves the goal."**

**§5.3 Goal Drift 是更难察觉的那个**："the objective keeps its name, and a system that reports progress against it need not track it." 形式对应：Everitt et al. (2016) 的 agent 能改自己的 utility function **无害 only when its value function anticipates the rewrite and evaluates the future with the utility it currently holds**；Hibbard (2012) 为 model-based utilities 保住了该条件。两者都把"标准的固定性"变成**要争取的东西而非默认**。

### 2.10 四条限制（§6，论文自陈）

1. 定义**不含可达性或复杂度断言** —— "writing that an agent instance is drawn from the modifier states what is chosen, not that the choice is reachable or affordable."
2. **不建模时间尺度** —— 世界动作与 agent 更新之间的交替按**步**计数，不按算力。
3. 实际防护（proof gate、coding benchmark）被当作**外部机制**；"whether a guard should itself be an agent component is a design choice we leave open."
4. 框架描述**无人干预运行**的系统；人类审查/回滚在形式化之外 —— "although in practice **a human still sets the direction and reviews the result**"。

**论文预先回应一个反驳**："recursive self-improvement is not simply an MDP over configurations. An MDP fixes its transition law and its reward outside the agent, whereas here the next configuration is drawn by a modifier inside the agent, and the standard of evaluation may be inside it as well."

**三个待做的定理目标（§6 From Catalogue to Results）**：
1. 自一致性条件的解集**未表征**：它容纳多少解、何时其中一个服务目标，**仍然开放**；
2. RSI → GPI 的归约**是散文而非带明确假设的命题**；
3. 系统内部的 monitor 能否判定其自身 modification critic 的 faithfulness —— "it is the one question we would expect to require a **self-reference argument rather than a construction**"。

## 4. 它假定了什么（挖隐含前提）

1. **假定世界与目标可以被形式化为 MDP 且在分析期间固定。** Eq.1 之后："we hold both fixed in what follows, since such changes originate outside the system and leave the analysis below unaffected." **这是假定"外部目标不漂移"** —— 而 §5.3 说的 Goal Drift 恰恰是漂移发生的情形。论文说漂移是 agent 造成的（目标本身不动），但**目标被外部方悄悄改掉**的情形，形式化里没有位置。

2. **假定"外部"是一个清晰的边界而非连续谱。** Dial 2 的 grounded 定义要求"内容来自系统外 **且** base 在 agent 外"。但 RAG 系统从世界检索内容写入 agent 记忆，评估基准则读 agent 记忆——**content 与 base 的归属在这个例子中是混合的**。论文没有给出混合情形的判据。

3. **假定 agent 的成员集 $\mathrm{Ag}$ 是清晰可判的。** Remark 3 把 agent = harness、权重与基准在外。但当代 agent 里，记忆既是 scaffold 的一部分（可改），又是下一轮的输入（不可无痕改）。**$\mathrm{Ag}$ 的划分是分析者的选择，不是系统的性质。**

4. **假定 modification critic $U$ 与 action critic $V$ 是两个可区分的角色。** 定义上它们是同一个 $\mathbb{R}$ 值的两个来源；在多数实际系统中"评估策略"和"评估改动"由同一个 LLM 用同一个 prompt 模板做。**论文承认实例可以"leave some of them unused"，但没讨论角色合并。**

5. **假定 Eq.4 的自一致性条件是"正确"的表征。** 论文自己说这是 characterization 而非 enforced，并且**解集未表征**。因此**"满足自一致性条件"不蕴含"这是个好系统"** —— Minimal Example 正好证明了这点（三种都满足，只有一种服务目标）。

6. **假定 proof gate 之类的防护可以作为系统外部存在。** §6 限制 3 明说"whether a guard should itself be an agent component is a design choice we leave open"。**但如果防护在 agent 内，它就是 Table 4 的 Goal Drift 触发条件。** 论文没有解决这个张力。

7. **假定"提升极性"是连续谱上可排序的三态。** Table 2 按"残留多少 anchoring"排序：Anchored → Goal Drift → Fully Self-Referential。**但 Remark 2 承认一个 anchored 的 judge 可以被满足而不服务目标** —— 所以"极性"与"是否真的服务目标"是两个正交维度，Table 2 把它们压在一列里。

8. **假定人类方向的设定与审查可以先搁置。** §6 限制 4 承认"a human still sets the direction and reviews the result"，但形式化不含人类。**这对 DWC 是关键**：DWC 的项目形态本身就是人类在设定方向。

9. **假定 formalism 的价值在于"可把现有系统放在同一坐标上"。** §5 的 Table 4 明确："it records where the classical guarantees end, **not how far self-improvement can go**." 缺陷清单是**收敛的而非穷尽的**（"The list is short by design"）。

## 5. 可迁移到 DWC 的点 / 不可迁移的点

### 5.1 可迁移（每条给出具体接口）

**① 五个组件的分类学 —— DWC 应该照它给自己的组件分类** ——
- 搬什么：$\chi=(\pi,V,m,U,\rho)$。DWC 的现状（记忆 + 自进化两大能力）可以直接映射：
  - $\pi$ = DWC 的执行策略（prompt + 调度）
  - $V$ = DWC 的评估器（召回率基准、验收脚本）
  - $m$ = DWC 的改进器（当前为空，PROGRESS.md 明写"承重代码 0 行"）
  - $U$ = DWC 的"改动评估器"——**DWC 目前没有这个独立角色**
  - $\rho$ = DWC 的 evaluation base ——**这正是 PROGRESS.md 问的"系统外的真值源是什么"**
- **价值**：一次显式的五元盘点，能立刻暴露 DWC 缺哪两个角色。**DWC 的核心问题"系统外的真值源是什么"在这个框架里就是 $\rho$ 的 grounded 定义。**

**② grounded 的双条件定义 —— 这是 DWC 真值源设计该抄的判据** ——
- 搬什么：**内容来自系统外（世界与目标）** 且 **base 本身在 agent 外**。两个条件是 **and**，缺一不可。
- DWC 接口：DWC-MEM 的可复现召回率基准若由 DWC 自己的记忆内容生成，它满足条件 1 但违反条件 2 → 按论文定义是 **Goal Drift**。
- **可落成一个 gate 断言**：`{Q*, T_seal, release_rule, L} ∩ W_i = ∅ ∀i`（与 06396 的 Eq.30 同形，但**论证出处不同**：06396 是设计选择，13406 是**从 GPI 保证失效推出的必要性**）。
- 这给了 DWC 一条**论证依据**：不是"我们决定保护测量"，而是"不保护则 Eq.4b 的 argmax 无界搜索失去唯一判据（Table 4 第一条缺陷）"。

**③ Remark 2（learned proxies）—— 直接命中 DWC 的记忆真值源难题** ——
- 搬什么：**外部 judge / reward model 不管训练在什么数据上都是 anchored；判别标准问的是"标准坐在哪里"，不是"它多忠实于目标"。**
- DWC 含义：**不要用"评估器准不准"来判断真值源合法性，要用"评估器在不在可写面内"来判断。** 一个弱评估器 + 密封 = 合法；一个强评估器 + 在可写面内 = Goal Drift。
- 这条让 DWC 的真值源设计从"如何造一个好的评估器"（工程问题）转为"如何保证评估器不可写"（结构问题）。

**④ Table 4 的四缺陷作为 DWC 的风险清单** ——
- 搬什么：四条缺陷，每条标注触发 dial 与被违反的 GPI 条件。
- DWC 接口：DWC-AUTO 每次加机制前先问"我触发的是哪一条"。典型误判：**DWC 若让改进器改自己的提案策略** = 触发"Search over candidate selves"；**DWC 若让记忆检索器参与"什么算好记忆"的判定** = 触发"Self-evaluation"。
- 论文给的诊断工具可直接用：**观察到的证据是"继续搜索的搜索中 78.26% 以更差的分数收尾"**（引自 RSIBench-Data）。**DWC 若发现自己的循环也这样，那就是命中了缺陷一，不是"还没调好"。**

**⑤ Minimal Example（三个 base 放置）作为 DWC 的设计评审模板** ——
- 搬什么：同一构造，三种 base 放置，自一致性条件都成立，只有 anchored 那种服务目标。
- DWC 用途：任何"让系统自己判断改动好不好"的设计（DWC 的记忆自评估、经验自评分）都应被当作 Goal Drift 或 fully self-referential 候选，**而不是当作"更好的自动化"**。这是一个具体的评审问题，不是空话。

**⑥ Table 3 的分类作为 DWC 自我定位工具** ——
- 搬什么：$\mathrm{Ag}$ 成员 + Dial 1 + Dial 2 三列。
- DWC 用途：DWC 应能诚实回答"我改了什么、改进器在不在 $\mathrm{Ag}$ 内、我的 $\rho$ 在不在"三问。**按 Table 3，绝大多数已演示系统都在 Anchored 行，包括论文引用的所有 Gödel 家族。**

### 5.2 不可迁移

**① 全部数学不变量在 DWC 的当前形态下无法实例化。**
- 原因：Eq.1 的 $\arg\max_\chi\mathbb{E}[\sum\gamma^tr]$ 要求 DWC 的系统状态 $\chi$ 位于**可枚举的内容空间** $X=\prod C_o$，且改进可以用折扣回报表达。DWC 的组件内容空间（记忆条目、技能、prompt）**不可枚举**（论文自己在 §6 承认"unbounded content space"）。
- 所以：**GAI 可以当作 DWC 的诊断语言，不能当作 DWC 的实现模板。**

**② Eq.4 的自一致性条件不能用作 DWC 的验收判据。**
- 原因：论文**自己说解集未表征**，且 Minimal Example 证明满足条件不等于服务目标。把它当验收判据会给出假阳性。

**③ 四个定理目标对 DWC 无用。**
- 原因：它们都是数学问题（解集基数、形式化归约、自指论证），DWC 是工程实现。

**④ "无人干预"的框架设定与 DWC 的实际形态不符。**
- 原因：§6 限制 4 承认实际上"a human still sets the direction and reviews the result"。DWC **整个项目**就是人设定方向。论文把人类放在形式化之外，这意味着 GAI 对 DWC 的价值只在于**诊断与论证工具**，不在于设计模板。

**⑤ 引用数字（58.33% / 78.26%）不可作为 DWC 的性能预期。**
- 原因：(a) 是**转述**的他人工作，报告者未核验；(b) 来自 RSIBench-Data 的特定设置（固定目标模型 + 固定外部评估），DWC 的记忆场景不同。

**⑥ 本篇完全依赖外部工作，无自建实验。**
- 后果：**DWC 无法引用本篇的任何实测数字来支撑自己的设计选择。** 若要落地，只能引用其**定义与判据**。

## 6. 与其他论文的关系

**在 RSI 图谱中的位置**：这是 19 篇里**唯一一篇形式理论论文**。它的贡献不是系统也不是数据，是**判据**。

**前序**：GPI（Sutton & Barto 2018 §4.6，论文明确致敬："Apparently, Generalized Agent Iteration is a salute to the Generalized Policy Iteration"）；Gödel machine（Schmidhuber 2003/2007，论文称其为"the closest formal counterpart"）；Yampolskiy 2015、Nivel et al. 2013 的形式区分；Good 1965、Yudkowsky 2013、Omohundro 2008 的思想来源。

**并列/被定位**：论文自己引用了两个综述并说明差异 —— Chen et al. 2026（bounded self-refinement vs open-ended RSI，把验证信号从 formal verifier 排到 intrinsic self-assessment）与 Gao et al. 2025（按"什么在演化"组织：参数/prompt/记忆/工具/scaffold）。**论文的定位是第三个维度：把 GPI/RSI 放在同一循环上，用两个 dial 做坐标。**

**与 `2609.06396`（MetaRSI）的关系：互为理论—工程镜像，作者独立，两篇互不引用。**

| | 13406 (GAI) | 06396 (MetaRSI) |
|---|---|---|
| Dial 2 grounded 的处理 | **诊断**：不 grounded 会发生 Table 4 四缺陷 | **工程解决**：Eq.30 把 $\{Q^\star,T_{seal},release\_rule,L\}$ 排除出一切写入面，含元层 |
| 论证来源 | 从 GPI 保证失效**推出**必要性 | 从"系统能膨胀它同时被允许定义的任何指标"**推出**必要性 |

**互补性极强**：13406 告诉你**哪些保护不能省**（Table 4 每条都标了"违反哪条 GPI 条件"），06396 告诉你**怎么在代码里实现这些保护**。缺前者，06396 的 Eq.30 看起来只是设计偏好；缺后者，13406 的 Table 4 无法落地。

**与 `2609.11873`（Last AI）的关系**：11873 提出 B0–L5 的**自主性等级**（以"改进决策有多少从外部设计师转交给 AI"为判据）。13406 的两个 dials 是**正交的另一根轴**：11873 问"决策归谁"，13406 问"标准是否 grounded"。

一处**真实的技术张力**值得记录：13406 的 Table 3 把 **Red Queen Gödel Machine 归为 Goal Drift**，11873 也在 §6 讨论 RQGM 但**把它当作解决 evaluator 替换问题的方案**（"addresses this by freezing evaluators within each epoch and validating replacements against an independent ground-truth anchor"）。
- 按 13406 的定义，RQGM 的 evaluator 是 agent 组件（Table 3 明写 $\mathrm{Ag}=\{\pi,m,U\}$，"the agent and its evaluator, which co-evolve"），因此它**确实是 Goal Drift**。
- 11873 描述的"冻结 + anchor 验证"是**减轻**该缺陷的措施，但按 13406 的 Dial 2 定义，它**不改变极性**（base 仍在 agent 内）。
- **两篇合起来给出一条实践结论**：RQGM 的 anchor 与冻结是"Goal Drift 的良好实践"，但按 GAI 框架它**仍不在 Anchored 行**。这个判读差异本身对 DWC 有价值——它说明**"我们有独立的 anchor"不等于"标准不在可写面内"**。

**与 DWC 的关系总结**：GAI 给 DWC 的价值是**一套诊断语言和一条论证依据**，不是实现模板。它最锋利的一句是 Minimal Example 的结尾——**"The conditions hold in all three; only the first serves the goal."** 这句话可以直接当作 DWC 记忆自评估设计的判否标准。
