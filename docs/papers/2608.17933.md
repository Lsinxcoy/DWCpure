## 1. 问题

金融时间序列非平稳、异质，**没有单个无监督算法能在所有资产/市场状态上稳定工作** ⇒ 依赖专家选模型/设计特征/调超参。论文把"自治变点检测"重述为**在可执行科学实验上的经验搜索**（executable experiment trajectories），而非固定算法或静态 agent 工作流。

## 2. 核心机制：三算子 + 停滞判据 + incumbent-preserving 选择

### 2.1 轨迹记录（八元组）

```text
τ_k = (P, op, π_k, h_k, M_k, S_k, q_k, L_k, D_k, a_k, z_k)
      │    │   │    │    │    │    │    │    │    │    └ 修订是否停滞 z_k∈{True,False}
      │    │   │    │    │    │    │    └ 净化执行日志 ┘ └ incumbent-selection 决策 ∈{Accept,Reject}
      │    │   │    │    │    │    └ 验证分数
      └ 父集（显式谱系 — 轨迹池 𝒯 是**有向实验搜索图**, 不是无结构对话史）
```

原文逐字：*"z_k∈{True,False} indicates whether a revision has stagnated."*（§3）

### 2.2 ★★★ 停滞判据（R1 规则的论文出处 — 逐字公式）

论文 §4.2 伪代码第 20 行：

```text
z_k ← (op = Revision) ∧ (q_k is invalid ∨ q_k − q_(prev) ≤ ϵ)
```

原文补充（§4.4 附近）：*"Acceptance and stagnation are intentionally independent: a small positive improvement is accepted because it improves the incumbent, yet it is still marked as stagnant if the improvement does not exceed the meaningful-improvement threshold. Consequently, the improved experiment becomes the new incumbent while simultaneously triggering Alternative Strategy in the following non-final iteration."*

**三条可迁移判据**（DWC 口径）：
1. **停滞 ≠ 拒绝**：小幅正改进**既接受又记停滞**（两个布尔位独立）——DWC 的 `stagnant_of` 三态与之同构（R188 已实现 gain ≤ NOISE_BAND 一形态）。
2. **停滞只对 Revision 记**（`op = Revision` 前提）：Alternative Strategy / Recombination 本身**不产生停滞标记**。
   ⇒ **R188 实现的缺口**：DWC 的 `stagnant_of` 对三个方向一视同仁判停滞（verdict 失败 ∨ gain ≤ 噪声带 ∨ 无候选），**没有"只有 FORWARD/LATERAL 类的前进算子记停滞、REVERSE 类不记"这条细分**。这是 R192 起要裁决的设计点（见 §4）。
3. **invalid or ≤threshold** 二选一（不是 AND）——DWC `verdict 失败 ∨ gain≤band` 与之逐条对上。

### 2.3 ★ 算子分工（伪代码 §4.2 第 4-13 行）

```text
if k = λ (预算末步)      → op ← Recombine; P ← SelectStrongTrajectories ∪ {τ*}
else if ∃ unused stagnated revision τ_s for M*  → op ← AlternativeStrategy; P ← {τ*, τ_s}
else                      → op ← Revision;     P ← {τ*}
```

原文逐字摘要（§1/§2）：*"Revision exploits the current incumbent by refining the best validated pipeline. When revision stagnates, Alternative Strategy explores a fundamentally different modeling direction or an untried EDA-recommended detector. In the final stage, Recombination synthesizes complementary evidence from high-performing trajectories."* + *"An incumbent-preserving selection rule ensures that unsuccessful experiments ..."*

**⇒ 与 DWC 三方向的映射（控制流层面）**：
| EvoTS | DWC | 触发条件 |
|---|---|---|
| Revision（默认） | FORWARD | 无停滞 ⇒ 精化当前最优（DWC：diagnose 签名命中） |
| Alternative Strategy | LATERAL | **Revision 停滞**且存在未用过的停滞修订 ⇒ 换方向 |
| Recombination | **无对应** | 末步综合强轨迹 — DWC 第三方向是 REVERSE，语义不同 |

**⚠ 04128 vs EvoTS 的第三方向不同源**：2609.04128 §5.5 的第三方向是 REVERSE（后退），EvoTS 是 Recombination（重组）。两者只在"三算子 + 停滞换向"的**控制流骨架**上互证，**第三方向本体不同**（R188 已据实收紧过这个口径，本文再确认一次）。

### 2.4 incumbent 更新规则（第 16-17 行）

```text
if q_k is valid and q_k > q_(prev) then (M*,S*,q*) ← (M_k,S_k,q_k); a_k ← Accept
else a_k ← Reject
```

**严格大于才换**（平手保持 incumbent）——与 DWC `select_policy` 的 argmax + `no_worse_than_current`（R174）同族：没好处不动。

## 4. 对 DWC 的可迁移性（诚实边界）

| EvoTS 机制 | DWC 现状（R191 后） | 差距 |
|---|---|---|
| 停滞 = invalid ∨ gain≤ϵ（**只对 Revision**） | `stagnant_of` 三态对三方向一视同仁 | **R192 候选裁决点**：DWC 是否引入"只有前进类算子记停滞"（EvoTS 式） |
| 停滞≠拒绝（两位独立） | 已同构（R188 `stagnant_of` 与 verdict 分字段） | 无差距 |
| 末步 Recombine 综合强轨迹 | 无（第三方向是 REVERSE） | **本体差异，不移植** |
| 100% 执行成功率 | behavior 面有 REFERENCE 兜底、train 面实测 4/12 raised | 不可比（论文是 LLM 生成代码的执行率；DWC 是 RULES 表达式片段） |
