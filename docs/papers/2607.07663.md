## 2. ★★★ 验证层级（§5.2）—— DWC judge 器官的直接设计依据

**原文（逐字）**：

```text
At the top sit formal verifiers — proof checkers, type systems — which are sound
by construction: self-play theorem proving and verified skill evolution can iterate
indefinitely without accepting a false improvement [118, 82].

One step down, execution feedback — tests, compilers, benchmarks — is reliable but
incomplete: passing tests underdetermines correctness, and any fixed benchmark is
eventually gamed.

Next, learned judges — reward models, LLM-as-judge — are bounded by the judge's own
competence and are themselves optimization targets [122].

At the bottom, intrinsic signals — the model's confidence, self-consistency,
likelihood — are the cheapest and the most gameable.
```

### 四层 + 各自的失效模式（DWC 判据用）

```text
层级          信号                可靠性   覆盖   失效模式
──────────────────────────────────────────────────────────────
L4 (顶)      formal verifier     构造可靠 窄    覆盖不足（只管形式性质）
L3           execution feedback  可靠     中    underdetermined; 固定基准终被刷
L2           learned judge       有界     宽    受 judge 能力上界; 它自己是优化目标
L1 (底)      intrinsic signal    最弱     最宽  最易被 game
──────────────────────────────────────────────────────────────
★ 原文的经验规律: "demonstrated self-improvement strength tracks this hierarchy"
  ★ 但作者自我限定: "a qualitative pattern we observe throughout the corpus,
    not a measured law"   ← 必须照录, 这是自陈的非测量性
★ 三个定位例证:
  FunSearch / AlphaEvolve  → 顶层两层
  2024 负结果后存活的自精化方法 → 都是"爬了层级"的
  AI-scientist gap → "precisely a level-4 problem being attempted with level-3 tools"
```

### ★ 关键限定：层级排的是"给定目标下的信号"，目标选择在其之前

```text
"Figure 5: ... The hierarchy ranks signals given a target; the choice of target is
 prior to it rather than a rung of it (§5.4)."
```

## 3. ★★★ Mirror Loop：55% 衰减 + 一次接地恢复（§5.2 末）

**这是本篇对 DWC 最硬的一条实证。**

```text
"The Mirror Loop study iterates three providers' models through ten rounds of
 ungrounded self-critique across four task families and finds informational change
 declining 55% across iterations — recursive self-evaluation without external feedback
 yields reformulation, not progress — while a single minimal grounding intervention
 (one verification step at iteration three) restores forward movement [140]."

That is the survey's thesis as an experiment: the difference between a loop that
improves and a loop that circles is one rung of external verification.
```

### 对 DWC 的直接含义

```text
① 无外部接地的自评回路 = 循环打转, 不是进步 ⇒ DWC 的 iwm 器官不是"可选加固", 是必需
② ★ "一次验证步骤" 就能恢复 ⇒ 接地不必昂贵, 关键是**存在**
   ⇒ 对应 DWC §9 第 25 项 (f) "无新反馈对照组" 的镜像:
     DWC 必须能证明"去掉一次外部验证 → 增益消失"
③ 量化形式: 10 轮 / 4 类任务 / 3 家模型 / 信息变化衰减 55%
   ⇒ 这是 DWC 可直接对标的基线数字
```

## 4. §5.3 失败模式一：self-confirming loop（直接对应 DWC §9 第 20 项）

```text
"When generator and evaluator share weights, biases correlate. Tan et al. diagnose
 the mechanism in self-rewarding RL: confidence-coupled rewards systematically
 over-reward high-confidence mistakes, so the loop preferentially reinforces exactly
 the errors the model is most sure about [141]."
```

★ **与 Meta-Rewarding（2407.19594）互为印证**：那篇是 actor/judge 共享权重的实例，
本篇把它归为失败模式 1。**共享状态 ⇒ 偏置相关 ⇒ 循环确认。**

  while ignoring the image [53]

## 7. 可迁移条目

```text
★ M1. 四层验证层级 → DWC judge 三层设计的**外部校准依据**
   本篇 L4 formal verifier > L3 execution > L2 learned judge > L1 intrinsic
   DWC 现设计 L1 规则 / L2 语义 LLM / L3 独立最终 judge
   ★ 二者是**不同切分**（信号可靠性 vs 判定环节），不能直接对齐
   ★ 但可用本层级检查 DWC: 某条铁律/判据能否升级到形式验证层？
     · 不能 ⇒ 说明它永远受 L2 上界约束 ⇒ 必须配 L3 独立审计
     · 能   ⇒ 应优先形式化（如不变式验证）

★ M2. Mirror Loop 55% 衰减 → DWC 的**接地必要性基线**
   判据建议: DWC 应能复现"无外部接地 ⇒ 增益消失"，并给出衰减幅度
   ★ 目标数字: 与 55% 同量级才说明 DWC 的接地机制真的在起作用

★ M3. self-confirming loop → 反对 DWC actor/judge 共享状态的**论文级证据**
   原文机制: confidence-coupled rewards systematically over-reward high-confidence mistakes
   ★ 与 2609.2680 的 "Agreement can indicate consistency without establishing
     correctness" 互为印证（不同来源、不同表述）

★ M4. "改进评判器是集体答案" vs DWC 原则 12 —— **正面冲突，必须裁决**
   本篇 §5.1 列出四条改进评判器的路线（rubrics 自演化 / 自训练验证 / 评判评判者 /
   Red Queen 共演化准则）
   DWC 原则 12: judge 不得自评
   ★ 我的读法: 两者不是矛盾而是**分工** ——
     "改进评判器"改的是 judge 的**策略/提示/权重**（仍需外部评测其改进）；
     "judge 自评"是 judge 给自己打分（不可归因）。
     但这条分工必须写进 DWC，否则原则 12 会被人当作过时保守。

★ M5. BinEval 的原子二元问题分解 → DWC judge L1 的粒度参考
   "atomic binary questions whose verdicts aggregate into interpretable,
   debuggable scores"
   ★ 对应 DWC: 一次 Verdict 应由多个可独立调试的二元判定聚合而成
```

## 8. 与 2609.2680 的冲突点（★ 必须裁决）

```text
① "改进评判器"路线 vs DWC 原则 12（judge 不得自评）
   本篇 §5.1: Deep-research 自演化 rubric / 自训练验证 / meta-evaluation /
             Red Queen 共演化准则 —— 四条并行
   ⇒ DWC 原则 12 需要补一句边界, 否则与领域主流正面冲突

② 验证层级是否要求"每条判据都要尽量爬到 L4"?
   本篇说 demonstrated strength **tracks** the hierarchy
   DWC 的铁律（IRON_LAWS_DESIGN 十条）多数是运行时检查 ⇒ 停在 L3
   ★ 这不冲突（层级是"给定目标下"的排序），但 DWC 应显式声明
     "本设计的目标选择在前，层级在后"（引本篇原文）

③ 本篇说 "the AI-scientist gap is precisely a level-4 problem being attempted
   with level-3 tools"
   DWC 的进化核心正是要改"怎么改进"，目标本身在变
   ★ ⇒ DWC 的自我修改如果不能形式验证，就永远处在这个 gap 里
   ⇒ 对应 DWC §9 第 25 项 (e) "两层补丁必须区分" 的加强版理由
```
