## 1. 问题

论文自己承认的缺口有四层，逐层加码：

**(a) 领域缺口：RSI 的验证被"格式"锁死，不是被"学科"锁死。**
作者对 45 个近期自改进系统做普查：**69%** 关闭改进循环时用的是机器可免费检查的目标（测试套件、exact-match key、数值目标、多选标签）。而报告科学基准的系统**落在那 69% 之内，而不是之外**（Fig.4）。论文措辞："What such a loop certifies is restricted, benchmark-bound capability"——认证的是**受限的、基准内的**能力，不是该学科的一般能力。唯一例外是一个用 rubric 而非可执行测试关闭的代码系统 [44]。

普查在 2026 年 8 月翻倍（22 个循环 / 18 个领域 → 55 个循环 / 22 个领域），新增的 33 个循环**没有一个落在 rung 4 或 rung 5 之上**。

**(b) 机制缺口：单表面改进必然要付它看不见的代价。**
论文 Fig.3 给出三段论：a. 一次失败**不携带任何标签说明该由三个表面中的哪一个负责**；b. 每个单表面算子在自己的表面上关闭合法循环，但会 incurring 三个看不见的成本——scaffold 扩展在每次推理被**重复付费为 context**、数据放大**够不到 rollout 从未展现的能力**、训练**可能回退已持有的行为**；c. 组合序列 `扩展 scaffold → 放大它揭示的东西 → 内化进权重 → 退役该扩展` 两者都不付，第四站的下降就是归还的 scaffold 预算。

**(c) 编排缺口：跨基质的系统把顺序写死了，而不是从证据里决定。**
论文原话："Systems crossing substrate boundaries hard-wire a single order rather than deciding it from evidence, though composition across substrates is exactly where non-commutativity and redundancy appear."

**(d) 元缺口（论文的核心，也是 "Meta" 得名的来源）：改进算子几乎总是一个固定程序，所以循环改进了系统，但没有任何东西改进这个循环。**
论文原话："the improvement operator is almost always a fixed program, so the loop improves the system but nothing improves the loop."

论文由此把核心立场推到极致：**进步的单位不是模型，而是循环**（§6.8）。生产性的问题不是"怎么让模型更强"，而是"在一个从未关闭过循环的地方，最便宜地关闭一个新循环要花多少"。

## 2. 核心机制

### 2.1 被改进对象：三元组，不是 checkpoint

$$\;S = (\mathcal{D},\;\theta,\;\mathcal{H})\qquad(\text{Eq. }1)$$

- $\mathcal{D}$ = **data state**（语料、合成记录、课程）
- $\theta$ = **model state**（可训练参数与 adapters、有界的架构选择、产出它们的训练配置）
- $\mathcal{H}$ = **harness state**（执行脚手架）

论断：**"a change confined to any one of them changes what the deployed system does"**。

### 2.2 学习信号 $\sigma$：唯一的通道，且**会过期**

$$\sigma = \Sigma(\mathcal{E}),\qquad \mathcal{E}=\{(t_k,\tau_k,y_k)\}_{k=1}^{K}\qquad(\text{Eq. }2)$$

- $\Sigma$ **确定性且固定**：聚合、归因、附 provenance，输出**三层类型化对象**（outcome layer / attribution layer / model-attributed mechanism layer），**它不决定要改什么**。
- 可进入证据集的四类东西：任意保真度的 verifier 结果、系统自己的轨迹（**为它展现的 competence 而读，不只为是否成功**）、针对已证明缺口准入的外部知识、框架自身的决策记录。
- 准入门（admissible）：源自当前系统 + 每个算子可读 + **不携带"判断改动好不好"的权威**。
- 两个性质：**唯一通道**（使异质过程可比较、可交换、可组合）+ **perishable**（"a step that changes what the deployed system does invalidates every signal compiled before it, because the attempts such a signal summarizes were made by a system that no longer exists"）。

### 2.3 改进过程与预算

$$U:(S,\sigma,B)\longmapsto (\widetilde{S}, A, E, c)\qquad(\text{Eq. }3)$$

预算 $B=(\beta_{tok},\beta_{clk},\beta_{gpu},\beta_{qry})$——**四种不可互换资源**。
非对易性显式写成公式：$U_j\circ U_i(S) \neq U_i\circ U_j(S)$（Eq. 4），因为每个过程改不同组件，从而改变下一个过程读到的信号。

**保护性测量**：$Q^{\star}$（sealed evaluator）、$\mathcal{T}^{\star}$（held-out）、release rule、资源账本 $\mathcal{L}$——**全部不属于 $S$，任何改进过程不可修改**。论文的理由："without it, the quantity being maximized can be increased by editing the measurement."

**Episode**: $e=(S_0,\mathcal{T}_{adapt},\mathcal{T}^{\star},B_{tot})$。

### 2.4 目标函数（Eq. 5，四项带符号）

$$J(\Pi,\phi) = \mathbb{E}_{e\sim\mathcal{E}}\Big[\underbrace{Q^{\star}(S_T)-Q^{\star}(S_0)}_{\text{realized gain}} - \lambda\underbrace{C(z)}_{\text{cost}} - \mu\underbrace{\mathrm{Reg}(S_T,S_0)}_{\text{regression}} - \nu\underbrace{\mathrm{Gap}(\sigma,Q^{\star})}_{\text{evaluator gap}}\Big]$$

约束 $C(z)\preceq B_{tot}$。$\Pi$ = 改进过程的内部策略，$\phi$ = 产出序列的策略。
三条设计要点：① 在**发布的后继**上评估，不是历史上最好的候选（generation 与 selection 都被计入）；② 在**固定预算**下评估（单纯多花钱不算改进）；③ 依赖**配对** $(\Pi,\phi)$，所以最大化它必须同时决定"每个过程内部做什么"和"按什么顺序用"。

### 2.5 失败签名 $\varphi(\tau)$（Eq. 10）—— 类型化的诊断对象

$$\varphi(\tau) = \big(\underbrace{\chi(\tau)}_{\text{terminal cause}},\;\underbrace{\psi(\tau)}_{\text{causal role}},\;\underbrace{\mu(\tau)}_{\text{reusable mechanism}}\big)$$

**着色即权限边界**：$\chi,\psi$ 是灰色（grounded 在 trace 与 verifier report，受 schema 与 evidence 约束），**只有 $\mu$ 是模型自己的假设**。三者被所有三个算子共享 → **路由决策（§4.4）做在一个任何算子都不能为自己利益改写的对象上**。

附录 D 给出两套**按规则分配**（非模型分配）的分类法，且共享优先级序——多症状失败归因于**最早**的原因而非最显眼的：
- closed-form track：`output_protocol` / `abstention` / `reasoning_answer_mismatch` / `arithmetic_error` / `distractor_confusion` / `none`
- executable track：turn-level 有序 `invalid_tool_call` / `argument_mismatch` / `state_mismatch` / `recovery_failure` / `missing_tool_call` / `response_mismatch`；task-level `missing_validation` / `unlimited_exploration` / `missing_artifact` / `wrong_scope` / `premature_finish` / `environment_error`——**最后一个被排除在改进目标之外，因为它不是系统的性质**。

### 2.6 Loop Kernel（§4.1）—— 一个范式，七个阶段

**Definition 4.1（self-improvement operator，三条件）**：
(i) 唯一输入是编译后的 $\sigma$，从不直接碰环境；
(ii) 决定"改什么"的部分是一个策略 $\pi$，且**可变**；
(iii) 决定"改动好不好"的部分**固定、外部、且在算子的写入面之外**。

算子被完全指定为三元组：
$$U = \langle \mathcal{K}, \pi, w\rangle,\qquad w\in\{\mathcal{D},\mathcal{H},\theta\}\qquad(\text{Eq. }9)$$

$$\mathcal{K} = \textsc{Observe}\to\textsc{Diagnose}\to\textsc{Propose}\to\textsc{Validate}\to\textsc{Execute}\to\textsc{Select}\to\textsc{Export}\qquad(\text{Eq. }8)$$

- **可变异（模型驱动）只有两个**：`Diagnose`、`Propose`。模型读 $\sigma$ 与当前组件状态，归因失败，产出候选修改 + 预期效果 + 风险声明。
- **其余五个是确定性代码**：`Observe` 绑定声明的输入；`Validate` 查 schema 并**机械拒绝写入面之外的编辑**；`Execute` 在隔离工作区应用；`Select` 用固定 evaluator 与 promotion rule 打分；`Export` 发出携带 content hash / 父代 / 支持证据 / 实现成本的类型化 artifact。`Select` 和 `Export` 跑在算子写入面之外。
- **周期闭合**（Eq. 7）：$\sigma'=\Sigma(E\cup E')$，$E'=\mathrm{rollouts}(\widetilde{S},\mathcal{T}_{adapt})$ —— 导出的东西在**它自己产出的系统**上被度量，而不是它出发时的那个。
- **整个循环恰好携带一个 authority boundary**，把它切成"模型提议"和"确定性代码裁决"两段。论文强调：**切在哪是承重的，七阶段的细分不是唯一的**。

一句话概括分工："The model carries the entire semantic burden of deciding *what* is wrong and *what* to change, while deterministic code holds every authority to decide whether the change was good."

### 2.7 三个基础算子（写入面两两不相交）

| 算子 | 符号 | 写入 | 角色 |
|---|---|---|---|
| Data-RSI – amplifier | 𝖣 | $\mathcal{D}$ | 从执行经验合成已验证记录，**标出经验到哪儿为止** |
| Harness-RSI – scaffold | 𝖧 | $\mathcal{H}$ | 在 typed patch 下编辑五槽脚手架，不碰权重 |
| Model-RSI – internalization | 𝖬 | $\theta$ | 有界训练配方，把 recurring context 成本换成一次性训练成本 |

**成本序固定**：模型调用 → 模型调用+replay → GPU-hours。这个序正是 §4.4 调度问题非平凡的原因。

**𝖣 Data-RSI**：四维学习签名
$$\kappa(e) = (\kappa_k,\kappa_r,\kappa_v,\kappa_d)\qquad(\text{Eq. }11)$$
依次诊断：知识缺失 / 知识在场但推理失败 / 缺验证步骤 / 易被干扰项带偏。
合成流水线（Eq. 12）：$\mathcal{E}\xrightarrow{\textsc{Extract}}\mathcal{P}\xrightarrow{\textsc{Direct}}\Delta\xrightarrow{\textsc{AdvGen}}\mathcal{C}_{cand}\xrightarrow{\textsc{Gate}}\mathcal{D}'$，**分四段是为了让"什么错了""教什么""怎么造一条具体记录"各自可审计、可单独替换**。
对抗生成（Eq. 13）：$(q,a)\sim O(\delta,\varepsilon,\kappa)$，$\hat a\sim A(q)$，$\mathrm{acc}=\mathbb{1}[\hat a\equiv a]$。**Operator 造、Anchor 在看不到 Operator 答案的情况下盲解（blind re-derivation），两者都由同一个目标模型扮演**——分离靠**输入隔离**而非模型身份。
验证（Eq. 14）：$G(r)=C_{contract}(r)\wedge C_{verify}(r)$，**fail-closed**。
附录 E 的 **Algorithm 2 三道记录门**（全 fail-closed）：
- **Gate 1 正确性**（闭式：独立 solver 不看标签重推 + 独立 verifier 复检标签/格式/推导一致；可执行：建环境、能构造、参考解过测试、no-op 解必须失败、独立 solver 在界内可解）
- **Gate 2 新颖性**：用 $\theta_{rel}$ 廉价解码预解；若已解出 → 标 `already-held`，路由到 consolidation，**排除出价值归因**
- **Gate 3 Provenance**：与密封集 $\mathcal{Z}$ 的归一化精确匹配或高 n-gram 重叠即拒；语义近重复 fail-closed；必须携带 source failure signature 或声明的外部来源；**必须不是从诊断评测运行自身的产物派生**

**𝖧 Harness-RSI**：五槽 genome
$$\mathcal{H} = (\underbrace{I}_{\text{system prompt}},\;\underbrace{\mathcal{M}}_{\text{memory}},\;\underbrace{\mathcal{O}}_{\text{built-in tools}},\;\underbrace{\mathcal{S}}_{\text{skills}},\;\underbrace{\mathcal{T}}_{\text{MCP}})\qquad(\text{Eq. }15)$$
每个槽是**distinct edit granularity** → 编辑面可枚举 → proposal 是**对具名字段的 typed patch，而不是重写的程序**。
$$\Pi = (\eta,\{o_i\},\varepsilon,\mathcal{R}),\qquad o_i=(\mathrm{slot}_i,\mathrm{op}_i,v_i)\qquad(\text{Eq. }16)$$
$\eta$=repair hypothesis、$\varepsilon$=expected effect、$\mathcal{R}$=risk statement。**要求填假设和预期效果，强迫模型说出它认为什么错了、期望发生什么，且形式上能被后续阶段对照结果检查。**
提升（Eq. 17）：$\mathcal{H}^{\star}=\arg\max_{\mathcal{H}\in\mathcal{H}_{merged}}Q(\mathcal{H})$ s.t. 严格超越历史最佳 + 复杂度上界 $\|\mathcal{H}^{\star}\|\le B_{\mathcal{H}}$（约束 active context、memory 条数、序列化 genome 大小）。memory 条目有固定类型（knowledge / positive pattern / anti-pattern），**合并或删除会记录每条被移出的条目及原因**。

**𝖬 Model-RSI**：配方空间
$$\mathcal{R}=\mathcal{R}_{arch}\times\mathcal{R}_{adapt}\times\mathcal{R}_{optim}\times\mathcal{R}_{seq}\times\mathcal{R}_{ckpt}\qquad(\text{Eq. }18)$$
$$\theta_j=\mathrm{Train}(\theta_0,\mathcal{D}',r_j),\quad j=1,\dots,k\qquad(\text{Eq. }19)$$
**训练永远从同一固定基 $\theta_0$ + 累积数据集出发，绝不续训上一轮的 adapter** —— 使各代只在数据与配方上不同、共享一条优化历史，**保持增益可归因并抑制跨轮误差累积**。数据用 loss mask 只给 assistant 生成位置计分。
提升（Eq. 20）：与 Eq. 17 同构的严格改进纪律，只有候选成本不同。

成本不对称（Eq. 21）：$\Delta_{ctx}(\mathsf{H})>0$（每次推理重付）vs $\Delta_{ctx}(\mathsf{M})=0$（训练时付一次）。**这正是 $\mathsf{M}\to\mathsf{H}$ adapter 要利用的**：一旦行为被内化，就退役 scaffold 扩展。

### 2.8 算子组合：五of-six 可容许转移（§4.3）

- **Definition 4.2（capability-altering step）**：𝖧 和 𝖬 是；**𝖣 不是**（只写数据态、发 artifact）。
- **Definition 4.3（signal freshness）**：$\mathrm{fresh}(a,t{+}1)\iff \mathrm{compiled}(a)\ge\max\{t'\le t: u_{t'}\ \text{is capability-altering}\}$，约定 $\max\varnothing=0$。
- **Principle 4.4（Admissibility）**：一步可容许 **当且仅当它消费的每个 artifact 都是 fresh 的**。

$$\mathcal{A}_{legal} = \{\mathsf{D}\to\mathsf{H},\;\mathsf{D}\to\mathsf{M},\;\mathsf{H}\to\mathsf{D},\;\mathsf{M}\to\mathsf{D},\;\mathsf{M}\to\mathsf{H},\;\mathsf{D}\to\mathsf{D},\;\mathsf{H}\to\mathsf{H}\}$$
$$\mathcal{A}_{forbidden} = \{\mathsf{H}\to\mathsf{M},\;\mathsf{M}\to\mathsf{M}\}$$

**唯一的跨算子排除 $\mathsf{H}\to\mathsf{M}$ 的理由**（原文）："a harness step changes what the deployed system can do but produces no data, so the most recent dataset necessarily predates that change, and training on it would internalize behavior the system has already superseded."

每条可容许边由 **Transition Agent-v1** adapter 实现：
$$T_{i\to j}(a_i)=a_j \iff \mathrm{fresh}(a_i)\wedge\mathrm{typecheck}(a_j,\mathcal{A}_j)\qquad(\text{Eq. }24)$$
五个 adapter 及其类型转换：`Experience Extraction`(𝖣→𝖧, Experience→HarnessPatch)、`Dataset Materialization`(𝖣→𝖬, Dataset→masked shards + recipe)、`Signal Recompilation`(𝖧→𝖣, Genome→重编译 σ)、`Signal Recompilation`(𝖬→𝖣, Checkpoint→重编译 σ + κ)、`Redundancy Reconciliation`(𝖬→𝖧, TrainingRpt.→HarnessPatch)。**Adapter 对目标系统无权威：它们只 reformat、distill 或 reject。**

### 2.9 两轴调度（§4.4）

**水平编排**：
$$z_{t+1:t+m}\sim \pi^{\mathrm{h}}_{\phi}(\cdot\mid z_{1:t},\sigma_t,B_{rem}),\qquad \mathrm{supp}(\pi^{\mathrm{h}}_{\phi})\subseteq\mathcal{A}(z_{1:t})\qquad(\text{Eq. }25)$$
**可容许性在规划时定案**——program 是转移图里的合法词，每步挂证据与预算 → **规划与执行分离**。

**垂直优化**（改进算子而非调用算子）：
$$d_t = \pi^{\mathrm{v}}_{\phi}(\cdot\mid z_{1:t},\sigma_t) = (i_{\text{target}},\;\kappa_{\text{contract}},\;a_{\text{attribution}},\;J_i,\;\Xi_{\text{requested surfaces}})\qquad(\text{Eq. }26)$$
合同 $\kappa$ 把算子的每个字段划成三类：**Mutable surfaces**（诊断方式、提案优先级、自身适用性陈述）/ **Action surfaces**（写系统的那部分）/ **Protected surfaces**（evaluator、sandbox、release gate、artifact schema、证据链、算子身份与声明的 IO 类型）。
安装新策略前过四道检查（Eq. 27）：identity / declared-surface containment / **diff 等于声明的修改**（"the decisive one in practice"）/ stop condition。

两轴产出两个不同对象：水平产 $\Delta S$，垂直产 $\Delta\pi$ → 给 §5 的经验分解三个明确归因对象（序列、算子、交互）。

### 2.10 Meta 层与三层嵌套（§4.5）

$$\phi \leftarrow M_{\psi}(\phi,\mathcal{H}_{term}),\qquad \mathcal{H}_{term}=(z,\sigma_{1:T},\{\Delta\pi_i\},g,c)\qquad(\text{Eq. }28)$$

**Eq. 29 是分层不变式的正式写法**：
- $\mathrm{RSI}^2\text{Agent-v1}:\ \mathrm{write}(\phi)$
- $\mathrm{Operator}_i:\ \mathrm{write}(W_i)\subseteq S$
- $\mathrm{RSI}^2\text{Sub-Agent-v1}_i:\ \mathrm{write}(\mathrm{mutable}(\Xi_i))\subseteq\pi_i$
- $\mathrm{MetaRSI}^2\text{Agent-v1}:\ \mathrm{write}(\mathrm{instruction}(\phi))\subseteq\phi$

论文原话："What keeps the levels apart is not convention but write surfaces, one per agent... **This is why the framework needs four agents rather than one**: the write surfaces are what make the levels compositional instead of merely recursive."

$M_{\psi}$ 带**固定参数 $\psi$：它修改 $\phi$ 但自身不被修改，所以层级在最外层终止。**
$M_{\psi}$ 的独特视角：Sub-Agent 只看到一个算子在一条 term 里的一片切片；Meta 看到每个完成 term 中"哪些序列和垂直指令产出了活过 release gate 的增益"。

**Human in the loop**：Eq. 29 命名的是四个**角色**，不是四个模型。"A domain expert reading a learning signal is often, at present, a better judge than any model of whether a failure is worth a training run." 论文还给出一条轨迹性判断：human-in-the-loop 是**通往自主的路点，不是永久分工**。

### 2.11 Algorithm 1（一个 improvement term 的生命周期）

```
1: S_0, 算子 {U_i = ⟨K, π_i, w_i⟩}, RSI²Agent-v1 策略 φ, 预算 B
2: σ_0 ← Σ(Evaluate(S_0))            ▷ 固定 evaluator；密封集不动
3: while B_rem > 0:
4:     a_t ← Route_φ(z_1:t, σ_t)      ▷ horizontal 或 vertical
5-11:  if Horizontal: 抽 program 限于 A(z_1:t)，绑定 adapter、确认 Eq.22 新鲜、预留预算，逐步跑 kernel，Gate 提升
12-15: else: d_t ← π^v_φ(...); SubAgent 改策略；仅当 Eq.27 成立才装 π'
16:    σ_{t+1} ← Σ(Evaluate(S_{t+1}))  ▷ 每步后重编译信号
17: end for
18: φ ← M_ψ(φ, H_term)                ▷ 元更新
19: return 发布的 S_T, 更新后的 {π_i}, 更新后的 φ
```

**贯穿全程的不变式："no component ever evaluates its own output."**

### 2.12 保护性分隔（§4.7，Eq. 30）

$$\{Q^{\star},\mathcal{T}_{seal},\mathrm{release\_rule},\mathcal{L}\}\cap W_i=\varnothing\;(\forall i),\quad \{Q^{\star},\mathcal{T}_{seal},\mathrm{release\_rule},\mathcal{L}\}\cap(\mathrm{write}(\phi)\cup\mathrm{write}(\phi_{meta}))=\varnothing$$

### 2.13 Verifier Ladder（Table 5）与五条法

| Rung | Verifier | 示例领域 | Data-RSI 在此 rung 的作用 |
|---|---|---|---|
| 1 | 可执行测试、exact match | 软件、terminal、闭式科学 | 按诊断直接指导合成 |
| 2 | 数值收敛、仿真 | 流体/结构设计、电路 | 同上，成本是 simulator |
| 3 | 复现已报告结果 | ML 复现、计算生物学 | 区分方法缺口与数据缺口 |
| 4 | 带仪器的protocol执行 | 湿化学、材料合成 | **决定跑哪些实验** |
| 5 | 专家 rubric，无 ground truth | 法律、政策、史学 | **界定对专家时间的需求量** |

**五条法（每条都写成可被后续结果反驳的形式）**：
1. **Verification, not capability, sets the frontier.** $\rho(N,R)=-0.75$，$r(N,\mathrm{cap})=+0.64$，但 $r(N,R|\mathrm{cap})=-0.67$ 而 $r(N,\mathrm{cap}|R)=+0.45$ n.s.。推论：**要拓宽自改进，就去建 verifier**。
2. **Self-knowledge expires, so re-description is the rate limit.** Principle 4.4 是它的局部形式。推论：**写 verifier 的算子一次作废全部历史**。
3. **Competence is substrate-free; its cost is not.** 推论：**substrate plurality 是必要的，不是方便的**——只有双可写 substrate 的循环才能退役另一 substrate 已吸收的东西。
4. **Trust is measured by what cannot be written.** 这比 Goodhart 更强："the divergence is not merely hard to detect, it is unobservable from inside." 推论：**改进工作信号，绝不改进锚**。
5. **No loop creates capability; every gain is imported.** 机制："a record for a never-shown capability is schema-indistinguishable from a correct one, so it trains like everything else." 推论：**一个自改进结果有两个数，不是一个：它放大了什么，它引入了什么。**

### 3.1 目标系统与设置

- 自托管开权重目标：**Qwen3.5-35B-A3B**（MoE，35B 总参 / 3B 激活），权重可写 → 三个算子全部能动。64K context。

### 3.4 改进改进者（§5.4）

**设计**：Term 1 跑一个改进者产出 $S_1$；Term 2 **分叉**：一支用原改进者继续改进 $S_1$，另一支用元层重写过的改进者在**同预算、同密封划分**下改进同一个 $S_1$。**两支唯一差别是"哪个改进者跑了"。**

- **Term 2：元更新改进者 +7.2 vs 原改进者 +4.9，差 +2.3**。按基准：Terminal-Bench 2.1 +1.6、SWE-bench Pro +1.7、GPQA-D-hard100 +2.6、AIME +3.3 —— **优势随基准允许的增益增长，且四者排序在两个改进者下相同**。"What the meta-update changed is the size of the step, not where the improver looks."
- **五个 term（Fig.11）：元路径 +26.2 vs +20.7，term5 差距 +5.5 且逐 term 变宽。**
- **每 term 增益（Fig.11b）：两条路径都在衰减。**无元更新 term2 +4.9 → term5 **+0.7**；有元更新 term2 +7.2 → term5 **+1.4**（term5 仍是对方的 2 倍）。terms2–5 平均 **+3.8 vs +2.5**。
- **平台期**（每 term 回报 ≤1.5 分的那一 term）：**无元更新在 term4，有元更新在 term5**。
- Table 12 汇总：达到 +20 平均增益所需 term 数 **2.5 vs 4.0**；**策略延续到下一 term 的比例 68% vs 38%**；**scheduler regret 8.2% vs 16.5%**；**回归 −0.2（GPQA-h100，term5）vs none**。
- 论文对衰减的归因："Decay itself is what a loop drawing on a fixed substrate does."
- **前沿 fleet 三个 term**：全部模型每 term 都涨，均值 **+7.3 / +2.8 / +1.2，累计 +11.3**；fleet 均值 **80.0 → 91.3**，前四名收在 93.6–94.7（相差 1.1 以内）。**留存由 headroom 而非强度决定**：两个最低基线（Gemini 3.1 Pro 66.3、GLM-5.2 78.4）在 term2 保住 term1 增益的 **43% 和 63%**，其余四个保住 **26%–39%**，两量秩相关 **Spearman $\rho=-0.84$**。

### 3.5 负面结果 / 诚实项

- **回归被实测到**：无元更新路径在 term5 于 GPQA-D-hard100 **倒退 0.2 分**（Eq.5 的 regression 项真实生效）。
- **衰减是实测的**，两条路径都衰减，论文不掩饰。
- **论文报告的跨域主张（§6.4.3）明确标注为未验证**："Whether many such loops, exchanging artifacts across many disciplines, aggregate into something resembling broad expert-level competence is an **open empirical question**."
- **§6.8 自陈的三个反驳条件**：loop count 在控制 rung 后跟随 capability；诊断 artifact 与 genome 在实践中无法播种下一个 loop；单独改进的算子组合效果不优于本文组合。
- **§6.1–6.7 的"五法"与 verifier ladder 在 rung 4–5 的用途**：论文**没有在 rung 4/5 上跑任何实验**。所有实验都在 rung 1（Terminal-Bench / SWE-bench / GPQA / AIME）。rung 2–5 的论述是**论述，不是测量**。
- **物理世界（§6.5）明确是展望**："Every loop in this report closes inside a computer."
- **论文未报告**：单算子 vs 组合的显著性检验（无 p 值、无置信区间，只有 5 seed 均值）；$\mathsf{H}\to\mathsf{M}$ 禁令被违反会怎样（无实验）；元层 $\psi$ 参数具体值；scheduler regret 的计算细节；五 term 实验是否在同一密封划分上重复评分。

## 4. 它假定了什么（挖隐含前提）

1. **假定存在一个能被无污染调用的强 verifier。** 全部主结果建立在 Terminal-Bench / SWE-bench / GPQA / AIME 上。论文自己把这称为 **format bound** 并批评它——但它的系统与它的数字仍然停在这个 bound 内。**批评与依赖同一个前提。**

2. **假定"amplifier"的上界是可接受的。** §6.2 承认："A record synthesized for a capability the model has never exhibited is authored by the same model that lacks it, so the loop cannot bootstrap knowledge it does not contain. The system composed of these operators alone is a **closed amplifier**." 因此**每一次真实增益都必须从循环外导入信息**。论文的整个系统只能**界定**需要多少外部输入，不能减少它。

3. **假定目标模型自身足够强以扮演所有角色。** 闭式轨上一个 3B 激活的模型同时扮演 Diagnose、Propose、Operator、Anchor、scheduler、meta-agent。这是**极强的前提**：在 DWC 常见的弱模型 / 小模型条件下，这六个席位的能力会同时塌陷，而论文没有任何降级方案。

4. **假定写入面在构造上真的可枚举。** Eq. 27 的第三道检查（diff = 声明的修改）**只有在提议者无法伪造 diff 的元数据时**才成立。若提议模型同时生成"声明的修改"和"实际的修改"，diff 检查就退化为形式检查。论文没有讨论这个对抗面。

5. **假定 $\mu(\tau)$（可复用机制）虽然由模型产出，但被要求 grounded 在确定性的 $\chi,\psi$ 上。** 附录 D 说"a mechanism that contradicts the assigned terminal cause is rejected at validation"。**这是对一致性的一致性检查，不是对正确性的检查。**一个与失败相关但错误的机制能通过这道检查。

6. **假定密封测量足够强以支撑泛化主张。** GPQA-D-hard100 是 100 题，Terminal-Bench 2.1 是 89 任务。**+8.3 分在 89 个二值任务上的方差是很大的。**论文给 5 seed 均值但不给方差/置信区间。

7. **假定改进预算在领域间可比。** Eq.5 的 cost 项 $C(z)$ 用 $\mathrm{corr}_{\mathrm{Oracle}}$ 等计数归一，但"tokens"和"GPU-hours"之间的实际交换率是**领域特定的**，论文没有讨论跨领域如何归一化成本。

8. **假定人类监督是一条连续可调的轴。** §4.5 的人机谱系假定"human expert 能接管 scheduler 而保持框架不变"，但**没有报告任何 human-in-the-loop 的实验**。这条轨迹是论述。

9. **假定\mathcal{T}^{\star}能被"一次性评分"。** 论文说 sealed set "on which the final system is scored once"。这使每 term 只能获得一个数据点——也正是它必须跑 5 term × 2 路径 × 多 seed 才能得到 Fig.11 的原因。

10. **假定 agent 的定义是五槽 genome。** $\mathcal{H}$ 的五个槽（system prompt / memory / tools / skills / MCP）覆盖了当代 harness 的**大部分**，但不含：调度循环本身（这被外置为 $\phi$）、模型权重（外置为 $\theta$）、verifier（被保护）。这个切分是**设计选择，不是必然**。

## 5. 可迁移到 DWC 的点 / 不可迁移的点

### 5.1 可迁移（每条给出具体接口）

**① 失败签名 $\varphi(\tau)$ 作为 DWC 记忆写入的最小单元** —— 这是本篇对 DWC 最直接的价值。
- 搬什么：三段式 `(terminal cause, causal role, reusable mechanism)`，**且前两段由规则分配、第三段由模型假设**。
- DWC 接口：定义 `FailureSignature` dataclass；记忆条目强制携带 `signature` 字段；`terminal_cause` 与 `causal_role` 由 DWC 侧的**规则分类器**（非 LLM）填充，`mechanism` 由 LLM 填充。
- 立刻可用：论文附录 D 直接给了两套可抄的分类法（closed-form 6 类 / executable turn-level 6 类 + task-level 6 类）。DWC 可以先照抄这套优先级序。
- **价值**：DWC 的记忆如果不记录"为什么失败"，检索时无法按成因路由，只能按语义相似度——这正是 `2609.14857`（ModularRSI）说的"localizing recurring behavioral deficiencies within monolithic harnesses is difficult"。

**② 四维学习签名 $\kappa(e)$ 作为 DWC 的检索键 / 缺口标记** ——
- 搬什么：`κ_k`(knowledge) / `κ_r`(reasoning) / `κ_v`(verification) / `κ_d`(distractor) 四维，**下游读它是"要造哪类记录"的指令，不是标量分**。
- DWC 接口：`EpisodeSummary.learning_signature: tuple[4]`；检索时可按 `κ_k` 高但准确率低的 episode 定向召回"知识缺口"类记忆。
- 这直接对应 DWC 的"DWC-MEM 真值源 = 可复现召回率基准"：**有了 $\kappa$ 维度，召回率可以按缺口类型分别度量**，而不只是一个总召回率。

**③ Signal freshness 作为 DWC 记忆的失效判据（Principle 4.4）** ——
- 搬什么：不是搬整个三算子系统，而是搬**这条判据**：`fresh(a,t+1) iff compiled(a) ≥ 最近一次 capability-altering step`。
- DWC 接口：每个记忆条目带 `compiled_at_generation: int`；系统有 `capability_altering_step: int`；**任何 prompt/skill/记忆策略被改写后，所有旧条目标记为 stale 并在检索时被降权或要求 re-verification**。
- 这条**防止一个 DWC 特有的病**：记忆库越滚越大，但里面记的是三个版本前的系统行为。论文的机制给了判据。

**④ 三层 ASB 分离 + 密封真值源，作为 DWC 的 G5 门** ——
- 搬什么：Eq.30 的集合交空条件 + "no component ever evaluates its own output" 这条不变式。
- DWC 接口：DWC 的记忆写入器必须是**确定性代码**，不能由 LLM 决定"这条记忆该不该留"；LLM 只提议（propose），代码裁决（adjudicate）。
- 这与 DWC 现有 `QUALITY_GATE.md` 的七门思路一致，但论文给的是**可写成代码的不变式**（`{Q*, T_seal, release_rule, L} ∩ W_i = ∅`），可以直接落成一个 gate 脚本断言。
- 对 DWC-AUTO 的直接意义：**"同输入对照的 before/after 差分"就是论文的 $Q^{\star}(S_T)-Q^{\star}(S_0)$**——DWC 的真值源定义与论文 Eq.5 的 realized gain 项结构完全同形。

**⑤ 目标函数 J 的四项结构作为 DWC-AUTO 的收益函数** ——
- 搬什么：`gain − λ·cost − μ·regression − ν·Gap(σ, Q*)`。
- DWC 接口：DWC-AUTO 的验收脚本应同时输出四个数而非一个；**特别地 `μ·Reg` 项让"旧能力回退"成为一等惩罚**，而不是事后诊断。
- **这直接回应 DWC PROGRESS.md 里的隐忧**："论文读了没落地" —— 论文在这里给了一个**可实现的验收函数形状**。

**⑥ Verifier ladder 作为 DWC 的记忆域选择依据（Table 5）** ——
- 搬什么：五级阶梯 + "rung 决定 Data-RSI 在此做什么"的分工（rung1-2 指导合成，rung4-5 界定实验分配）。
- DWC 接口：DWC 若要闭一个记忆闭环，必须先声明"我的 recall benchmark 属哪一 rung"。DWC-MEM 的可复现召回率基准是 **rung 3（复现已报告结果）**，不是 rung 1。

**⑦ 五个 harness 槽作为 DWC 的可枚举写入面** ——
- 搬什么：`ℋ = (I, ℳ, 𝒪, 𝒮, 𝒯)`，以及"每个槽是 distinct edit granularity → proposal 是对具名字段的 typed patch"。
- DWC 接口：DWC 的记忆/技能系统应当能被描述成**有名字的字段**，而不是一坨自由文本；这样"这个改动写了哪个面"是机械可判的。

**⑧ 平台期与衰减的实测形状** ——
- 搬什么：这是**可直接用来设定 DWC 预期的负向数字**：每 term 增益从 +4.9 衰减到 +0.7（5 term 内），无元更新时平台期在 term4。
- DWC 用途：DWC 若在第 3–4 个循环就停止涨，**那符合已发表的衰减形状，不是 bug**。这条能防止 DWC 把正常衰减误判为失败并因此乱加机制。

### 5.2 不可迁移

**① Model-RSI 整块不可迁移（前提不成立）。**
- 原因：需要**可写权重 + GPU 训练栈 + 从固定 $\theta_0$ 重训**。DWC 是 agent 项目的记忆+自进化，不具备训练基础设施。
- 若强行照搬只会得到 `𝖣→𝖬` 边的一个空实现。

**② 整个"五条法"中依赖 45 系统普查与 22 领域能力分数的部分，只可作为参考坐标，不能作为 DWC 的验收依据。**
- 原因：那些数字（$R(d)$ rung 归属、capability 67.8–80.8 等）来自**第三方论文的最佳发布分数**与**不同协议**的拼接，论文自己声明"Only the MLE-bench pair is measured within one system; the other five compare each end's best published frontier score"。
- 抄它当基线会引入协议不一致。

**③ 前沿模型实验（§5.3）不可作为 DWC 的性能预期。**
- 原因：**依赖闭源模型**（GPT-5.6 Sol、Claude Opus 5、Gemini 3.1 Pro、GLM-5.2、Kimi-K3、Grok-4.6 全部只能通过 provider 接口调用）。DWC 不具备同等模型条件。
- 论文标出的 `+7.3 均值`是**在别人最强 scaffold 上**测的，DWC 用弱模型时不能引用这个数。

**④ MetaRSI² 元层在 DWC 的当前阶段（承重代码 0 行）不可迁移。**
- 原因：元层的前提是**已经有了一个能产生 released gain 的基线 term**（Fig.11 的设计要求 Term 1 先有 $S_1$）。DWC 现在连第一件承重代码都没有，PROGRESS.md 明写"**承重代码 0 行（刻意为空，先立门再写码）**"。
- 正确顺序：先做 DWC-AUTO 的**一个** term（Eq.5 的一次测量），再谈元层。

**⑤ rung 4–5 的全部论述（实验分配、专家时间界定、物理世界）不可迁移。**
- 原因：**论文自己没有在这里跑过任何实验**，全部是论述。且需要仪器/专家时间。

**⑥ 人类可调度（human-in-the-loop 谱系）不可迁移为自动化主张。**
- 原因：论文**未报告任何 human-in-the-loop 实验**。

**⑦ `Gap(σ, Q*)` 项在 DWC 无外部锚时不可实现。**
- 原因：DWC 的问题是"系统外的真值源是什么"，而 Gap 项要求**同时有工作信号 σ 和密封 evaluator $Q^{\star}$**。DWC 若没有 $Q^{\star}$，这一项无法计算——而它恰恰是论文用来防止"改测量而非改能力"的那一项。

## 6. 与其他论文的关系

**在 RSI 图谱中的位置**：这是 19 篇里**唯一一篇自建完整闭环系统并给出主实验数字的**（相对 2609.14857 等同门工作）。它不产出新算法，而是产出一个**代数**：三个写入面 + 一条新鲜度判据 + 一个目标函数。

**前序**：Gödel machine 一脉（论文自己列为 [23]）；STOP [1]、ADAS/AFlow [2,27]、Gödel Agent/DGM [28,3]、Self-Adapting LMs [4]、RSIBench-Data [35] —— 论文逐一点名它们各自处理哪个表面，并指出它们的两个共同缺口（写死顺序 + 算子固定）。

**与 `2609.13406`（GAI）的关系：概念上互为镜像，但作者独立。**
- 13406 提出两个 dials：**Dial 1** 改进机制是否在 agent 内，**Dial 2** 评估基准是否 grounded；并给出 polarity 三态（Anchored / Goal Drift / Fully Self-Referential）。
- 06396 实际上**硬编码了 Dial 2 的 Anchored 态**：Eq.30 明确把 $Q^{\star}$、release rule、账本排除在一切写入面之外，包括元层。
- 换言之：**13406 告诉你"必须钉住哪根锚"，06396 给出了钉锚的可实现形式**（Eq.30 的集合交空 + Algorithm 1 的 Gate）。二者互为理论/工程对照。06396 未引用 13406。
- 一个小张力：13406 的 Defect 表把"Goal Drift"标为 structural **且 observed**；06396 通过保护面**规避**而非**解决**它。这不是矛盾——13406 也说防护本身是设计选择。

**与 `2609.11873`（Last AI）的关系**：11873 把 MetaRSI 这类工作定位为 **L2（策略自主）到 L4（部署适应）之间**，且明确指出 L5（机制递归）的证据"concentrated in bounded prototypes"。06396 的元层（MetaRSI² 改 $\phi$）在 11873 的分类下**正好是 L5 的 structural 证据**——因为元层改变的是"治理后续改进的策略"。
- 但 11873 要求的 **effective L5**（"the revised mechanism produces or selects better successors under comparable budgets and independent assessment"）——06396 的 Fig.11(c) 恰好就是这个设计：同预算、同密封划分、唯一差别是哪个改进者跑，+2.3。
- **所以 06396 是 19 篇中少见的、同时提供了 11873 所要求的 structural 与 effective 两类 L5 证据的工作。** 11873 未引用 06396（06396 v2 日期 09-09，11873 v3 日期 09-22，但 11873 的参考文献里我没看到 06396）。

**与本项目另一条主线（记忆类论文）的关系**：06396 的 Data-RSI 本质上是"**从执行经验合成已验证记忆并界定其边界**"。它的 **Gate 2（novelty，已解出则标 already-held 并排除出价值归因）** 与 **Gate 3（provenance）** 是本篇对记忆系统最有工程价值的两个可抄机制——这两道门在任何记忆系统里都能直接用。

**与 DWC 的关系总结**：它是这 19 篇里**最接近"可以直接照抄一个模块"的**——但可抄的是**类型与判据**（失败签名、学习签名、新鲜度、ASB 分离、四项目标函数），不是它的**实验数字**（那依赖 Qwen3.5-35B-A3B + 四套 2026 基准）。
