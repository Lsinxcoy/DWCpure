## 1. 一句话

## 3. ★★★ Table 1 消融 —— DWC §9 第 25 项 (a)(c) 的答案就在这张表

**原文逐字**：

```text
Table 1: Comparison of DGM, its ablations, and baselines on SWE-bench and Polyglot benchmarks.

  Method                              SWE-bench   Polyglot
  DGM                                     50.0%      38.0%
  DGM w/o Open-ended exploration           23.0%      14.0%
  DGM w/o Self-improve                    39.0%      28.0%
  DGM Greedy                              39.7%      30.0%
```

### ★ 这四个数字分别证明什么（DWC 直接可用）

```text
① DGM 50.0% vs **w/o Open-ended exploration 23.0%**
   ⇒ **归档 + 非贪心采样**的贡献 = +27.0 个百分点（SWE-bench）
   ★ 这是最大的一项。原文措辞: "allowing all solutions in the archive to serve
     as potential stepping stones can lead to greater improvements over time,
     underscoring the importance of open-ended exploration."
   ★★ 对 DWC 的含义: 如果 DWC 的进化只保留"最好的一个"（贪心），
      实测会掉到 39.7%（Greedy）⇒ 归档非贪心**不是装饰，是主要收益来源**。
      ★ 这直接支撑 DWC §11 的 `world_model` 归档/世界树设计。

② DGM 50.0% vs **w/o Self-improve 39.0%**
   ⇒ **改自己代码**（递归）的增量 = +11.0 个百分点
   ★ 关键: 这是"改 agent 代码"的**净**贡献，已扣掉归档的贡献。
   ★★ 对 DWC 的含义: 递归改代码的收益（+11）**显著小于**开放归档的收益（+27）。
     ⇒ 若 DWC 资源有限，应先投归档/多样性，再投"改自己的代码"。

③ DGM 50.0% vs **DGM Greedy 39.7%**
   ⇒ 同上，贪心 vs 归档的差 = +10.3 个百分点

④ ★ 诚实项: DGM 的基线对手是 **ADAS 式**（"DGM w/o self-improve replicates the
   approach of ADAS (Hu et al...)"）⇒ 39.0% 那个数里含 ADAS 的能力，不是"无递归"裸跑。
```

## 4. ★ 阶梯式评测协议（DWC 可直接抄）

**原文逐字**：

```text
"For SWE-bench, if a coding agent achieves over 40% success (a heuristic chosen based
 on the noise observed in preliminary runs) on the 60-task subset and ranks among the
 top two performers in the archive, it is then evaluated on 200 tasks (140 plus the
 previous 60) to more accurately assess its true coding capability.

 For Polyglot, if a coding agent achieves over 40% success on the 10-task subset,
 it is evaluated on an expanded 50-task subset."
```

### 三个设计点

```text
① **小集粗筛 → 大集精评**（60→200 / 10→50）
   ⇒ 对应 DWC §9 第 25 项 (b) "配对探针的严格形式"：
     先在小 dev 集筛，胜者才进大集。成本随轮次分层。

② ★ 门槛 40% 是**启发式选的**，不是理论值
   原文自陈: "a heuristic chosen based on the noise observed in preliminary runs"
   ★ 这与 DWC 反复强调的"口径要一致"是同类诚实标注。

③ 归档内排名 top 2 才进大集
   ⇒ 用**归档排名**而非绝对分做筛选，把"多样性与精度"分在两个阶段处理。
```

## 5. 机制细节（摘要 + §4.1）

```text
★ 自我改的是什么（Abstract）:
  "iteratively modifies its own code (thereby also improving its ability to modify
   its own codebase) and empirically validates each change using coding benchmarks"
  ⇒ ★ 双重收益: ① 解题能力 ② **改代码的能力本身**
    第二项是 Hyperagents 要专门解决的问题（见 2603.19461 报告）

★ 归档的作用（Abstract）:
  "grows an archive of generated coding agents. It samples agents from this archive,
   which self-modify to create new, interesting versions of themselves. This open-ended
   exploration forms a growing tree of diverse, high-quality agents and allows the
   parallel exploration of many different paths through the search space."

★ 存档的是什么状态（§4.1 相关）: agent code + archive
  ★ Table 5（2609.2680）记 DGM 的 retained state = "Agent code; archive"

★ FM 配置（Table 5）: Sonnet 3.5 主 agent，o3-mini 做 editor / 任务
  ★ 铁律: **outer driver 固定**（"Shared agent; fixed outer driver"）
```

## 7. 诚实条款（逐条照录）

```text
① 摘要的 Polyglot 用**全集**（14.2→30.7），§4.4 主结果用**50 子集**（14.0→38.0）
   ⇒ 引用时必须带任务集说明，否则会把 38.0 当全集成绩
② 40% 门槛是启发式选的，原文明说是 preliminary-run 噪声观察的结果
③ 消融基线 w/o self-improve 复刻的是 **ADAS**，不是"什么都不做"
④ ★ 未报告 sandbox 绕过率（STOP 报告了）—— 不可据此推断 DGM 无绕过风险
⑤ ★ 未报告 多次运行的方差 —— Table 1 是单点值
   ⇒ 对比 2609.2680 引用的 Metaⁿ 是 "0.851±0.014" 带标准差的
   ⇒ ★ DGM 的 50.0% 应视为**单次结果**，不能当统计结论
```

