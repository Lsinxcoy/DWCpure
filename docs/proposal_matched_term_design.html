① 文献状态 — 为什么 DWC 只能做「最小版」

综述 §3.6.5 对 effective recursion 的要求: 「matched budgets, including the cost of evaluating the mechanisms」 — 这是要求不是现状（原文逐字引自 SYNTHESIS §二·1）。

R96 反刍横搜（32 篇全文, RUMINATE.md 视角1/视角3）的硬结论:
三件套文献命中篇目
matched budget（同预算对照）仅 1 篇 Verma 2607.26117（+ 其安慰剂臂）
独立锚（评估器不读被评臂）仅 1 篇 RQGM 2606.26294（1−ε 保守下界 + anchor）
安慰剂/等预算假改进仅 1 篇 Verma 2607.26117（把 +12.2 变负的手段）
⇒ 空白坐实: 三件套各≤1 篇 = 没有可抄的现成协议（不是共识缺失）。 综述要的「effective L5 判定」在 32 篇中无一篇给出完整证据 （RUMINATE 视角3·2: 无任何篇同时具备结构递归+有效递归证据）。
⇒ DWC 定位 = 跟随设计者, 不是抄袭者（方案 §⑦T5 原话）: 先出「同 term 预算下 π0 vs π*」的最小对照设计 —— 本稿。 成稿与结果均不声称 L5e（禁用措辞见 §⑥）。

② π0 / π* 在 DWC 的载体

定义（本设计内, 不外推）:
符号含义DWC 载体（代码证据）
π0（基线策略） 改进发生前的完整策略快照 — 世界树 + 调度序 + 记忆状态 + 配置 一轮收官时刻的: PolicySpec(R86, pid+seg_order 锁值) + dials + 世界树快照（run_term 快照 ℋ）+ 记忆库 dump （六段档的 parent_state 正好是它的记录形态 — 稿①复用）
π*（改进后策略） 经一轮自我改进后的策略 — 同快照结构, 差异=该轮被接纳的 change 执行轮跑完后的同结构快照; 差异项由六段档 proposed_change + acceptance_decision=accepted 界定（只比被接纳的差, 不比全量）
term 预算 两臂各自运行的 term 数与评估成本 CostLedger（R99: history 结账 + open 标记）— 逐 term 记账, 可断言两臂 n_terms 与 cost 相等
「一轮」的界定: π0→π* = 一个 knowledge3 档周期 （一档一提交的那一轮）。多轮累积属综述 §3.6.5 另一缺口 （「跨代统计可靠累积」, 本设计不碰 — 单轮最小版）。

③ 三件套最小版映射（跟随设计的落点）

件文献原型（≤1 篇各自）DWC 最小版现状
matched budget Verma: matched budgets 含评估成本 两臂 同 term 数（N）+ 同判分次数 + CostLedger 断言 cost(π0)==cost(π*)（评估开销计入 — §3.6.5 字面） 账本在 CostLedger 已落 R99
独立锚 RQGM: anchor + 1−ε 保守下界 judge frozen + TRUTH_SOURCE golden（G2）+ 锚不读两臂 （anchors 只在评估时读, 不进任一臂的执行 prompt/状态）— 断言: 两臂跑完后 truth_sha8 与臂前一致（稿①段4 字段直接复用） 锚在 G2/judge frozen 已落; 统计下界不引入（无明文口径, 裁决②域）
安慰剂臂 Verma: 等预算假改进把 +12.2 变负 π̂ 臂 = 等预算盲改动: 与 π* 同数量级的改动注入, 但改动内容 与证据无关（随机 dial 摆动/随机规则 — 与 R107 blind_placebo 同族, 只是对象从「记忆工件」升到「策略改动」） 机制在 blind_placebo 臂协议已跑通 R107, 本设计换对象复用
刻意不做的三件: ① 1−ε Beta 下界（统计口径无核不发明）② 跨代累积统计 （§3.6.5 另一缺口, 非最小版）③ 自适应停止判据（裁决④域）。

④ 对照设计 — 臂 / 预算 / 判读

臂 A: π0        — 改进前快照原样跑 N term（基线）
臂 B: π*        — 改进后快照跑 N term（被接纳 change 生效）
臂 C: π̂(placebo) — 等预算盲改动快照跑 N term（安慰剂, Verma 同款）

同条件: 同一批任务(seed 定序) · 同 N term · 同判分器(frozen) ·
       同 CostLedger 口径 · 同 memory 状态起底（π0 的 dump 为三臂共同底,
       差异只在 change 注入 — 否则混入「记忆不同」的混淆）
内容效应 = score(π*) − max( score(π0), score(π̂) )
判读直觉: π* 必须同时超过基线与安慰剂 — 只超基线不超安慰剂 = 「有改动就行」的安慰剂效应（Verma 把 +12.2 变负的正是这步）。
「同 memory 底」是本设计的关键约束: 三臂从 π0 同一 dump 出发, π* 臂只多「被接纳的 change」, π̂ 臂只多「等预算假 change」— 把记忆差异 从臂间差里剥掉（否则重演 R107 教训: golden 替身把差异旁路）。

⑤ 协议与成本记账（复用 R107 已验证形态）

protocol 字段（进 docs/matched_term_design.json 的报告头）:
  seed          : 显式（args.seed, 默认固定）
  n_terms       : N（两/三臂相同 — matched 字面）
  budget_rows   : CostLedger 每臂逐 term 账（n_terms, cost, 判分次数）
  arms          : ["pi0", "pi_star", "placebo_pi"]
  anchor        : {truth_source, truth_sha8(前), truth_sha8(后), judge_frozen}
                  — 前后一致断言（独立锚字面）
  change_scope  : 六段档 acceptance=accepted 的 change 列表（π* 臂注入物,
                  可回查档 id — 与稿①互链）
  placebo_spec  : 盲改动的生成规则 + seed（可复现同一批假 change）
  verdicts      : {vs_baseline, vs_placebo, content_effect} 三读数
  claims_allowed: 只许报 matched-term 三读数（§⑥ 禁用词生效）
可复跑: 确定性 golden executor + 固定 seed ⇒ 同输入同输出; LLM 形态若启用则标注 endpoint="llm" + 三态记账 （candidates_* 同款）, 只报方向不报显著性（既有纪律, n 小）。

⑥ 判读规则 + 禁用措辞

禁用措辞（本设计产出的任何报告不得写）: 
✗ 「DWC 达成 effective L5 / effective recursion」
✗ 「L5e 通过」/「有效递归已验证」
✗ 「显著优于」（n 小只报方向, 无显著性检验不许用「显著」）
✓ 允许: 「matched-term 对照: π*−π0=…, π*−π̂=…（方向性, 单轮, 样本小）」
✓ 允许: 「在本设计的最小协议下, 内容效应方向为正/零/负」
为什么如此保守: 三件套文献各≤1 篇（§①）⇒ 无公认协议 ⇒ 我们的最小版 只是跟随设计不是达成判定; 且 §3.6.5 要求「评估成本计入预算」+ 「跨代可靠累积」两条本设计只覆盖前者的一半（单轮 CostLedger 记账, 无跨代统计）— 按 §3.6.5 原文, 这离「effective」判定还差一整段。 报告中的差距按缺口如实写, 不修辞。

⑦ 验收清单 + 执行序

□ 三臂脚本跑通（π0/π*/π̂ 同底同预算）+ CostLedger 断言两账相等
□ 独立锚断言: truth_sha8 前后一致（不一致=红, 污染即拒报）
□ 内容效应三读数出数（vs_baseline / vs_placebo / content_effect）
□ 报告头协议字段齐全（§⑤ 逐字段断言）+ 禁用措辞扫描测试（§⑥）
□ 盲改动可复现（同 seed 同一批假 change）
□ 三层验证不变 · 一档一提交 · 同批自洽 current+1
□ ★ 结果无论正负全报（方向为负也入档 — W5 不覆盖）
执行序: 本稿 + 稿① → 用户过审 → 执行轮（实现→三层→档→提交）→ 4b 四项裁决独立轮。两稿无依赖, 可并行过审。

⑧ 诚实条款

1. 本稿不给结论只给协议 — 未跑任何对照, 无数字可报（跑数在执行轮）。
2. π* 的「change」以六段档 acceptance=accepted 为准 — 若执行时六段档 未落地（稿①未过审）, 则退化为「本轮 git diff 为 change 清单」, 如实标注 change_scope="git_diff(legacy)"。
3. placebo 的假 change 生成规则须在执行轮写死（本稿只定「与证据无关、 等预算」两约束, 具体分布不预设 — 无明文不发明）。
4. R107 教训已吸收: golden 替身下记忆不进执行路径 — 本设计 π 载体是 「整快照含记忆」, 若执行中发现三臂差异被旁路, 如实报结构必然（与 R107 caveat 同款措辞）, 不把恒等当「无效」证据。
