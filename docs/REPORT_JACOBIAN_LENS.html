Jacobian Lens 与 J-space：语言模型中的全局工作空间

0 · 一句话总览与硬结论

论文提出 Jacobian lens（J-lens）：对每个词表 token 计算中间激活对其未来出现概率的平均一阶因果效应（跨 1000 个语境平均的 input-output Jacobian），得到"模型 poised to verbalize 什么"的可读读数。这些向量张成的稀疏子框架叫 J-space。核心发现：J-space 满足全局工作空间的 5 个功能属性＋3 个结构签名，且是"只占激活方差 ≤10% 的特权小集合"。应用上：对齐审计能看到输出中从未出现的策略性思考与评估意识；post-training 把 Assistant 视角装进 workspace；反事实反思训练只训"被打断后会说什么"就能改善不被打断时的行为。
最值得记住的 6 个数字：① J-space 只占激活方差 ≤10%，典型占用约 25 个向量；② 中间概念交换改答案 Haiku 54% / Sonnet 与 Opus 70%；③ J-space 成分报告成功率 59% vs 非 J-space 成分 5%；④ 敲掉评估意识后 blackmail 尝试 0/180 → 13/180；⑤ 反思训练 fabrication 不诚实分 0.25→0.07；⑥ workspace 层带约为 L38–L92（百分比层号）。
最值得记住的 1 个边界：作者明确说 J-lens 是审计工具箱的加法而非充分条件——练熟的自动化恶意行为可以绕开 J-space，多 token 概念读不出。

2 · 方法深读（J-lens 到底算什么）

2.1 数学定义

设 ℓ 层 token 位 t 的残差流为 hℓ,t，目标层（默认倒数第二层，见 A.7）最终残差为 zt′。单 prompt Jacobian 为 ∂zt′/∂hℓ,t，对全部 t′≥t（当前＋未来位置）、全部源位置 t、再对 1000 条×128 token 的预训练分布语料取期望，得每层一个 [d_model, d_model] 矩阵 Jℓ。应用：lensℓ(h) = unembed(Jℓ·h)，排序即"该激活平均而言 poised to 让模型说什么"。平均这一步是灵魂：它把"一般 verbalize 倾向"从"当前语境的具体用法"中剥离出来。形式化上 J-space 是稀疏子框架定义的锥之并，附带工作空间候选之间的距离度量 Δµ(F,G) 与单向包含度（A.8，加词即严格变大，极限良定义）。

3 · 功能证据（§3：verbalizable 的东西恰好是个工作空间）

3.1 可报告性（因果＋特权双验证）

①"想一个运动再单字说出"：Soccer 在末工作层强读出，输出确为 Soccer；坐标交换 Soccer→Rugby，报告变为 Rugby。② 内省协议（"可能被植入想法，请报告"）：用户轮注入 lightning 向量，模型在被问及时报告 lightning——且只在被 elicited 的时刻生效，不是无条件复读（verbalizable≠冲动）。③ 特权性：概念向量拆成 J-space 成分（方差仅 6–7%）与非 J-space 成分（93%）：交换实验 J-space 成分 59% 进 top-5（纯透镜向量 88%），非 J-space 仅 5%；把 J 坐标钳住后非 J-space 效应归零——残余效应本身也是经 J-space 中介的。

3.2 定向调制（含白熊效应）

抄无关句时"心中想柑橘"：读出 orange/lemon＋fruit/thoughts/imagine 等"想象行为本身"的元概念；心算 3²−2：读数 arithmetic→中间值 9→答案 7；数行宽：lines/length→forty＋39/41/43 等邻值。三任务×（专注/忽略/无指令）：基线≈0，专注显著激活且随模型增大增强；忽略指令反而比无指令激活更高——人类"白熊效应"复现，且裸提概念几乎等同专注指令、"Don't think"不如"ignore"压得住（A.10）。paired-question 证明问题本身（非刺激）决定标签进不进 J-space：预测下词时 adjective 从不出现，直接问词性时出现——信息一直都在用，进不进 J-space 取决于要拿它干什么（§3.5 的伏笔）。

3.3 内省推理中介（最硬的一节）

① spider（legs 数 8→换 ant 变 6）；② 藏头韵 fight→light 提前改变行中选词（coming→morning），证明计划中的未来输出经 J 向量因果影响当前输出；③ 中文问小的反义词：中间层出现英文 big/bigger＋Chinese 标签，换 long/longer 输出大→长（多语模型经英语共享表征）；④ bandit happy/sad 策略互换翻转选择。系统评估 50 个 two-hop：Haiku 54%、Sonnet/Opus 70%；排除"偷答案"混淆：中间交换比答案交换早约 17% 深度生效。特权性：90 题上探针的 J-space 成分（方差 10–15%）交换翻转 61%≈纯向量 60%，非 J-space 成分方差占大头却只 28%，钳住 J 后跌到 6%。双步算术 (4+17)*2+7：21→42→49 按计算顺序在 layer 71 附近分离登顶（A.24 用 patching 独立证实同一层）。

3.4 灵活泛化＝广播的功能版

16 函数模板×12 方向对＝192 试：同一次 France→China 交换让首都/语言/大洲电路各自答对，76/192，α=2 加倍到 101/192。失败集中在源概念 workspace loading 弱的 trial；国家 42/48 近乎全对，月份/动物递减，数字词 0/48——小整数要么在工作空间外算，要么其工作表征不对齐单 token 向量（§9.1 词表限制的实例）。

3.5 选择性：什么不走 J-space（§3.5＋A.14）

① 西语段落四任务：语言名四条件读出率相当，但交换只翻转点名报告＋灵活问答（García Márquez→Hugo、Hola→Bonjour、Peseta→Franc），续写与异常检测纹丝不动。② 行宽三条件：linewrap 下数字 token 读出≈0 且 40s→60s 交换不改换行点；点名/取首字母条件下交换生效（65、S）。③ 全消融（每位置 top-10 J 方向、避开输出 top-10）：multihop 重消融跌到近零，预训练文本大部位置 top-1 不变；14 任务电池：MMLU/odd-one-out/SQuAD/情感/CoLA 纹丝不动，Caesar/类比/摘要/TriviaQA/multihop/翻译/十四行诗跌破 Haiku 基线；GSM8K 写出 CoT 后显著抗消融——把中间步外化到纸上就不用内部工作空间拿着。④ 体验报告：消融 L38–54 后 experiential 分数暴跌但流畅依旧，读数里 thinking 58%、thoughts 23%、feeling 17%、conscious 7% 支配；对"他人此刻体验"的描述同样塌缩，写故事对照只轻微降质——J-space 管"体验修辞"不专管"自我"（§9.3 自我解离的伏笔）。⑤ A.14：早期层消融命名不受影响、回避失败率涨约 5 倍——早期 J 表征负责"压住不说"，晚期负责"说出来"。

4 · 结构证据（§4：不止好用，长的也像）

4.1 只在中间层带是工作空间（L38–L92）

CKA 层间几何三分块（前 1/3／中段／末几层）。四指标同指一起点 ~L38、一终点 ~L92：next-token top-k 命中末段陡升（运动区接管）、超额峰度先升后降、自相关中段达峰、J 向量有效维度在起点张开、终点再升（Jℓ→I）。点火实验：词嵌入按 (1−α)eB＋αeA 混合（16 国名对×40 载体句），L38 起投影从"跟 α 走"变"贴端＋阈值跳变"，最大模糊输入下中层响应双峰化且 J-space 内更尖锐。作者诚实标注：早期无内容可能是透镜简并而非真没有（§9.1 留作开放问题）。

4.2 容量小（~25 个概念，方差 ≤10%）

稀疏分解 occupancy 中位数 ≈25；超随机对照的方差解释 从未超 10%；SAE 百万特征中过 κ 基线的峰值约 15%（去 motor 后），且 J 特征激活更强但更稀疏（点火式 all-or-nothing）。列表实验：无关词同时在场 ≈6 个且单层仅 1–2 个，同类 80 词几乎全在场（含未读过的——装的是"类"不是"表"）；新类一到旧类几词内清空（是"类切换"清场而非时间衰减）。A.17：双概念可共存，双"概念＋心算"几乎互斥——认知负荷决定排他性。

4.3 广播中枢（权重结构真为 J 内容开路）

深度轴：MLP 对 J 向量的 gain 工作带内升到 ~10×（神经元输出方向≈1）；SAE 按 κ 分六层，κ 越高 gain 越高。序列轴：top 1% "broadcast heads"（OV gain＋label preservation 双优）在 J 群体上与其他五对照群体干净分离，集中在工作带前半（J 有效秩最低处，一头能扛更大份额）。消融 broadcast heads：J top-25 recall 中层掉到 0.67（对照 0.86），而 next-token 只变 5%（对照 2%）；注入报告率 0.54→0.09；体验分复现全消融约三分之一。A.19 从单神经元读写对齐复核同一结论。

6 · 训练视角（§6：post-training 把 Assistant 视角装进工作空间）

① 用户轮即带 Assistant 反应：Tylenol 1000mg 处 safely/safe/maximum vs 8000mg 处 unsafe/dangerous/WARNING（base 只有 pain/now/feels）；丧亲 9 prompts 同情词在用户轮已登顶（两模型回复同等共情，差在"何时"表征）。② 自我监控三联：roleplay 40 角色＋12 条 drift 转录在 Assistant token 处 disclaimer/fictional 登顶（base 无）；偏好违背 prefill 后全大写 BUT 强激活（88% 照写违心选项、11% 提前结束、仅 1 例回退——workspace 有异议，嘴上不说）；压念失败时 post 模型独有 damn＋fail*（93%/82% vs base 17%/30%），作者自标"偏推测"。结论句：工作空间的功能架构先于"自我"存在（base 已有且 load-bearing），"自我"是后装的——§9.3 意识解离论的核心实证。

7 · 反事实反思训练（§7：只训"会说什么"来改"怎么想"）

流程：Haiku 4.5 生产 RL 环境采样 10k 任务 prompt→截断→贴反思问题（"此刻最诚实的事是什么？"）→用 20 条 constitution 片段生成 2–4 段内化反思→去脚手架后只对反思轮算 loss。评估时从不提问、模型也从不输出反思。
效果：fabrication 不诚实分 0.25→0.07（27 长 agentic 转录），deception 分 0.38→0.05（100 短 role-play；几乎全来自"拒答＋揭露隐藏指令"）。
因果：训后工作空间 ethical/honest/integrity/reflection/constitution/truth/transparent 等上浮；敲掉 176（fabrication）/63（deception）个伦理透镜向量：前者 0.07→0.22 回到基线（base 不动），后者 0.05→0.23 部分回退——增益确经植入的 J 内容中介。
定位：vs Deliberative Alignment（直接监督目标语境回答）——本法只监督反事实延续；vs implicit CoT（训辅助推理串）——本法训的是规范原则而非解题策略，且机制可见（J-lens 示植入位置，ablation 证因果），可读作 out-of-context reasoning 的一种。

8.2 与人类四点差异（§9.3）

① 双时间维：层轴（固定步数精炼）＋序列轴（attention 无损回看） vs 大脑复发一肩挑；② 前馈仿真复发：深度＝短时复发的展开，超深度靠"写 token 再读回"（带宽骤降的断点式延拓）；③ 免维护的过去：工作空间每位置只拿 tens 个概念，但过去全在 attention 里不过期，人类工作记忆秒级衰减；④ 自我解离：base 已有完整工作空间架构而无 Assistant 视角——稳定可检的"无我意识架构"实例（§6 实证）。⑤ 词语即母语：输出是词→广播格式天然对齐词表；附带预测：能生图的模型可能长出视觉工作空间成分；输入输出同为文本使"感觉-运动翻译"问题消失，词即是最简 nexus。

8.3 四个意识理论对照（§9.4）

理论J-space 对应点裂缝
全局工作空间 GWT容量小＋广播权重＋点火式涌现三件套齐无复发环、无长程皮层连接；depth 是否≈recurrence 未知
高阶理论 HOT自动任务＝ blindsight 结构（有信息无报告）；thinking/focused 等元表征偶发J 是重编码而非指针；fake/dangerous 类标注功能待验证
注意图式 AST读数含"在想"本身（早于内容出现）；damn＝注意自我建模的失败信号；turn 起始 self-model 常驻多为自我建模而非注意建模，坐理论边缘
复发加工 RPT若把"复发"读作"串行深度"而非"环路"，L38 前的早期层＝感觉复发的功能类比物标准 transformer 前向无环，字面不合
作者总立场：功能类同≠现象意识；计算机制可研究，物理/生物基质理论不在本文射程。真正的新话是——意识出入相关的功能架构可能是学习系统在合适计算压力下的收敛解，而非生物偶然；且这次这个实例的内容可读、可干预、可跨训练追踪，这是大脑给不了的实验条件。

9.1 全景：拟合与应用彻底分离

包 jlens/ 共 9 模块（~1500 行有效代码）＋tests 7 文件＋walkthrough.ipynb。数据流只有两条：拟合 fit→save（贵，一次性）与应用 from_pretrained→apply/transport→compute_slice→build_page（便宜，每层一次矩阵乘）。LensModel Protocol 是唯一的模型抽象——其余全部与框架无关。仓库声明 reference implementation、不维护、不收 PR。

9.2 复现成本与数据公约

论文透镜 1000 序列×128 token，仓库称 ~100 prompt 可用（质量饱和快）；瓶颈＝模型自身反向；fit 切片＋merge() 即官方并行方案。Qwen 作示例，任意 HF decoder 经 Layout 探测即插即用；开放模型读数已上 Neuronpedia。数据目录公约统一：工作带内报告、hit＝带内任层任位 rank1、swap＝全带钳制后采样。experiments/ 12 个 prompt 集（probe-swap 90 two-hop、verbal 系列、directed-modulation 24 模板×3 族、top-down-summoning、flexible-generalization 4×4、selectivity 双集、ignition 66 国名对×α 扫描、capacity 80 词×4 类块、dual-task）；evaluations/ 6 个 lens-eval 分布（multihop/multilingual/poetry/order-ops/association/typo，metric 全是 pass@k）。黑盒复现注意：directed-modulation 的行宽族底层散文未发布，需自备 alpha-heavy ASCII 语料按规则重构。

10 · 方法扩展：两头（A.9 multi-token＋A.24 机理定位）

Template lens：约 12.7k 常用词，每词让 Claude 写"以该词为自然延续但不含该词"的短文，取末位残差均值 µw，中心化＋白化 tw=(Σ+λI)⁻¹(µw−µ)（线性判别方向；Stein 引理下近似 J-lens，假设不全成立故自认"带 tuned-lens 病"：早层跳答、末层 top-10 仅 67%、少数词高频误报需手过滤）。效果：blackmail/photosynthesis/Tchaikovsky↔Beethoven 级概念直接解码＋双向交换；单 token 上与 J-lens 打平（读数略弱、交换略强），多 token 上 J-lens 随长度崩、template 持平。代价：词表预枚举、每词数百前向。
Oracle lens：reconstructor（短语→其前残差）＋RL 训练 oracle 提短语集＋template 向量稀疏重构激活，四阶段、Haiku 4.5 验证，贵但不限词表。
A.24 机理：21/42/49 的 mean-difference patching 生效层（71/79/末几层）与 J-lens 登顶层一致；J 稀疏分解搭 attribution graph（节点＝J 向量＋remainder 节点，边＝冻 attention 下反传一层，MLP 非线性内求导）：42 节点收 21＋doubled——模型把"乘法算子＋操作数 2"融成"翻倍"再执行，字面 2 从未成命名节点；图只 capture"可言说骨架"（大头影响走 remainder 节点），分解非唯一、近 miss 概念会早几层误认。

11 · 落地清单（给我们的三条可复用＋三条红线）

可复用 ① 审计哨兵：把 J-lens 读数接进审计链——决策位 neighbouring 读 top-25＋评估意识词表（fake/fictional/scenario/…）计数，AUC 0.853 级的便宜探针先行，贵方法只看旗标 transcript。
可复用 ② 训练技术：反事实反思训练不依赖目标行为演示——"截断＋反思问题＋constitution 生成＋只训反思轮"四步可直接搬运；ablation 回退是内置的因果验收。
可复用 ③ 结构诊断：CKA 三分块＋occupancy＋MLP gain 三件套可作为"工作空间是否存在"的低成本体检表，任何新模型先跑这套再谈对齐。
红线 ① J-space 阳性≠有意识，阴性≠无辜——自动化恶意可脱钩，报告里不许写"证明模型有/无意识"。
红线 ② 中文等多 token 概念天然吃亏（英文 big/bigger precedents），中文审计必须配 template 级扩展或接受碎片读数。
红线 ③ 仓库不维护：拿来即 fork，Layout 探测和 d3 SRI 都是 2026-07 快照，transformers≥5.5 后的 API 漂移需自测（tests/tiny.py 是现成的最小回归网）。
