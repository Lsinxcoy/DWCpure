def _rank(xs):                                    # 平均秩（并列取均值）
    order = sorted(range(len(xs)), key=lambda i: xs[i])
    r = [0.0] * len(xs); i = 0
    while i < len(order):
        j = i
        while j + 1 < len(order) and xs[order[j+1]] == xs[order[i]]: j += 1
        avg = (i + j) / 2.0 + 1.0
        for k in range(i, j + 1): r[order[k]] = avg
        i = j + 1
    return r

def spearman(xs, ys):                             # ρ = Pearson(rank, rank)
    rx, ry = _rank(xs), _rank(ys)
    n = len(xs)
    mx, my = sum(rx)/n, sum(ry)/n
    cov = sum((a-mx)*(b-my) for a, b in zip(rx, ry))
    vx  = sum((a-mx)**2 for a in rx) ** .5
    vy  = sum((b-my)**2 for b in ry) ** .5
    return 0.0 if vx*vy == 0 else cov / (vx * vy)

B · 段式回放设计稿 §2.2 Eq4–6 + Fig8 借鉴 · 消化 R90 留位 · 设计先行

要解决的实证问题（R90 三迭代）：dream 揭示语义（非根深挖优先 + 空转 break + root 兜底）⇒ nonroot≥2 不可达 ⇒ 选择窗口死锁，w_delta 排序在 replay 域永不触发；区分度只剩 r 开关。R90 结论:「要 w 进 dream 需改揭示语义 = 设计变更留位」。
论文给的先例：Eq6 的 subgoal 段语义 —— 下层只跟上层轨迹的前 K 个（closed-loop K=1），段内 re-anchor（Fig8: 段起点重锚后段内 cost 单调 0.89–1.00）。映射到 replay：段 = 分支揭示单元，段间重置 elig，把 R90 被 interleave 打断的「同层多观测叶」窗口变成段内常态。

裁决点（三案 → 推荐甲）

裁决甲（推荐）乙丙
段定义段 = root 的一个 child 分支单元（与读法乙「root 开分支」同构 — 段边界=既有语义的显式化, 零发明）每 K_hard 步硬切组层轨迹（依赖方案 C ⇒ 耦合, 后置到 C 落地后）
段间顺序root children 序 × δ 排序（段间选择用 dmap — 与任务源同源）固定字典序—
段内预算K_s = 段内最大揭示步（新参数, 默认 4）; 全局 K₂ 不变（段预算 ⊆ K₂）无段预算（挖完为止）—
re-anchor 语义段开始时 observed = {root} ∪ 已完成段的完成集 — elig 按段重算（其他分支的叶不进本段候选）observed 全程累积（=现状, 死锁不解）—

死锁破解机制（为什么段式甲能让 w_delta 复活 — 基于 R90 实证的推演）

现状（R90 实证）: root 连揭两子被段间 interleave 打断 — 001 深挖插入,
  「同层双观测叶」态永不出现 ⇒ nonroot 恒 0/1 元素
段式甲: 段内只挖本段分支 — child1 的 a、b 同层双叶态成为段内常态:
  段内 step 序列 → root 揭 child1 → child1 揭 a → (a 完) → root 揭 b
  → 此刻 leaves={a, b} 同轮在场
  · r=0 家族: nonroot=[a, b] 两元素 → w_delta·dmap 排序真实生效
    （R90 v3 反序对构造失败的原因正是段间 interleave, 段式直接移除）
  · r=1 家族: 仍需 a/b 都能揭（有未观测子）才入候选 — 边界如实标注
⇒ w_delta 的 dream 主场回归路径 = 段式甲 + r=0 变体（B 轮的验证靶）
