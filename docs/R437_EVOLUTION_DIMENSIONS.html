四、新颖度奖励面（ν_t）

只有 5 个组件拿结构新颖度奖励（论文式15 + DWC 增补）：client_tool · skill · memory · subagent · meta_evolution。 提示词 / 控制流 / 配置 / 输出管道 / 上下文管理 不拿（论文原话）。

五、一句话结论

声明了 21 个进化对象 / 12 个可编辑组件， 但生产上真正能改变系统行为的只有 2 个：control_flow（半活：能起草、能试跑、不落地） 和 prompt（半活：能生成候选、能 A/B、不自动晋升）。 其余 10 个里，3 个「有实现但零调用」（skill / memory / config），5 个「只在词表里」， 2 个「元层」。
