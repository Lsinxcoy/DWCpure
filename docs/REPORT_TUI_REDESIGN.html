0 · 三条跨方案共识（先抄这些，不犯错）

① 颜色是语义，不是装饰

所有高分 TUI 都把颜色当 token 用（status.error / text.muted / accent.primary），而不是 raw hex。dev-tool 系的原话：深色画布上颜色是被配给的信息载体——语法、diff、日志级别、状态在深色上才读得清。DWC 已经是深色＋amber，方向正确，缺的是一套 token 表（现在颜色散落在代码里）。

② 空间记忆＞花样

lazygit/k9s/btop 七大经典布局的第一戒律：面板一旦定居就不许动——"focus 换位是最恶劣的设计罪"。改版只换皮、不搬家：顶栏还是顶栏，对话还是对话。

③ 内容前流，chrome 极简

Claude Code 的 AI 回答无边框、无前缀、白字直排；工具块才有框。消息之间只有一条 #505050 细线。DWC 的 Markdown 卡已经是这个路子——保持。

可偷的部件

① 工具块标题嵌在边框上：

┌─ Bash ─────────────────────────┐
│ $ npm test                      │
│   ✓ handles input (12ms)       │
└─────────────────────────────────┘
DWC 动作区现在是裸行——失败行展开后套这个粉框，档次立刻上来。
② 思考动词："✳ Percolating…"（184 个俏皮词、6 符号 120ms 反转）。DWC 的"轮 n·思考中…"可换成中文俏皮词（"酝酿中…""推演中…"），成本 5 行。
③ 底部状态行：Opus · 12.4K tokens · $0.04 · 3.2s——DWC 顶栏已有 pending/done，缺 token/耗时位（R272 刚加了模型位，拼一起就是完整状态行）。

2 · Gemini CLI 语义边框 最实用

核心一招：边框颜色＝工具状态

等待中黄 #ffffafbg 轮询中回执卡

另有 15＋ 内置主题 JSON token 架构（ui.active / status.warning / border.default）——DWC 将来做主题切换（amber↔陶土↔琥珀）时照抄这个 token 表即可。圆角框 ╭─╮╰─╯ 全套，textual 原生支持。

3 · Retro CRT 琥珀 与 Deep Space 同源

现 amber 语言的"加强版"

底 #1a1200（暖黑）＋字 #ffb000 琥珀＋双线框 ╔═╗║╚╝＋分节符 ══╡ SECTION ╞══＋点线 ······。DWC 的 Deep Space 是"冷高级"，Retro 是"暖高级"——两套都是 amber 系，切过去只需要换底色＋框线字符，零布局改动。ALL CAPS 题头＋reverse 反白数值是点睛。

注意：全套 Retro（figlet 大字＋全大写）会挤占信息密度，只建议取"暖底＋双线＋分节符"三件，不取大字。

4 · 给 DWC 的四套改版方案（按工程量排）

方案 A · 语义上色 ≈80 行

不动任何结构：建 theme.py token 表（accent/success/warn/error/muted/surface 六 token 收敛散落 hex）＋动作行按 ok 上色（成功行保持、失败行粉框＋详情）＋done 历史行变灰。风险最低，R273 可直接做。

方案 B · 工具块边框化 ≈120 行

A ＋动作/回执/mem 卡统一套圆角边框（标题嵌框线，抄 Claude Code），Gemini 式四态边框色（蓝跑/黄等/灰完/红败）。对话区从"行流"升级为"块流"，现代感主要来源。

方案 C · 暖底换肤 ≈60 行

B ＋底色切暖黑 #1a1200、双线框、══╡ 分节 ╞══（取 Retro 三件）。DWC 气质从"冷高级"转"暖高级"，和 amber 一脉相承。建议做成 /theme deep|warm 可切换（token 表天然支持）。

方案 D · 呼吸感 ≈100 行

C ＋思考俏皮词、shimmer 输入框、状态行 token/耗时（R272 模型位已就位）、subagent 多彩（Claude Code 八色盘，DWC 暂无子代理——先空出 token 位）。动效全部走现有 spinner 节拍，不引入新时钟。

5 · 落子建议（你醒来拍板）

推荐：A→B 连做一轮 R273，C 以 /theme 可切换跟上，D 看心情

① A＋B 是"现代感"的 80% 且零布局风险（守"面板不搬家"戒律）；② C 的暖底是品味分歧项，做成可切换谁都不得罪；③ 全程 G1 不动（只换皮，不碰判定/执行）；④ 主题 token 表一旦建立，以后换肤都是改表不动代码——这才是"高级"的工程底子。

回一句 "动手 A+B" 即开工（默认主代理直做）；或者单点其中一项。R272 的回归＋提交在我这边挂着，回来即办，不耽误。
