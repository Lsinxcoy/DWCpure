W4 · 收束判据不来自世界模型自算 收束函数的输入不得含 dynamics 的 confidence 依据: ARSI compare_interventions 用 avg_conf 排序 (假置信度)

逐句对照 δ_θ

W4 字面δ_θ 的实际违吗
输入不得含 dynamics 的 confidenceδ_θ 输入 = judge 判分史的频率（C3' task_scores + evidence, 系统外观测）字面不违它压根不是 dynamics confidence

C · 裁决①δ_θ 任务源偏置（任务级难度怎么算出来）

接法任务级 δ = 该任务历史失败签名的组内稀有度：task_id → C3' 分数点（judge.task_scores 已按 task_id 记）→ evidence 拉历史签名 (c,q) → DifficultyEstimator → 该任务取其历史签名的 max δ。全在已落链上, 零新数据
落点run_term 任务源生成处: tasks 列表按 δ 降序排（罕见失败的任务优先探）——不动 select（= 裁决 C1 时的落点）
边界没评过的任务无历史签名 ⇒ δ=0 保守排尾（不装 NaN 进排序 — NaN 不可比, 明确降级为 0 + 记录 "no_history"）
行为影响任务源顺序变化（可能影响 e2e 的 next 断言 — 用排序不删条目, 集合不变）
依赖裁决①选 C1/C2 时可与 B 同轮；选 C3 时本接点照做、select 另议
