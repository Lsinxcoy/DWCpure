① 问题重述与我的决定

裁决③原文义务:「Pareto 验收 = 单目标 no_worse 的升级 — 需先答『哪几个目标、谁定权重』」（用户授权: 我深度分析后决定）。

我的决定（三句话版）:
1. 哪几个目标 → {gain, cost, retention} 三目标（全部已有测量, 不为 Pareto 造新测量; 频域不进验收的排除清单见 §③）。
2. 谁定权重 → 决策层零权重: 验收走 DecoEvo Eq.10 支配式判定 （一维非平凡改善 + 全维不回退), 文献明文不做跨目标加权; 权重问题 被结构性消解。
3. 权重还剩两个真参数 → δ（改善门）与 η（回退门） — 这才是要定值的 东西, 逐维给初值与校准来源（§⑤）。展示层的等权摘要 明标无裁决效力 （§④）。

② 文献锚 — DecoEvo Eq.10（逐字）

accept ⟺ ∃k∈K : Δ_k > δ　且　∀j∈K : Δ_j ≥ −η　（Eq.10, DecoEvo 2607.25675）
"at least one usable audit objective must show non-trivial improvement, and no objective may regress beyond η" — 原文同时明文: "No weighted cross-objective aggregation"（不做跨目标加权求和）。
DecoEvo 教训链（精读 2607.25675）: SC-CoEvo 未配四件套 ⇒ 分数耦合 对照 13/15 反向; DecoEvo 自身靠 分数解耦 + 盲审计 + Pareto 验收 + 冻结审计集 四件套避免该结局; 提案与验收用不同数据（rewriter 只见 探针记录, 候选在隐藏集上评, 验收 rollouts/配对冻结）。
⇒ 对裁决③的直接含义: 「谁定权重」在正解里不存在 — 加权求和 正是 13/15 反向的机制温床（耦合分数被权重放大）; 答案是支配式验收 + 两个门参数。

③ 哪几个目标 — 三目标 + 排除清单

目标语义测量（已有 — 不发明）在 Eq.10 的角色
gain改进质量 dream v_by_version / judge success_rate（R85/R100 已跑） 主改善门对象（∃k Δ_k>δ 可来自它）
cost效率（越低越好） CostLedger 逐 term 账（R99 已落, 含评估成本 — §3.6.5 字面） 改善门对象（变便宜=改善）+ 回退门（变贵超 η 拒）
retention旧能力保持 regression_check 保护组（终止条件③; R115 ε 策略键同源） 纯约束（∀j 门）: 有回退即 −η_ret 不满足 ⇒ 拒; 不作改善门
为什么是这三个（判据, 不是口味）: 它们是综述 Table 8 六维中 DWC 已有测量的前三个（gain/efficiency/retention）— 对应 RSI 的 「更好 + 更省 + 不弄坏」三轴, 彼此有真实权衡（多探索 ⇒ gain↑cost↑; 保守 ⇒ retention↑gain↓）。

排除清单（诚实写明为什么不是目标）: 
novelty / liquidity      — 过程机制指标（服务 gain 的中间量）, 非验收目标;
                           混入验收会稀释语义（机制与结果分层）
stability (pass^k)       — 与 gain 同域高相关 ⇒ 加进去=伪多目标
                           （DecoEvo 耦合教训的正面防范）→ 进审计面不进验收
transfer / meta-recursion— Table 8 缺口清单, DWC 无测量 ⇒ 不进 K
                           （无可测不进验收 — 不装）
δ 覆盖 / 任务数          — 世界树状态量, 属 gain 的解释变量

④ 权重设计 — 三层结构（决策零权重 / 门参数 / 展示等权）

层1 · 决策层 = 零权重（唯一有裁决效力的层） 
Eq.10 支配式验收（对 M>1 select_policy / 提案 gating 通用）:
  对候选 c 与在位者 0, 逐维算 Δ（归一化后）:
    Δ_gain     = V(c) − V(0)                          （越大越好）
    Δ_cost     = cost(0) − cost(c)                    （变便宜为正 — 方向翻转）
    Δ_ret      = 1[无回归] − 1[无回归] 的退化量        （0 或负）
  accept ⟺ (Δ_gain > δ_gain  ∨  Δ_cost > δ_cost)
            ∧  Δ_gain ≥ −η_gain
            ∧  Δ_cost ≥ −η_cost
            ∧  Δ_ret  ≥ −η_ret
  ⇒ **没有任何一处出现加权和** — 维度不可互换（gain 换不来 cost 回退）,
    耦合维无法通过权重放大自己（13/15 反向的机制被结构性掐断）

  平票规则（与 E2 一致的保守传统）:
    不满足 accept ⇒ 在位者续任（challenger 归档不静默）
    多个候选同时 accept ⇒ 全进非支配集, 按 cost 升序取首
    （cost 是最客观破局轴: 确定性记账无抖动 — R105c 教训: V 有跑间抖动）
层2 · 门参数层 = δ 与 η（真正要定值的"权重等价物"）→ §⑤
层3 · 展示层 = 等权摘要（明标无裁决效力） 
score_display = mean( norm_gain, norm_cost, norm_retention )   # 归一到 [0,1]
用途: 报告/趋势图的单值可读性
硬标注（进代码注释与每次输出）:
  "展示专用 — 不参与任何 accept/reject 判定; 判定只认层1 支配门;
   等权 = 不引入先验独裁, 但仍是聚合 ⇒ 故无裁决权"
⇒ 「谁定权重」的最终答案: 层1 没有权重可定; 层3 的等权不值得定
   （无裁决效力 ⇒ 谁定都不影响系统行为）; 需要工程定值的只有层2 两门

⑤ δ / η 门 — 逐维初值与校准来源

门维初值来源/理由
δ（改善门）δ_gain 待校准（执行轮用 0, 同时跑重复采样测 V 抖动后回填） ★ 改善必须 > 跑间噪声才算真（R105c: 同配置跨跑 success 抖动 0.20 — V 的抖动**未测** ⇒ 不拍脑袋给数, 执行轮首跑补测（β/τ 同款纪律）
δ_cost10%（相对基线成本下降 ≥10% 才算成本改善） CostLedger 确定性记账无抖动 ⇒ 门来自管理口径不是噪声; 10% 初值标注 「管理口径, 可调」— 小于此的省钱不值得换代（换代有切换成本）
η（回退门）η_gain0 = 现行 no_worse_than_current 语义原样（best ≥ current）— 单目标升级不放松既有底线, 零回退破坏
η_cost20% 质量换成本是合法交易（gain 改善门通过时可容许变贵 ≤20%）; 超 20% = 不可控膨胀, 拒（初值管理口径, 可调）
η_ret0（硬） Recuris 锚点任务判据 + DWC「不破坏已会做」铁律 — 旧能力零回退是 判据不是偏好（R115 ε 策略键只容忍 delta 数值口径, 不改此门）
校准义务（进执行轮验收）: 任一"待校准"门在报告里必带 calibration_note（值从哪来/还缺什么）; δ_gain 回填后老档带 supersedes 版本链（六段档 Humanlaya 属性）。

⑥ 双审计落地（DecoEvo 两类审计的 DWC 映射）

审计A · 耦合审计（防 13/15 反向 — 分数耦合的正面探针）
  每次多目标评估附维间 Pearson ρ 矩阵（gain/cost/retention, n≥8 样本）
  |ρ| > 0.8 ⇒ 该对维标 "coupled" 进审计报告 — 警示伪多目标
  （耦合时 Eq.10 的 ∃k 门会被耦合维主导 — 报告必须显式带此警示, 不静默）
  ρ 不足样本（n<8）⇒ status=insufficient_samples（X2 不装数同族）

审计B · 冻结/盲审计（提案与验收用不同数据 — DecoEvo 原文）
  · 验收集 = 冻结 anchors（G2 truth_sha8 断言已有 — 文件 agent 不可写）
  · 提案者不可见验收反馈 = DWC judge 独立 + r_priv 不读（既有判据）
  · ★ 与裁决①(拆)的合流: D_val 拆出即「最终选择专用、搜索不可见」子集
    —— 裁决① 的标签隐藏正是审计B 的 DWC 缺件, ①执行轮补上后
    「提案不见验收数据」才完整（现: 部分满足）
合流关系: 裁决③的审计B 依赖裁决①的 D_val 拆分 ⇒ 执行序: ① 拆分先行 → ③ Eq.10 验收接在其上（本稿即 ③ 的设计, 执行排 ① 后）。

⑧ 诚实条款

1. 本稿无实测 — δ_gain 的 V 抖动未测（执行轮首跑补）; δ_cost/η_cost 是管理口径初值非文献值（DecoEvo 未给跨域通用数值, 其 Eq.10 只给 形式）; η_gain/η_ret=0 来自既有判据不是新发明。
2. 三目标不声称完备 — Table 8 六维中 transfer/stability(已降审计面)/ meta-recursion 不在 K, 因为 DWC 无测量（缺口如实, 不造尺子凑维数）。
3. ρ 耦合审计是探针不是证明 — n 小的 ρ 不稳定, 只作警示不做裁决。
4. 展示层等权仍是一种聚合 — 它无裁决效力是设计约束（代码级 断言保证）, 不是语义上"不算加权"; 有人将来把展示值接进裁决 = 违约, 破坏测试负责抓。
5. 与裁决②的边界: Eq.10 管「验收什么」, epoch 对拍管「评估器怎么换」 — 两机制正交, 不复用对方的门。
