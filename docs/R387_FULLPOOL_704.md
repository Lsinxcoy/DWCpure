三、本轮补的两个工具层修复
════════════════════════════════════════════════════════════
① **`shlex.split(posix=False)` 保留引号**（第二次踩同一个坑）
   模型传 `-E "max_round|max_rounds"` ⇒ grep 收到
   `'"max_round|max_rounds"'`（带字面引号）⇒ 永远搜不到、ok=False。
   修：`posix=True` 正确剥引号。

② **`run` op 不经 shell，管道/重定向必然失败**
   模型爱写 `grep ... | head -20` ⇒ `|` 被当字面参数传给 grep。
   修：`_argv_of` 在 `|` / `||` / `&&` / `;` / `>` / `>>` / `&` 处截断
   （**不引入 shell** —— 过 shell 是注入面）。
