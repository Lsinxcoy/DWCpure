① 论文语义（§2.5–2.7 逐字要点）

· 迭代 t 的离线阶段 ℋ_t 固定不变；构造评估 M ≥ 1 个策略版本 π_t^0…π_t^{M−1}，起始 π_t^0 = π_t（当前策略）。每个版本在每个历史树上单独评估完毕，才从反馈中开发下一个版本。

· m = 策略版本（不是"假想世界状态"——R75 提案时的措辞已修正）；i = replay world；k = 决策轮。

· 𝒯_i 固定，只有策略可观测部分 𝒯_i^{m,k} ⊆ 𝒯_i 在变；转移=确定性返回已录 children，绝不生成新候选。

· 式1：V = max s_v − β₁·N + β₂·(N/max{1,k})。论文未报告 β₁/β₂ 具体值（"fixed coefficients" + β≥0 符号约束）。

· §2.7：policy-development agent 接收 π^m 的 replay 轨迹与分数+修订反馈，"identify successful decisions and recurring failures"，然后修订可执行的策略代码；下一轮 π_{t+1} = π^{m*}，m* ∈ argmax V^m。单调性保证=「固定历史上平均 replay 分不劣于当前」。

② 缺口一：ℋ 载体语义

缺口：ℋ_t = ℋ_{t−1} ∪ {𝒯_t} —— 论文每轮一棵独立发现树。DWC 现状是单棵 dev 树长跑（R77 播种后 10 叶、term 间只增长不换树）⇒ "每轮一棵新树"与现状冲突；且 WorldTree 无快照机制。
推荐裁决：单树时点快照 
ℋ = [deepcopy(world_model) @ term_1, deepcopy @ term_2, ...]
# 同一棵增长树在各时点的快照序列 ≈ 论文的"每轮独立树 + 历史累积"
# —— 论文语义的忠实近似（各快照互不影响, 可并行回放）; 不发明"每 term 换新树"

落点：DWC 侧维护 _replay_history: List[WorldModel]（run_term 尾按需快照；深度与论文 𝒯_i 对齐=完整树）。内存列表 + 可选落盘（config/anchors/ 同族，gitignored）。

③ 缺口二：M 版本产生

缺口：论文的"开发下一版本"= 修订可执行的策略代码（policy-development agent 产码）。DWC 的"策略"=采样逻辑硬编码（_el_pick 的 EL+δ 组合）无策略代码可修；发明"策略修订 agent"=违实现对齐设计（无设计明文）。
推荐裁决：首版 M=1（论文明文合法） 
M=1: 只评估 π^0 = 当前策略（在 replay 可观测面复用 δ 排序+EL 游标语义）
单调性退化为 V(π^0) ≥ V(π^0)（平凡成立）—— 诚实标注, 不冒充改进
M>1 留二期：等"策略可修订化"设计（候选：采样参数 dials 化 + evolver 提案修参数）
  —— 那是独立设计轮, 不在本稿发明

价值：循环骨架（快照→回放→V 评估→argmax 选优→单调性核验）先跑通；骨架不依赖修订机制（论文框架的正确子集）。

④ 缺口三：β₁/β₂ 来源

缺口：论文未报数值（R74 已锁 replay_score 必传无默认——NOISE_DELTA 纪律）。
推荐裁决：配置驱动 + 校准协议，初始值 0 
# config/replay.yaml（新, difficulty.yaml 同族）
replay: {beta1: 0.0, beta2: 0.0}   # β≥0 边界值; 退化 V = max s_v（纯 discovery quality）
# 校准协议（占位, 复用 R63–R67 实验纪律）: β 网格 × 多轮 A/B, 预注册判据后才定非零值

0 不是发明的数——是"无校准数据时的最保守选择"（β≥0 约束的下界, 意味着不加惩罚/奖励项）；非论文报值。
